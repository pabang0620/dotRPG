# 운영정책

## 제1조 (목적과 적용 범위)
이 정책은 이용약관 제12조에 따라 볼론(Bolon)에서 금지하는 행위와 그에 대한 이용 제한(제재) 기준, 통지와 이의 제기 절차를 정합니다. 게임 안의 모든 채팅(길드 채팅 포함), 캐릭터 이름, 길드 이름과 공지, 파티 모집 글, 거래(경매장, 우편), 결제에 적용됩니다.

## 제2조 (제재의 종류)

| 종류 | 내용 | 기간 |
|---|---|---|
| 경고 | 위반 사실을 알리고 기록으로 남깁니다 | 없음 |
| 채팅 금지 | 모든 채팅과 귓속말을 쓸 수 없습니다 | 1시간, 1일, 7일, 30일 |
| 계정 정지 | 로그인할 수 없습니다 | 1일, 7일, 30일, 영구 |
| 경제 활동 정지 | 경매장, 우편, 거래 등 재화가 오가는 기능을 쓸 수 없습니다 | 조사가 끝날 때까지 |
| 결제 정지 | 유료 별조각을 살 수 없습니다 | 조사가 끝날 때까지 |
| 이름 변경 요청 | 부적절한 캐릭터 이름을 바꾸도록 요청합니다 | 바꿀 때까지 |
| 길드 이름·공지 변경 | 부적절한 길드 이름이나 공지를 바꾸도록 요청하거나, 운영자가 임시 이름으로 바꾸고 공지를 비웁니다 | 바꿀 때까지 |
| 길드 해체 | 길드를 해체합니다. 길드원은 24시간 동안 다른 길드에 가입할 수 없습니다 | 없음 |

영구 정지는 운영 책임자의 승인을 거쳐서만 내립니다.

## 제3조 (위반 유형별 제재 기준)
같은 유형을 다시 어기면 다음 단계의 제재를 내립니다. 위반 정도가 무겁거나 여러 유형을 함께 어긴 경우에는 단계를 건너뛸 수 있습니다.

| 위반 유형 | 1차 | 2차 | 3차 |
|---|---|---|---|
| 욕설, 비하, 혐오 표현 | 채팅 금지 1일 | 채팅 금지 7일 | 계정 정지 7일 |
| 성적 표현 | 채팅 금지 7일 | 계정 정지 7일 | 계정 정지 30일 |
| 도배 | 경고 | 채팅 금지 1일 | 채팅 금지 7일 |
| 광고, 사기, 현금 거래 홍보 | 계정 정지 7일 | 계정 정지 30일 | 계정 정지 영구 |
| 운영자 사칭 | 계정 정지 7일 | 계정 정지 30일 | 계정 정지 영구 |
| 부적절한 캐릭터 이름 | 이름 변경 요청 | 계정 정지 1일과 이름 변경 요청 | 계정 정지 7일과 이름 변경 요청 |
| 부적절한 길드 이름, 공지 | 경고와 길드 이름·공지 변경 요청 | 운영자가 길드 이름·공지를 강제로 바꾸고 길드장 계정 정지 1일 | 길드 해체와 길드장 계정 정지 7일 |
| 현금 거래(RMT) | 계정 정지 30일과 부당 이득 회수 | 계정 정지 영구 | |
| 계정 판매, 대여, 공유 | 계정 정지 30일 | 계정 정지 영구 | |
| 불법 프로그램, 매크로 사용 | 계정 정지 30일과 부당 이득 회수 | 계정 정지 영구 | |
| 버그, 오류 악용 | 계정 정지 7일과 부당 이득 회수 | 계정 정지 30일과 부당 이득 회수 | 계정 정지 영구 |
| 다른 사람 계정 도용, 해킹 | 계정 정지 영구 | | |
| 결제 부정, 환불 악용 | 결제 정지와 경제 활동 정지 | 계정 정지 30일 | 계정 정지 영구 |

버그나 오류를 발견하면 즉시 {{email}}로 신고해야 합니다. 알고도 신고하지 않고 계속 이용하면 악용으로 봅니다. 신고하고 이용을 멈춘 경우에는 제재하지 않습니다.

## 제4조 (자동 제재)
게임은 다음 기준으로 자동 제재를 합니다. 자동으로 계정을 정지하지는 않습니다.

- 금칙어가 들어간 채팅은 해당 부분을 `*`로 가려서 보냅니다. 서버에는 가린 문장만 저장하고 원문은 저장하지 않습니다.
- 띄어 쓰거나 기호를 끼워 금칙어를 숨기려는 채팅은 보내지 않습니다.
- 10분 안에 금칙어가 5번 걸리면 채팅이 10분 동안 금지됩니다.
- 같은 말을 3번 연달아 보내면 채팅이 10초 동안 금지됩니다. 이 금지가 10분 안에 5번 쌓이면 채팅이 10분 동안 금지됩니다.
- 24시간 안에 세 번째 자동 채팅 금지부터는 24시간 동안 금지됩니다.
- 채팅은 1분에 30번까지, 1초에 1번까지 보낼 수 있습니다.

## 제5조 (캐릭터 이름 규칙)
1. 캐릭터 이름은 2자 이상 8자 이하의 한글, 영문, 숫자로 만듭니다.
2. 다른 이용자와 같은 이름은 쓸 수 없습니다(대소문자 구분 없음).
3. 운영자나 회사를 사칭하는 이름(운영자, 관리자, GM, admin, 공식 등과 그 변형)과 욕설, 성적 표현, 혐오 표현이 들어간 이름은 만들 수 없습니다.
4. 자동 검사를 피해 만든 부적절한 이름은 제3조에 따라 이름 변경을 요청하거나 제재합니다.

## 제5조의2 (길드 이름과 공지 규칙)
1. 길드 이름은 2자 이상 12자 이하로 만들며, 다른 길드와 같은 이름은 쓸 수 없습니다(대소문자 구분 없음). 공지는 60자 이하입니다.
2. 길드 이름과 공지에는 제5조 제3항의 사칭·욕설·성적 표현·혐오 표현 기준과 금칙어 검사가 같게 적용됩니다.
3. 길드 이름이나 공지에 대한 신고와 제재는 제3조와 제6조에 따르며, 제재의 통지와 이의 제기는 길드장에게 제7조와 제8조대로 합니다.

## 제6조 (신고)
1. 이용자는 채팅 창에서 다른 이용자를 신고할 수 있습니다. 신고 사유는 욕설·비하, 도배, 광고·사기, 불법 프로그램 의심, 기타입니다.
2. 신고하면 최근 대화가 증거로 자동 첨부됩니다. 귓속말은 신고자와 신고 대상 사이의 것만 첨부됩니다.
3. 신고는 1시간에 5건, 하루에 20건까지 할 수 있습니다.
4. 다른 사람을 괴롭히려고 거짓으로 신고하면 제3조의 욕설, 비하에 준하여 제재합니다.
5. 이용자는 다른 이용자를 차단할 수 있습니다. 차단하면 그 이용자의 채팅, 귓속말, 초대를 받지 않습니다.

## 제7조 (제재 통지)
1. 제재가 내려지면 게임에 접속해 있는 경우 즉시, 접속해 있지 않은 경우 다음 접속 때 알립니다.
2. 계정 정지 중 로그인하면 정지 종료 시각을 보여 줍니다.
3. 통지에는 제재 종류, 사유, 기간이 들어갑니다.

## 제8조 (이의 제기)
1. 제재에 이의가 있으면 통지를 받은 날부터 30일 안에 {{email}}로 이의를 제기할 수 있습니다.
2. 이의 제기에는 캐릭터 이름, 제재 종류와 일시, 이의 사유를 적어 주세요.
3. 회사는 이의 제기를 받은 날부터 영업일 7일 안에 검토 결과를 알립니다. 검토가 늦어지면 그 이유와 예상 일정을 알립니다.
4. 제재가 부당했다고 확인되면 즉시 해제하고, 제재로 생긴 손해를 보상합니다.

## 제9조 (확률 변경 사전 공지)
확률형 아이템의 확률을 바꾸는 경우 바꾸기 7일 전부터 게임 안 공지와 웹 페이지로 알립니다. 게임 안 확률 보기와 웹 페이지에는 언제나 현재 확률과 확률표 버전이 표시됩니다.

## 제10조 (정책의 변경)
이 정책을 바꾸는 경우 시행 7일 전부터 게임 안 공지와 웹 페이지로 알립니다.

이 정책은 {{effective_date}}부터 시행합니다.
