# 개인정보처리방침

{{name}}(이하 "회사")는 개인정보 보호법에 따라 이용자의 개인정보를 보호하고 관련 고충을 신속하게 처리하기 위해 다음과 같이 개인정보처리방침을 정합니다.

## 제1조 (처리하는 개인정보와 목적)
회사는 다음 목적에 필요한 최소한의 개인정보만 처리합니다.

| 목적 | 처리 항목 |
|---|---|
| 계정 생성과 로그인 | Steam ID(17자리), 패밀리 공유 소유자 Steam ID, 계정 식별자, 계정 생성 시각, 로그인 시각 |
| 로그인 유지 | 갱신 토큰의 해시값, 설치 ID, 기기 식별값(해시) |
| 동시 접속 관리와 부정 이용 방지 | 접속 IP, 기기 식별값(해시), 설치 ID, 클라이언트 버전, 접속 상태(캐릭터, 맵) |
| 게임 진행 | 캐릭터 정보, 레벨, 경험치, 소지품, 재화와 아이템 증감 기록 |
| 채팅과 신고 처리 | 채팅 내용(금칙어를 가린 문장), 신고 내용과 증거로 복사한 채팅 줄, 차단 목록 |
| 이용 제한 | 제재 기록, 경제 활동 정지 기록 |
| 유료 결제 | Steam ID, 주문 금액과 통화, Steam 국가 정보, 결제 시 IP와 기기 식별값(해시), 결제 상태 |
| 오류 진단 | 클라이언트 버전, 플랫폼, 오류 메시지(500자 이내), 오류 위치 정보(2,000자 이내) |
| 서버 운영과 보안 | 웹 서버 접속 기록(접속 IP, 요청 시각과 경로, 응답 코드, 클라이언트 정보), 서버 시스템 로그 |
| 약관 동의 기록 | 동의한 문서와 버전, 동의 시각 |
| 파티 던전 결과 판정 | 같은 판에 참가한 멤버의 기기 식별값(해시), 설치 ID |
| 게임시간 선택제 | 이용 가능 시간대, 요청자와 이용자의 관계를 확인하는 자료(이메일로 받은 경우) |

회사는 이름, 생년월일, 전화번호, 주소, 이메일을 수집하지 않습니다. 다만 이용자가 문의나 이의 제기를 위해 이메일을 보내면 그 처리에 필요한 범위에서 이메일 주소와 문의 내용을 처리합니다.

기기 식별값은 기기 고유값을 그대로 저장하지 않습니다. 이용자 기기에서 한 번 해시한 값을 서버가 비밀키로 다시 해시하여 저장합니다.

## 제2조 (보유 기간)
회사는 다음 기간이 지나면 개인정보를 지체 없이 파기합니다.

| 항목 | 보유 기간 |
|---|---|
| 채팅 내용 | 보낸 날부터 7일 |
| 신고 증거로 복사한 채팅 줄 | 신고 처리 종결 후 180일 |
| 로그인 기록(IP, 기기 식별값, 설치 ID, 클라이언트 버전) | 90일 |
| 계정별 기기, IP 집계 | 마지막으로 확인된 날부터 180일 |
| 접속 상태 기록 | 접속 종료 후 7일 |
| 시간별 플레이 시간, 획득 집계 | 35일 |
| 만료되거나 폐기된 갱신 토큰 해시 | 30일 |
| 차단 목록 | 차단 해제 후 90일 |
| 친구 관계 | 관계 종료 후 90일 |
| 오류 보고 | 14일 |
| 웹 서버 접속 기록 | 14일 |
| 서버 시스템 로그 | 최대 30일 |
| 파티 판 멤버의 기기 식별값, 설치 ID | 판이 끝난 날부터 30일 |
| 부정 이용 탐지 기록 | 30일(심각한 기록은 180일) |
| 요청 재전송 처리 기록 | 7일(일부 요청은 24시간) |
| 결제 시 IP, 기기 식별값 | 180일 |
| 결제 기록, 재화와 아이템 원장 | 계정이 유지되는 동안, 탈퇴 후에는 마지막 기록일부터 5년(전자상거래 등에서의 소비자보호에 관한 법률) |
| 제재 기록, 신고 기록, 약관 동의 기록 | 계정이 유지되는 동안, 탈퇴 후에는 위 5년 보관 기간과 같이 보관 |
| 게임시간 선택제 설정 | 해제하거나 탈퇴할 때까지 |

## 제3조 (회원 탈퇴 시 처리)
1. 탈퇴를 요청하면 즉시 모든 로그인 토큰을 폐기하고 접속을 끊습니다. 캐릭터 이름은 다른 이용자가 알아볼 수 없는 값으로 바뀝니다.
2. 탈퇴 요청일부터 30일 동안은 탈퇴를 되돌릴 수 있습니다.
3. 진행 중인 이용 제한, 처리 중인 신고나 결제가 있으면 정리될 때까지 익명화를 미룰 수 있습니다. 미루는 기간은 최대 180일입니다.
4. 법령에 따라 보관해야 하는 결제 기록과 재화 원장, 이와 연결된 제재와 신고 기록은 제2조의 기간 동안 분리하여 보관한 뒤 파기합니다.
5. 이용 제한을 피하려는 재가입을 막기 위해, 이용 제한 중에 탈퇴한 경우 Steam ID를 되돌릴 수 없게 변환한 값을 최대 3년 동안 보관합니다.

30일이 지나면 다음과 같이 처리합니다.

- **삭제**: Steam ID 등 로그인 정보, 로그인 토큰, 로그인 기록, 오류 보고, 기기와 IP 집계, 접속 상태, 플레이 집계, 요청 처리 기록, 보내거나 받은 채팅, 이용자가 건 차단
- **익명화**: 다른 이용자의 차단 목록과 신고에 남은 이름, 파티 참가 기록의 기기 정보, 계정과 캐릭터의 접속 시각

## 제4조 (파기 절차와 방법)
1. 보유 기간이 지난 정보는 매일 정해진 시각에 자동으로 파기합니다.
2. 전자 파일은 복구할 수 없는 방법으로 삭제합니다. 종이 문서는 만들지 않습니다.
3. 백업은 암호화하여 보관하며, 백업에 남은 정보는 백업 보관 기간이 지나면 함께 파기합니다.

## 제5조 (제3자 제공)
회사는 이용자의 개인정보를 제3자에게 제공하지 않습니다. 다만 법령에 근거가 있거나 수사기관이 법령에 정한 절차에 따라 요구하는 경우에는 예외로 합니다.

## 제6조 (처리 위탁과 국외 이전)
회사는 서비스 제공을 위해 다음과 같이 개인정보 처리를 맡기거나 국외로 이전합니다.

| 받는 자 | 국가 | 내용 | 항목 | 시기와 방법 |
|---|---|---|---|---|
| Valve Corporation (Steam) | 미국 | 로그인 인증, 결제 처리 | Steam ID, 결제 정보 | 로그인과 결제 때 네트워크로 전송 |
| Google LLC (Google Cloud, 서버 호스팅) | 대한민국(서울 리전)에 저장 | 게임 서버 운영 | 제1조의 항목 전체 | 서비스 이용 중 상시 |
| Supabase Inc. (데이터베이스, AWS 서울 리전) | 대한민국(서울 리전)에 저장 | 데이터 저장 | 제1조의 항목 전체 | 서비스 이용 중 상시 |

서버와 데이터베이스는 국내(서울 리전)에 저장하는 처리 위탁이며, 국외 이전은 Valve Corporation에 대한 전송뿐입니다. 저장 위치를 바꾸면 이 표에 갱신하여 알립니다. 보유 기간은 제2조와 같습니다. 국외 이전을 거부하면 Steam 로그인과 결제를 할 수 없어 서비스를 이용할 수 없습니다.

## 제7조 (이용자 기기에 저장되는 정보)
게임은 이용자의 기기에 다음 정보를 저장합니다. 쿠키는 쓰지 않습니다.

- 로그인 유지용 갱신 토큰(Windows에서는 운영체제 기능으로 암호화하여 저장)
- 접속 서버 주소
- 설치 ID
- 설정(음량, 해상도, 언어, 키 설정, 채팅 친구와 차단 이름)
- 오프라인 저장 파일

게임을 지우거나 저장 폴더를 지우면 이 정보도 지워집니다.

## 제8조 (이용자의 권리)
1. 이용자는 언제든지 자신의 개인정보 열람, 정정, 삭제, 처리 정지를 요구할 수 있습니다.
2. 삭제는 게임 안의 탈퇴 기능으로 할 수 있습니다. 그 밖의 요구는 {{privacy_officer_email}}로 보내면 10일 안에 처리 결과를 알립니다.
3. 법령에 따라 보관해야 하는 정보는 삭제를 요구해도 보관 기간이 지날 때까지 삭제할 수 없습니다.

## 제9조 (만 14세 미만 아동)
회사는 만 14세 미만 아동의 가입을 받지 않습니다. 만 14세 미만 아동이 가입한 사실을 알게 되면 해당 계정의 개인정보를 지체 없이 파기합니다.

## 제10조 (안전성 확보 조치)
회사는 개인정보를 안전하게 처리하기 위해 다음 조치를 합니다.

- 로그인 토큰은 해시값만 저장합니다. 개발용 비밀번호는 argon2id로 해시하여 저장합니다.
- 기기 식별값은 비밀키로 해시하여 저장하고 원래 값은 저장하지 않습니다.
- 데이터베이스 백업은 암호화하여 보관합니다.
- 관리 도구는 역할(조회, 운영, 관리)에 따라 권한을 나누고, 관리자의 모든 작업을 감사 기록으로 남깁니다.
- 서버와 이용자 사이의 통신은 암호화(HTTPS)합니다.

| 항목 | 내용 |
