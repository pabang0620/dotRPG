# 키보드 설정과 강화 표현

## 이용 방법

타이틀 또는 ESC 메뉴의 **키보드 설정**을 연다. 배정된 키 또는 아래 기능 목록을 클릭하고, 새 키를 누르거나 키보드 그림에서 클릭한다. 이미 배정된 키라면 두 기능이 서로 교환된다. **적용**은 설정 파일에 저장하며, **닫기 / 취소**는 적용하지 않은 변경을 되돌린다. **기본값**도 적용 전에 미리 보고 취소할 수 있다.

공격, 이동기, 상호작용, 스킬 5개, 물약 2개, 귀환, 가방, 이동 4방향, 지도를 변경할 수 있다. Esc, Enter, Backspace와 운영체제 전용 키는 고정이다. 기본 방향키 이동, X 공격, QWERT 스킬을 유지한다. 오른쪽 Shift와 Tab은 기본 배치일 때만 보조 키로 동작하며, 다른 기능에 직접 배정하면 보조 동작을 해제한다. 이동 키와 게임패드 축을 분리해 예전 방향키 입력이 남지 않도록 했다. 게임패드 버튼은 기존 설정을 유지한다.

## 스킬과 강화

패시브 노드에는 보석 중심부, 금속 테두리, 큰 노드의 문양, 배운 경로의 발광과 선택 호버를 추가했다. 스킬 수치와 노드 연결은 변경하지 않는다.

강화 시 회전 문양과 모이는 빛, 성공 시 확장되는 링과 별 파편을 사용한다. 실패에는 붉은 파동과 흔들림을 적용한다. 연출은 일시정지 메뉴에서도 재생되며 창을 닫으면 파티클을 정리한다. 확률과 비용은 변경하지 않는다.

장착 무기 효과는 각 캐릭터 자신의 장비 키에서 강화 단계를 읽는다.

| 강화 단계 | 무기 효과 |
|---|---|
| +0 ~ +6 | 없음 |
| +7 ~ +10 | 무기 윤곽을 따르는 푸른 빛 |
| +11 ~ +12 | 푸른 빛 + 오라 + 흐르는 작은 빛 |
| +13 이상 | +11 단계의 오라 유지 |

전사와 마법사 모두 지원한다. 각 무기의 실제 투명도, 피벗, 배율, 좌우 반전과 앞뒤 정렬을 따라가며, 장비 교체/해제·강화 성공 결과가 즉시 반영된다. 재사용 가능한 코드 기반 이미지와 캐시를 사용하며 외부 이미지 다운로드가 필요 없다.

눈꽃 마을 울타리는 첫 마을 당근밭의 연결형 울타리 조각으로 교체했다. 가로/세로/모서리가 같은 연결 규칙을 사용하고 충돌 영역은 유지한다.

## 검증

Unity 6000.5.9f1 정식 Windows 빌드: `DotRPG.EditorTools.BuildScript.BuildWindows`.
출력: `Builds/Windows/dotRPG.exe`.

`dotRPG.exe -batchmode -dotrpgPresentation <출력 폴더>`는 별도의 세이브와 설정 파일로 실행한다. 키 교환, 이동 입력 교체, 대각선 속도, 저장/복원/취소/초기화, 두 직업의 강화 경계값과 8방향 공격 중 효과 정렬, 실제 강화 성공 및 파티클 정리, 울타리를 검사하고 UI/무기 미리보기를 생성한다.

최종 결과: 1280×720 및 1920×1080에서 각각 51개 검사 통과. 두 해상도의 키보드 설정·스킬 트리·강화 연출 캡처를 검수했다.


## 창 단축키 (2026-10-04)
키보드 설정의 **창 열기 · 닫기** 탭에서 HUD 메뉴의 모든 창을 변경할 수 있습니다.
기본값: 가방 I, 지도 M, 스킬창 K, 퀘스트 J, 요일던전 G, 레이드 H,
파티 P, 파티 찾기 O, 경매장 U, 친구 L, 외형 상점 C.
같은 키로 닫거나 다른 창 단축키로 전환합니다. 요일던전/레이드는 해당 탭을 엽니다.
채팅·입력칸 작성 중, 확인 대화상자, 던전 결과창에서는 창 단축키를 처리하지 않습니다.
NPC 상점·강화·창고는 기존 NPC 상호작용을 유지합니다.
검증: 2026-10-05 런타임 C# 컴파일 성공. 기존 플레이어의 별도 테스트 복사본에
수정 DLL을 적용한 Presentation 검사 101개 통과(0 실패), 1280×720 화면 확인.
이번 전체 Unity 빌드는 라이선스 인증 오류(exit 198)로 완료하지 못했으므로
Builds/Windows의 정식 실행 파일은 이전 빌드 상태입니다.
