# 골드 밸런스 (2026-10-16, 무자본은 조금 모자라게)

사용자 기준: "무자본으로 하면 돈이 딱 맞아떨어지기보다 조금 부족해야 한다. 무자본은 클리어하기 힘들어야 하고, 운이 정말 좋으면(전설 둘) 쉽게 깨야 한다. 던전앤파이터처럼."

계산 도구: `Tools/balance/theory_gold.py` (진행 시뮬레이션 `theory_progress.py`의 설계 기준 시나리오, 분당 15마리·하루 2시간·친구와 레이드, Lv40 42.2시간에 얹어 골드를 센다). 이론 계산이며 실측이 아니다.

## 1. 바꾸기 전

Lv40까지 무자본 수입 약 98만 골드, 클리어 한 벌(강화·물약·주문서)에 필요한 돈 약 16만 골드. 수입이 필요 지출의 6.2배라 돈이 의미가 없었다. 강화 골드가 너무 작았다(Lv40 무기 +11 시도 1회 600골드, 사냥 1분 수입이 약 400골드).

## 3. 무자본 수지 (Lv1~40, 이론)

무자본 "클리어 한 벌": Lv10 무기 +7, Lv15 무기 +7·방어구 +5, Lv20 무기 +10·방어구 +7·장신구 +5, Lv30 무기 +10·방어구 +7, Lv40 에픽 무기 +11·에픽 방어구 +10·장신구 +8. 강화 골드는 실패(+10·+11 무기 실패 시 -3)를 포함한 기대값이다. 파괴 구간(+12 이상, 방어구 +10 이상)은 한 벌에 넣지 않았다. 그라흐(Lv40)는 이론상 에픽 무기 +11이면 480초 안팎에 깬다(목표 300~600초).

- 전직 전과 중반은 돈이 남는다(초반 체감은 사용자가 확인한 그대로 두었다). 만렙에 닿는 시점에 한 벌 값의 86%를 들고 있어 그라흐 첫 도전은 무기 +10~+11 사이에서 하게 된다. 만렙 뒤 사냥·레이드를 이어 가면 수입이 지출을 넘는다(전체 기간 비율 1.1).
- +12 이상은 기대 비용이 급격히 는다(Lv40 무기 +11에서 +12 시도 1회 21,000골드, +12에서 +13은 67,200골드에 실패 시 파괴·보호권 3,000). 이 구간이 과금(강화권·보호권 상자)과 운의 몫이다.
- 전설: Lv40 전설 무기는 +0 공격 128로 에픽 +12(95)를 넘고, 전설 방어구도 같은 배율(x3.2)이다. 레이드 장비 카드에서 1%(판당 0.25~0.5%)라 "정말 운이 좋은" 경우이고, 둘 다 끼면 강화 없이 레이드가 쉬워진다.

## 4. 20명 플레이 에이전트 시뮬레이션 (analysis/player-sim v3)

`analysis/player-sim`(20개 페르소나, 시드별 독립 실행, 게임을 돌리지 않는 모델)에 이 경제와 10-14 보상 변경(확정 보상 4장, 유니크 보너스, 레전더리 1%, 레이드 상점, 승급 비용)을 넣고 10시드 x 30일, 5시드 x 90일을 돌렸다. 보고서: `analysis/player-sim/reports/report-dotrpg-v3.md`. 모델 보정: 강화는 접속할 때 골드가 있으면 하는 일상 행동으로(페르소나의 실패 허용도만큼 +10 위 위험 구간을 시도), 레이드 첫 시도는 패턴을 몰라 실패가 잦다가 시도마다 풀리는 것으로 두었다.

| 지표 (무과금 40회 실행, 90일) | 값 |
|---|---|
| Lv40 도달 | 21일째 (중앙값) |
| Lv40 도달 시 보유 골드 | 58만 (중앙값, 10%는 14만) |
| 90일 수입 / 지출 | 173만 / 123만 (강화 108만, 물약 3.4만, 승급·보호권 12만) |
| 골드가 모자라 강화를 못 한 날 | 5.7일 (30일 안에는 0.4일) |
| 끝날 때 무기 | 대부분 +10 (-3 하락 구간 앞에서 멈춤), +11 이상 25% |
| 첫 전설 장비 | 10% (결제 경험 32%) |
| 레이드 상점 전설 구매 | 37일째 (중앙값, 그라흐 일반·심화 주 2회 보상 기준) |
| 쩔 가능(그라흐 심화 90%) | 25일째 |

- 돈이 모자라는 날은 만렙 뒤 +11을 노리는 구간에서 나온다. 조심스러운 페르소나는 +10에서 멈추고 골드를 모아 두며, 밀어붙이는 페르소나는 골드가 바닥난다. 던전앤파이터와 같은 모양이다.
- 전설은 운(레이드 카드 1%)과 긴 프로젝트(상점 60개 = 쩔 가능 시점 뒤 약 2주, 승급 24핵 + 40만)로만 나온다. 바꾸기 전에는 승급(12핵 + 8만)으로 한 달이면 확정이었다.

## 5. 레이드 상점 결정

바꾸기 전 그라흐 레전더리 상자(재료 100)는 보상 주 2회(일반·심화) 기준 5주, 주 1회면 10주였다. "쩔 가능 시점부터 2주 뒤가 종결, 다음 콘텐츠는 2달 뒤" 기준에 맞춰 60개(주 2회 3주, 주 1회 6주)로 내리고, 에픽+ 상자는 20개(1~2주)로 내렸다. 해골왕 상점은 Lv20 장비라 Lv40 전에 손에 오도록 45 / 120(주 3회 보상 기준 1.4주 / 3.8주)으로 내렸다. 시뮬레이션에서 상점 전설은 쩔 가능 시점 뒤 12일 안팎에 온다.
