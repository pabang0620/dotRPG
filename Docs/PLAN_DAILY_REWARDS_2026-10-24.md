# 일일·주간 의뢰 보상 개편: 완료 상자·연속 보너스·강화 재료 상자 (2026-10-24)

## 1. 왜 바꾸나

- 사용자 원문: 일일 퀘 보상이 "있어봤자 하는 보상"이면 안 된다(아주 중요). "랜덤 보상도 주도록 하자, 낮은 확률로 꽤 좋은 게 나오도록, 강화 재료 상자 같은 거 1~100개 랜덤으로", "만렙 때도 할 게 있어야 하긴 하잖아".
- 지금: Lv40 기준 하루 3개를 끝내도 사냥 약 15~20분 경험치, 9분 골드 수준. 만렙은 칸당 3,000골드뿐이라 매일 할 이유가 약하다.
- 방향: 의뢰 칸 보상(경험치·골드)은 그대로 두고, 칸을 다 끝냈을 때 여는 상자를 더한다. 상자 가치는 "골드로 바꾸면 비율이 깨지는 것"이 아니라 "강화 보호권·레이드 열쇠·승급 재료처럼 골드로는 바로 못 사거나 비싼 것"에 둔다.
- 유료 재화(별조각·별의 결정)는 넣지 않는다. 결제 제한도 넣지 않는다.

## 2. 규칙

- 일일 완료 상자: 그 게임 날짜의 일일 의뢰 3칸을 모두 받으면 1번 연다. 어제 칸은 오늘까지 할 수 있으므로(이월 1일) 어제 상자도 오늘까지 열 수 있다.
- 연속 일수: 어제 상자를 열었으면 오늘 상자는 어제 연속 일수 + 1, 아니면 1. 7일 주기로 단계가 정해지고 8일째는 다시 1단계(연속 일수는 8로 계속 센다).
  - 하루 유예: 어제 의뢰를 오늘 끝내고 어제 상자를 열면 이어진다. 오늘 상자를 먼저 열었어도 어제 상자를 늦게 열면 오늘 기록의 연속 일수가 이어 붙는다(오늘 상자 보상은 다시 주지 않는다).
  - 하루를 통째로 놓치면(이틀 전 상자가 마지막) 1단계부터 다시.
- 주간 완료 상자: 주간 의뢰 3칸을 모두 받으면 그 주(목요일 06:00 시작)에 1번.
- 보호권 조각: 10개가 모이면 상자를 열 때 자동으로 장비 보호권 1장이 된다(따로 합치는 화면 없음).
- 강화 재료 상자: 상자에서 아이템으로 나오고 가방에서 열면(서버가 굴림) 마력 정수 1~100개.
- 스킨 선택 게이지: 주간 상자에서 +1칸, 계정당 그 주 1번(부캐릭터로 여러 번 채울 수 없다).
- 만렙 추가분: 상자를 여는 순간 레벨이 levelCap(챕터 3이 닫혀 있으면 40, 열리면 50)이면 더 준다. 3장이 열리면 Lv40은 만렙이 아니므로 추가분이 없고, 50이 되면 다시 받는다.

| 수량 | 구간 확률 | 수량 1개당 확률 |

- 공개: `GET /policies/:lang/probability`(ratesDisclosure "일일·주간 완료 상자" 절), 기동 때 `star_rates_snapshots`에 버전 dailychest-1 내용 저장(같은 버전에 다른 내용이면 기동 거부, 확률을 바꾸면 ratesVersion을 올린다). 굴림 결과는 `sealed_pulls`(source daily_chest, mat_box)에 한 줄씩 남는다.

## 5. 경제 점검 (`Tools/balance/theory_gold.py`)

- 상자 가치를 골드로 셀 때는 판매할 수 있는 것만 판매가로 센다: 강화석 14, 마력 정수 56(재료는 1~40에서 이미 남아서 판다. 강화 비용을 줄이는 몫은 "재료 구매 0"이라 판매가가 곧 그 몫이다), 강화 재료 상자는 마력 정수 기대 9.37개.
- 보호권 조각·장비 보호권·레이드 열쇠 조각·고대의 핵·스킨 게이지는 판매가 0이고, 필요 지출(KIT, 무기 +11까지는 파괴 단계가 없음)에도 들어 있지 않아 비율을 바꾸지 않는다. 대신 +12 이상 도전(선택 지출)의 보호권 구매(잡화점 3,000골드)를 주 약 7,500골드어치 덜어 준다.
- 상자 하나의 판매 환산: 1~7일째 784/784/840/840/896/896/1,694골드(평균 962), 주간 1,239골드.

| 지표 | 바꾸기 전 | 바꾼 뒤 | 목표 |
|---|---|---|---|
| 1~40 수입/지출(`theory_gold.py`) | 0.887 | 0.899 (+22,224골드) | 0.85~0.90 |
| 1~40 미니 던전 매일(`--mini 20`) | 0.82 | 0.84 | 참고 |
| 3장 비율(`--to 50 --mini 20`) | 0.854 | 0.888 | 0.85~0.90 |
| 만렙 일상 하루(Lv40 / Lv50) | 34,427 / 40,996 | 35,566 / 42,135 | 참고 |

- 4장 공개 시점 잔고는 바꾸기 전에도 1,667,694로 4장 범위(1,329,500~1,444,100)를 넘어 있었고 1,794,600이 된다. 4장 설계 때 같이 본다.
- 경험치는 바꾸지 않는다(의뢰 칸 xpShare 그대로, 상자에는 경험치 없음). 1~40 총 46시간 하한 유지.

## 6. 서버

- 데이터: `server/data/daily_quests.json`의 `chests`(서버 정본, data_version 해시 밖). 검증은 `src/gamedata/dailyQuests.ts`(아이템이 items.json에 있는지, 단계 1부터 이어지는지, 재료 상자 구간이 1부터 겹치지 않고 이어지는지, 스킨 게이지는 주간에만).
- 아이템: `frag_protect`(보호권 조각), `box_mat`(강화 재료 상자). 클라이언트 `ConsumableDatabase`가 정본이고 `GameDataExport`가 items.json에 내보낸다(둘 다 캐릭터 귀속).
- 마이그레이션 `0055_daily_chests.sql`: `daily_chests`(PK 캐릭터·기간·날짜 = 기간마다 한 번), item_ledger 사유 `daily_chest`·`fragment_merge`, sealed_pulls 출처 `daily_chest`·`mat_box`.
- API
  - `GET /characters/:uuid/dailies` 응답에 `chests: { day: [...], week, streak: { current, cycle, grace } }`. 일일은 어제 상자(열 수 있거나 연속이 걸린 때만) + 오늘 상자.
  - `POST /characters/:uuid/dailies/chest` `{ request_id, period, day }`: runEconomy(캐릭터 잠금, request_id 재생), 칸 미완료 422 `DAILY_CHEST_LOCKED`, 기간 지남 422 `DAILY_EXPIRED`, 두 번째 409 `DAILY_CHEST_CLAIMED`. 응답 `opened { streak, step, name, grade, rewards[{item_key,count,source}], merged, skin_gauge }` + 전체 목록 + delta.
  - `POST /characters/:uuid/items/open` `{ item_key: "box_mat" }`: 강화 재료 상자. `/items/use`로는 쓸 수 없다(`USE_OPEN_INSTEAD`).
  - 락 순서: 캐릭터 -> 계정 -> 별조각 지갑(스킨 게이지, 봉인된 상자와 같은 순서).
- 테스트: `test/dailyChest.test.ts`(잠김·재생·두 번 열기, 7일 금 상자와 조각 합치기, 유예·끊김·늦게 연 어제 상자, 만렙 추가분, 주간 상자 게이지 계정당 1회, 재료 상자 구간·수량·기록·use 차단, 확률 문서).

## 7. 클라이언트

- `DailyQuestClient`: `chests` 읽기, `OpenChest`. 받을 상자가 있으면 메뉴 알림(AnyActionable/AnyReady)에 포함.
- `DailyQuestScreen`: 탭 아래 상자 줄(상자 이름·완료 칸 수·7칸 연속 표시·연속 일수·유예 안내·내용·"상자 열기"). 일일 탭은 열 수 있는 어제 상자를 먼저 보여 준다.
- 상자 열기 연출은 가방 상자 열기(`CashClient.OpenItem`)와 같다: 장비 보호권·고대의 핵이 나오면 "대박!"과 rank_reveal, 아니면 pickup 소리와 내용 알림. 강화 재료 상자는 50개 이상(희귀 구간)이면 "대박!".
- 번역: `Resources/Data/Lang/<11개 언어>/dailychest.json`, 서버 표는 `i18n.py sync-server`.
