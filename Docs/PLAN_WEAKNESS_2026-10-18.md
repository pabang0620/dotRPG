## 1. 레이드 보상 혼자서도

- 서버 `RAID_REWARD_MIN_HUMANS` 기본값 2 -> 1. 혼자 + AI 동료 3명도 같은 보상(확정 골드, 카드 4장, 전용 재료, 핵, 열쇠). 받는 주기는 그대로(해골왕 열리는 날 하루 1회, 그라흐 주 1회, 심화는 주 1회 따로).
- "연습 입장(보상 없음)" 확인창과 안내 문구에서 인원 조건을 뺀다. 열쇠가 모자란 최종 레이드만 연습 입장이 남는다.
- 사람 파티 보너스(경험치 +15/30/50%)는 그대로라 같이 하면 여전히 이득이다.

## 2. 메인 퀘스트로 콘텐츠 해금 + 튜토리얼

기본(장비 착용, 판매, 창고, 월드맵, 자동 진행, 캐시샵)은 처음부터 열려 있다. 나머지는 메인 퀘스트를 마치면 열린다.

| 콘텐츠 | 여는 메인 퀘스트 | 열릴 때 진행하는 안내 의뢰 |
|---|---|---|
| 강화(대장장이) | 1-7 해골 숲의 흔적 | g_enhance 첫 담금질 |
| 보조 젬 | 1-8 숲길 순찰 | g_gem 스킬 다듬기 |
| 자동 사냥 | 1-8 숲길 순찰 | g_autohunt 사냥의 요령 |
| 요일 던전 | 1-9 이끼 낀 유적의 해골 | 1-10 요일 던전 첫 도전(메인 자체가 튜토리얼) |
| 일반 던전, 파티 찾기 | 1-10 요일 던전 첫 도전 | g_party 함께 가는 길 |
| 경매장, 1:1 교환 | 1-11 검은 뿌리 숲 토벌 | g_auction 경매장 구경 |
| 일일·주간 의뢰, 스킬 스타일 | 1-15 전직의 길 | g_daily, g_style (지금과 같음) |
| 길드 | 1-15 전직의 길 | 없음(팁만) |
| 미니 던전 | 1-11 검은 뿌리 숲 토벌 | 없음(팁만). 따라잡기 때 "할 일"에 뜬다 |
| 레이드 | 1-20 북쪽 고개 성채 수락(해골왕 레이드의 원래 해금 조건과 같게) | 1-20 북쪽 고개 성채(메인 자체) |
| 승급(고대의 핵) | 1-20 북쪽 고개 성채 | 승급 안내 팁 |

- 잠긴 콘텐츠: 메뉴 버튼(PC 사이드 메뉴, 휴대폰 메뉴 시트, 던전 창의 일반·레이드 탭)은 흐리게, 누르거나 단축키·NPC로 열면 창 대신 "메인 퀘스트 1-7 해골 숲의 흔적 완료 후 열려요"라고 알려 준다(`ContentUnlocks.Check`).
- 열리는 순간: "새 콘텐츠: 강화" 알림(토스트) + 한두 줄 설명 팁(같이 열린 것은 한 팁에 묶음) + 안내 의뢰(서브)가 의뢰인 대화 없이 자동으로 수락되고 추적창에 걸린다. 보고는 의뢰인에게 한다. 메인 퀘스트가 안내 역할인 것(요일 던전 1-10, 레이드 1-20)은 원래 대화로 받는다.
- 보조 젬은 보조 젬 칸만 잠긴다(스킬 칸 장착은 처음부터). 스킬 추천 배치가 보조 젬을 끼우는 것은 막지 않는다.
- 자동 사냥은 플레이어가 켜는 것(F7·버튼·성장 추천 버튼)만 잠긴다. 퀘스트·자동 진행이 하는 사냥은 그대로다.
- 1:1 교환은 내가 신청하는 것만 잠긴다(받은 신청은 열린다).
- 자동 실행(검증·측정 모드)과 이야기 꺼짐 세션은 모두 열린 것으로 본다.
- 이미 그 퀘스트를 지난 캐릭터는 처음부터 열려 있다(완료한 퀘스트로 판정).

## 3. "할 일" 바로가기

- HUD 오른쪽 위 "할 일" 버튼(단축키 있음). 누르면 지금 할 수 있는 것을 순서대로 보여 주고, 줄마다 "가기" 버튼으로 그 창을 열거나 그 장소로 이동한다.
- 순서: 메인 퀘스트 이어 하기 -> 새로 열린 콘텐츠 안내 -> 받을 우편·보상 -> 오늘 남은 요일 던전(3회 중 N) -> 레이드 보상(오늘 받을 수 있음) -> 일일·주간 의뢰 -> 강화할 수 있는 장비(골드·재료 충분) -> 성장 추천(사냥터·일반 던전).
- 메인·서브 퀘스트가 레벨 때문에 막혀 있으면 추적창에 "할 일 보기" 안내가 뜬다.
