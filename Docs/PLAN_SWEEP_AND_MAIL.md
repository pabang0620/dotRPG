# 던전 클리어권(소탕)과 보상 우편 설계 (2026-10-06)

## 1. 조사: 다른 게임들의 소탕 방식에서 공통으로 쓰는 규칙

| 규칙 | 흔한 형태 | 이유 |
|---|---|---|
| 해금 조건 | 그 던전·난이도를 직접 깬 기록이 있어야(대개 최고 등급 조건) | 한 번은 직접 하게 해서 콘텐츠·성장 감각을 유지 |
| 횟수 | 하루 입장 횟수를 그대로 소모 | 소탕은 "시간 절약"이지 "수익 증가"가 아니게 |
| 보상 | 기본 보상만, 등급 보너스·첫 클리어·대박 보상 없음, 일부는 드롭률 감소 | 직접 플레이가 항상 더 이득이게 |
| 비용 | 소탕권 1장(+ 일부는 소량 재화) | 무한 소탕 방지, 재화 소모처 |
| 획득처 | 일일·주간 활동, 이벤트, 점검·사과 보상, 재화 상점(주간 한도) | 과금 압박을 피하고 복귀 유저를 돕기 |
| 귀속 | 계정 또는 캐릭터 귀속, 거래 불가, 이벤트분은 기한 | 작업장 거래 방지 |
| 대상 | 개인 반복 콘텐츠만, 협동 레이드·주간 보스는 제외 | 파티 콘텐츠가 비지 않게 |
| 일괄 | 남은 횟수를 한 번에 | 귀찮음 해소가 목적 |

우편 쪽 공통 관행: 운영 보상은 제목·본문·여러 첨부를 담은 "공지 우편", 수령 기한(대개 7~30일), 계정당 1회 지급, 발송 대상 조건(전체·레벨·기간 내 접속자), 발송 전 2인 확인, 지급 기록과 미수령분 회수.

## 2. 클리어권 규칙 (우리 게임)

| 항목 | 규칙 |
|---|---|
| 아이템 | 던전 클리어권(ticket_sweep). 계정 귀속, 경매·판매 불가. 이벤트·우편으로 받은 것은 기한이 있는 별도 아이템(ticket_sweep_event, 받은 날부터 14일) |
| 사용 조건 | 그 요일 던전의 그 난이도를 직접 클리어한 기록이 있고, 그 최고 등급이 B 이상. 캐릭터 레벨이 그 난이도 권장 레벨 이상(입장 여유 -5를 소탕에는 적용하지 않음) |
| 소모 | 클리어권 1장 + 하루 입장 횟수 1회. 남은 횟수만큼 한 번에 쓰는 "모두 소탕" 버튼 |
| 보상 | 클리어 경험치 = 기본값(등급 보너스 없음, B등급 기준). 카드는 4장 중 고르기 대신 무작위 1장, 카드의 장비 확률 70%로. 대박 카드 없음. 처치 경험치·드롭 없음(전투를 안 했으므로) |
| 결과 | 정산 화면에 "소탕" 표시, 받은 경험치와 카드 1장 |
| 제외 | 레이드, 필드 보스, 첫 클리어(난이도 해금), 파티 판 |
| 퀘스트 | "던전 클리어 N회" 목표에는 인정. 난이도 해금에는 불인정 |
| 경제 정지 | 경제 정지(부정 방지) 중인 캐릭터는 소탕 불가 |

직접 플레이 대비 소탕 이득: 시간은 0, 보상은 등급 보너스(최대 +50%)와 대박 카드, 처치 경험치·드롭, 카드 고르기를 포기. 대략 직접 S등급 플레이의 55~65% 수준이 목표다(이론 계산으로 확정).

## 3. 클리어권 얻는 곳

| 경로 | 양 | 비고 |
|---|---|---|
| 잡화점 골드 구매 | 장당 가격 = 기본 1,000골드 x (계정 최고 레벨 단계 + 1), 계정당 주 7장 | 골드 소모처. 주 7장이면 매일 1회만 소탕 가능 |
| 주간 활동 보상 | 요일 던전 직접 클리어 주 10회 달성 시 3장 | "직접 하면 다음 주가 편해지는" 구조 |
| 이벤트·점검·사과 우편 | 운영자가 지정 | 기한 있는 이벤트용 |
| 별조각 상점 | 넣지 않음 | 과금으로 시간 단축을 파는 인상을 피함 |

## 4. 보상 우편(운영 우편) 확장

현재: 관리자가 캐릭터 1명에게 시스템 우편 1통(골드 + 아이템 1종)만 보낼 수 있고, 제목·본문이 없다.

| 기능 | 내용 |
|---|---|
| 공지 우편 | 제목, 본문(줄바꿈 가능), 첨부 최대 5종(골드 포함), 수령 기한(1~30일), 첨부별 귀속 |
| 발송 단위 | 계정당 1통(받을 캐릭터는 계정의 첫 접속 캐릭터, 부캐 곱하기 방지) 또는 캐릭터당 1통(드물게) |
| 발송 대상 | 전체, 조건(레벨 이상, 직업, 가입일, 특정 계정 목록), 기간 내 접속자 |
| 배달 방식 | "캠페인" 한 줄을 만들고, 대상이 접속하면 그때 우편을 만든다(전체 발송 때 수만 건을 한 번에 넣지 않음). 캠페인 기간이 끝나면 더 만들지 않는다 |
| 종류 | 점검 보상, 사과 보상, 이벤트, 출석, 기타 |
| 안전 | 2인 확인(작성자 외 소유자 권한 관리자가 승인해야 발송), 캠페인별 총 지급 상한, 감사 기록, 발송 취소(미수령분 회수), 수령 현황 |
| 화면 | 우편함에 제목·본문·첨부 여러 개 표시, "모두 받기", 기한 표시 |

## 5. 부정 방지와의 연결

- 클리어권과 운영 우편 첨부는 계정 귀속이라 경매로 옮길 수 없다.
- 소탕 보상은 서버가 전부 계산한다(클라이언트가 보내는 전투 값이 없어 오히려 안전).
- 주 7장 구매 한도는 계정 단위, 운영 우편도 계정당 1통이 기본이라 부캐 수만큼 늘지 않는다.
- 경제 정지 중에는 소탕과 우편 수령을 막는다.

## 6. 구현 범위

- 서버: 클리어권 아이템 2종, 소탕 API(단건·모두), 잡화점 주간 한도, 주간 활동 보상, 운영 우편 캠페인 테이블·관리자 API(작성·승인·취소·현황), 우편 다중 첨부.
- 클라이언트: 던전 선택 화면의 "소탕"·"모두 소탕" 버튼과 조건 안내, 소탕 결과 화면, 우편함 제목·본문·다중 첨부·모두 받기, 잡화점 진열.
- 순서: 부정 방지 1단계 구현이 끝난 뒤(같은 서버 파일을 건드림) 서버 설계 -> 구현 -> 점검.
