# 전직 스킬 전면 개편 (2026-10-06)

## 1. 점검 결과 (개편 전)

- 연출 체계가 5겹으로 겹쳐 있었다: 아트 생성기 12개 파일, 시전·판정 파일 5개(Rebuilt·Renewal·Fighter·Guardian·Presentation), 캐릭터 모션 1개, 개발용 캡처 7개, 미리 그린 시트(StreamingAssets 3폴더, Resources/Art/Careers 하위 4폴더), 문서 폴더(Docs/Careers 423MB). 같은 스킬이 여러 갈래로 분기해 무엇이 실제로 그려지는지 추적하기 어려웠다.
- 타격감이 없었다: 전직 스킬 적중에는 히트스톱이 없고, 밀어내기가 1.2로 고정(기본 스킬은 4~10), 시전·적중 소리가 따로 없었고, 화면 흔들림은 일부 스킬에만 있었다.
- 수치 문제:
  - 수호자 각성(천쇄방패)이 반경 6m 1200% 한 방으로 게임 최고 순간 피해였다(탱커가 딜러보다 강함).
  - 비숍 심판의 광창(280%, 4초)이 파이터 첫 스킬 월아검(240%, 4초)보다 셌다.
  - 파이터 스킬 대부분이 범위 공격이라 "빠른 단일·연계 딜러" 정체성이 흐렸다.
  - 시전 후 경직이 길었다(최대 1.1초).
- 그대로 둘 것: 스킬 id 36개와 칸 구조(0·4 패시브, 1~3·5~7 액티브, 8 각성), 해금 레벨(15/18/22, 각성 15), 서버 검증(`careerRules.ts`), 저장 데이터, 각성 시련 조건(파이터 연격, 수호자 도발·흡수, 메이지 화염→얼음→전격, 비숍 정화·회복·흡수), 스킬 아이콘 36장.

## 4. 타격감 규격

- 모든 전직 공격은 한 함수(`CareerCombat.Strike`)로 들어가고 무게 3단계를 가진다.
  - 가벼움: 히트스톱 0.03초, 불꽃 5, 밀어내기 3~4
  - 중간: 히트스톱 0.05초, 불꽃 8, 흔들림 약, 밀어내기 6~7
  - 무거움: 히트스톱 0.08초, 불꽃 12 + 충격 고리, 흔들림 강 + 방향 반동, 밀어내기 9~10
- 히트스톱·흔들림은 시전한 본인 화면에서만 난다. 한 번 휘두름에 여러 마리가 맞아도 히트스톱은 한 번.
- 소리: 시전음(휘두름·마력·방패·종)과 적중음을 스킬마다 정한다. 새 합성음 8종(검 베기, 무거운 일격, 방패 충격, 신성, 얼음 깨짐, 화염 폭발, 낙뢰, 돌진).
- 시전 경직은 0.08~0.3초(각성 0.5초)로 줄인다. 시전 중에는 공격 자세를 취한다.

## 5. 연출 규격

- 기본 스킬과 같은 픽셀 이펙트 도구(SkillFx: 섬광·불꽃·충격 고리·마법진·검기·폭발·번개·운석·얼음)를 직업 색으로 칠해서 쓴다. 미리 그린 시트를 쓰지 않는다.
- 새 픽셀 그림 3종을 이펙트 생성기에 추가한다: 방패 문장(수호자), 깃털(비숍), 빛 십자(비숍).
- 상태 표시: 보호막·보루·결계·축복·성역은 캐릭터 둘레의 색 빛과 방패 문장으로 보인다.
- 각성은 기존 각성 연출(화면 어둡게·이름 띠·빛 폭발)을 쓴다.

## 7. 이론 비교 (랭크 1, 기본 공격력 배수 / 재사용 1초당)

개편 직후의 설계 단계 값이다. 현재 스킬 수치는 3절 표와 `BALANCE_PLAN_2026-10-06.md`가 기준이다.

- 기본 전사 4칸(파쇄 일격·회전 베기·전쟁 함성·돌진 베기) 합 2.15. 파이터 상위 4칸(십자참 1.13·난무 0.49·섬광보 0.47·파쇄 검기 0.46) 합 2.55, 여기에 파죽지세·검기 연성·파쇄 표식이 더해져 전직 보상 +20~35%.
- 수호자 액티브 합은 약 1.0으로 의도적으로 낮다. 대신 기절·도발·보호막을 가진다(기본 스킬과 섞어 쓸 수 있다).
- 메이지 단일 대상 상위 4칸 2.13(기본 마법사 1.92), 무리 상대(3마리)에서는 빙결삼창·홍련구·중력 균열이 2~3배.
- 비숍 공격은 심판의 광창 0.55로 보조 수준. 회복·보호막이 본업.
- 각성 단일 대상: 파이터 15.6(낙검 6자루가 한 대상에 모인 경우), 메이지 13.5, 수호자 5.0(+기절·도발·파티 보호막), 비숍 2.5(+파티 회복·보호막). 예전 수호자 12배 한 방은 없어졌다.
- 몬스터는 맞은 뒤 0.15초 무적이므로 한 스킬의 연속 타격 간격은 0.17초 이상으로 맞췄다.
