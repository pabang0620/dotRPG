# 밸런스 시험 체크리스트 (2026-10-29)

목적: 1레벨부터 키우면서 "느낌"으로 밸런스를 본다. 화면 검증은 사용자가 직접 한다.
계정: admin(어드전사·어드법사·어드도적), darac(다락전사·다락법사·다락도적). 전부 1레벨, 물약 4종 500개씩, 별조각 약 200만(계정 공유).
서버: 시험 서버. 3장은 잠겨 있고 만렙은 40이다.

## 기록 방법
- 구간마다 아래 표를 한 줄씩 적는다: 직업 / 구간 / 막힌 곳 / 죽은 횟수 / 물약 소모 / 체감(쉬움·적당·어려움)
- 숫자를 재지 못하면 체감만 적어도 된다. "이 보스에서 막힘"처럼 위치가 중요하다.

## 1. 직업별 성장 구간 (직업 3개를 같은 구간에서 비교)
- [ ] Lv1~15: 사냥 속도, 첫 전직 전까지 답답함 (이 구간은 이미 맞춰 둔 값이라 크게 어색할 때만 기록)
- [ ] Lv15 전직 직후: 전직 퀘스트가 쉬운지, 전직 뒤 갑자기 강해지거나 약해지는지
  - 전사 2종, 마법사 2종, 도적(어쌔신·닌자) 전직을 각각 한 번씩
- [ ] Lv20 성채, Lv25 눈꽃 마을, Lv31 호숫가, Lv35 봉우리, Lv37 성소: 구간 보스에서 직업별로 막히는 곳
- [ ] Lv40 만렙 도달까지: 직업마다 같은 레벨에서 체감 강함이 비슷한지
- [ ] 직업별 한 줄 평: 어느 직업이 유독 쉽거나 어려운가

## 2. 도적 전용 (새 직업이라 따로 본다)
- [ ] 어쌔신: 근접 사냥 속도, 환영 삼격, 쿠나이 순간이동(Lv18), 변신술(각성)
- [ ] 닌자: 전부 원거리인 점, 분신 버프(60%) 체감, 연막 도약, 표창 난사(각성)
- [ ] 연쇄 도약(쿨 0.5초)과 마력 소모가 사냥 흐름을 끊지 않는지
- [ ] 허수아비(A키, Lv20)가 쓸모 있는지
- [ ] 보스방에서 어쌔신과 닌자 중 한쪽이 지나치게 강하거나 약한지 (측정 봇 결과와 사람 체감이 다른지 확인)

## 3. 장비·강화·재화
- [ ] 장비 드롭 속도: 레벨 구간마다 쓸 만한 장비가 적당히 나오는지
- [ ] 강화: +5, +10 단계에서 실패 체감, 보호권 소모량
- [ ] 골드가 남는지 모자라는지 (구간별로 막히는 시점)
- [ ] 물약: 500개가 어느 구간에서 바닥나는지 (바닥나는 지점이 곧 난이도 신호)
- [ ] 장비 계승(50→55→60 단계)은 만렙 확장 뒤 대상이라 지금은 건너뛴다

## 4. 일일·주간 상자
- [ ] 일일 퀘스트를 몇 개 해야 상자가 나오는지, 보상이 노력에 비해 적당한지
- [ ] 연속 출석에 따른 상자 등급(나무·철·은·금), 재료 상자의 마력 정수 양
- [ ] 만렙 레이드 열쇠 조각(하루 10개)이 부족하지 않은지

## 5. 뽑기·스킨
- [ ] 별조각이 충분하니 천장까지 가 보고, 천장 도달 체감과 합성(희귀 → 에픽 → 유니크 → 전설) 성공률 체감
- [ ] 중복이 쌓일 때 분해·교환이 의미 있는지
- [ ] 스킨 잔상 효과가 등급별로 구분되는지

## 6. 시험 도구 쓰는 법 (일시정지 메뉴 맨 아래 "시험 도구")
- 메인 퀘스트: 한 칸 / 챕터 끝까지
- 경험치: 한 레벨 / 만렙까지
- 전직의 길 퀘스트는 대신 골라 주지 않는다. "챕터 끝까지"가 그 앞에서 멈추면 전직을 직접 하고 다시 누른다.
- 3장이 잠겨 있어 챕터 끝까지는 2장 끝에서 멈춘다.
- 쓰는 요령: 보고 싶은 구간 직전까지 도구로 밀고, 그 구간부터 직접 플레이한다.

## 7. 끝나고 알려 줄 것
- 막힌 구간 목록(직업·위치)
- 너무 쉽거나 어려운 직업
- 재화(골드·물약·재료)가 모자라거나 남은 구간
- 이상한 동작이나 오류(위치와 직업)
