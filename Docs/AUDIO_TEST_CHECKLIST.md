# 오디오 청취 테스트 체크리스트

자동 검증은 끝난 상태다(아래 1절). 2절부터는 사람이 직접 들어야 판단할 수 있는 항목이다.
문제가 있으면 "항목 번호 + 들은 위치 + 느낌"으로 알려 주면 된다. 예: `B-VIL-3 마을, 반복될 때 툭 끊김`.

## 0. 파일 위치

| 무엇 | 위치 |
|---|---|
| 게임에 들어간 BGM | `Assets/Resources/Audio/music_*.ogg` |
| 다시 만들기 | BGM: Flow Music으로 후보 생성(`Tools/audio/bgm_jobs.json`) 후 `Tools/audio/bgm_pick.py --apply`, 사람이 고른 후보는 `Tools/audio/bgm_overrides.json` / 효과음: `python3 Tools/sfx/make_sfx.py --replace` (원본 WAV, 전체 미리듣기, 검증 결과를 `AudioSource/Sfx/`에 다시 만든다) |

선정이 끝난 뒤 게임에 들어가지 않은 후보와 작업 파일(`AudioSource/`)은 지웠다.

## 1. 자동 검증 (완료)

BGM은 곡마다 다음을 수치로 확인했다(`Tools/audio/bgm_loop.py`).

| 항목 | 기준 |
|---|---|
| 템포 | 의도한 BPM과 6% 이내 |
| 박 흔들림 | 박 간격 표준편차 25ms 이하 |
| 대표 멜로디 반복 | 앞 8마디 안의 4마디 멜로디가 곡 안에서 2번 이상 다시 나옴 |
| 루프 일치도 | 루프 끝 다음 두 마디와 루프 시작 두 마디의 화성 유사도 0.8 이상 |
| 이음매 음량 | 루프 끝에서 처음으로 넘어갈 때의 음량 차이가 곡 안 다른 마디 경계보다 3dB 이상 크지 않음 |
| 이음매 클릭 | 끝 샘플과 첫 샘플 차이가 주변 변화량의 40배 이하 |
| 음량 | -14 LUFS, 피크 -1 dBFS 이하, 클리핑 0, 1초 넘는 무음 없음 |

이음매는 첫 한 박을 등전력 크로스페이드로 이어 붙였다. 파일 자체가 끝에서 처음으로 이어지므로 게임은 페이드 없이 그대로 반복한다.

## 2. BGM 공통 (모든 곡에 해당)

각 곡마다 아래 B-공통 항목을 함께 본다.

- B-0-1 처음 10초 안에 흥얼거릴 수 있는 짧은 멜로디가 나오는가
- B-0-2 그 멜로디가 곡 안에서 몇 번 다시 나오는가(한 번만 나오고 사라지면 문제)
- B-0-3 게임을 끄고 나서 그 멜로디가 머리에 남는가(다음 날 기억나는지까지 보면 가장 좋다)
- B-0-4 다른 마을 곡과 섞이지 않고 구분되는가(대표 악기가 들리는가)
- B-0-5 3번 이상 반복해서 들어도 이어지는 곳에서 툭 끊김, 박자 밀림, 음량 튐이 없는가
- B-0-6 이어지는 곳에서 화음이 갑자기 바뀌거나 음이 잘린 느낌이 없는가
- B-0-7 처음이나 끝에 인트로, 엔딩, 페이드아웃이 남아 있지 않은가
- B-0-8 박자가 일정한가(중간에 느려지거나 빨라지지 않는가)
- B-0-9 보컬, 허밍, 가사처럼 들리는 소리가 없는가
- B-0-10 잡음, 찌그러짐, 고음 쇳소리, 저음 웅웅거림이 없는가
- B-0-11 10분 넘게 틀어 놔도 귀가 피곤하지 않은가
- B-0-12 효과음(타격, 줍기, 버튼)이 BGM에 묻히지 않는가
- B-0-13 BGM이 효과음보다 지나치게 크거나 작지 않은가(설정 기본값 BGM 60%, 효과음 80%)
- B-0-14 다른 곡과 비교해 음량이 비슷한가(어느 곡만 유난히 크거나 작지 않은가)
- B-0-15 설정에서 BGM 볼륨을 0, 50, 100으로 바꾸면 바로 반영되는가

## 3. BGM 곡별

### 타이틀 `music_title` (92 BPM, D장조, 플루트)
- B-TTL-1 게임을 켜자마자 나오는가
- B-TTL-2 "모험이 시작된다"는 설렘이 있는가
- B-TTL-3 플루트 멜로디가 앞에 나와 있는가
- B-TTL-4 캐릭터 선택, 로그아웃 후 타이틀로 돌아올 때 다시 이 곡으로 바뀌는가
- B-TTL-5 컷신에서 타이틀 곡을 부르는 장면에서 자연스럽게 바뀌는가
- B-TTL-6 템포가 처지거나 졸리게 들리지 않는가(자동 측정이 의도보다 느리게 나온 곡)

### 첫 마을 `music_village` (72 BPM, G장조, 오카리나·핑거피킹 기타·피아노)
- B-VIL-1 느리고 아련한, 해 질 녘 고향 같은 느낌인가
- B-VIL-2 오카리나 멜로디가 귀에 남는가(가장 오래 듣는 곡이라 가장 중요)
- B-VIL-3 마을에 오래 서 있어도 질리지 않는가
- B-VIL-4 마을 안 건물(상점, 대장간 등)에 들어가도 같은 곡이 끊기지 않고 이어지는가

### 첫 사냥터 `music_forest` (120 BPM, A단조, 피치카토·바순)
- B-FOR-1 장난스럽고 살짝 으스스한 숲 느낌인가
- B-FOR-2 사냥 리듬(타격음 연타)과 템포가 잘 어울리는가
- B-FOR-3 마을에서 사냥터로 나갈 때 1초 크로스페이드로 자연스럽게 바뀌는가
- B-FOR-4 사냥터에서 마을로 돌아오면 마을 곡으로 돌아오는가

### 바위 협곡 마을 `music_canyon` (104 BPM, D 도리안, 마림바·핸드드럼)
- B-CAN-1 건조하고 햇빛 강한 협곡 느낌인가
- B-CAN-2 마림바, 북 소리가 첫 마을과 분명히 다른가
- B-CAN-3 협곡 사냥터와 침수된 고대 성소, 성소 심층에서도 이 곡이 나온다. 성소 분위기에도 어색하지 않은가(어색하면 성소 전용 곡을 따로 만든다)

### 눈꽃 숲 마을 `music_winter` (88 BPM, E플랫장조 3/4 왈츠, 오르골·첼레스타)
- B-WIN-1 3박자 왈츠로 들리는가
- B-WIN-2 오르골, 첼레스타가 눈 내리는 느낌을 주는가
- B-WIN-3 너무 졸리거나 처지지 않는가
- B-WIN-4 3박자 곡이라 이어지는 곳에서 박이 한 칸 밀리지 않는가(특히 주의)
- B-WIN-5 게임에서 3번 이상 반복될 때 이어지는 곳에서 소리가 갑자기 커지거나 작아지지 않는가(자동 검증에서 유일하게 이음매 수치가 기준을 넘은 곡)

### 협곡 던전 `music_dgn_canyon` (128 BPM, C단조, 금관 리프·타이코)
- B-DCA-1 긴장감 있고 힘찬가
- B-DCA-2 금관 리프가 반복되며 기억에 남는가
- B-DCA-3 방에서 방으로 넘어갈 때 곡이 처음부터 다시 시작되거나 끊기는지 확인(같은 곡이면 그대로 이어져야 함)

### 숲 던전 `music_dgn_forest` (112 BPM, B단조, 하프시코드·오르간)
- B-DFO-1 오래된 성 같은 신비롭고 어두운 느낌인가
- B-DFO-2 하프시코드 멜로디가 반복되는가
- B-DFO-3 협곡 던전, 눈꽃 던전과 확실히 구분되는가

### 눈꽃 던전 `music_dgn_winter` (132 BPM, F#단조, 크리스털 벨)
- B-DWI-1 차갑고 빠른 긴장감이 있는가
- B-DWI-2 벨 소리가 날카롭거나 귀를 찌르지 않는가

### 보스 `music_boss` (150 BPM, E단조)
- B-BOS-1 보스방에 들어가면 바로 바뀌는가
- B-BOS-2 앞 방 곡보다 확실히 더 긴박한가
- B-BOS-3 보스 경고음(enemy_windup)이 BGM에 묻히지 않는가

### 레이드 `music_raid` (140 BPM, C단조, 호른)
- B-RAI-1 일반 보스 곡보다 웅장한가
- B-RAI-2 여러 명이 싸우는 큰 전투 느낌인가

### 레이드 광폭화 `music_raid_enrage` (165 BPM)
- B-ENR-1 보스가 광폭화하는 순간 바뀌는가
- B-ENR-2 바뀌는 1초 동안 박이 엉키거나 소리가 겹쳐 지저분하지 않은가
- B-ENR-3 "이제 위험하다"는 느낌이 확실한가
- B-ENR-4 보스를 잡거나 전멸하면 클리어/실패 곡으로 바뀌는가

### 클리어 `music_clear` (112 BPM, C장조)
- B-CLR-1 던전 클리어 순간 바뀌는가
- B-CLR-2 클리어 효과음(dungeon_clear 팡파레)과 겹쳐도 지저분하지 않은가
- B-CLR-3 결과 화면에 오래 있어도 반복이 자연스러운가
- B-CLR-4 결과 화면을 닫으면 마을/필드 곡으로 돌아오는가

### 실패 `music_fail` (76 BPM, A단조, 피아노)
- B-FAL-1 아쉽지만 너무 우울하지 않은가
- B-FAL-2 쓰러짐 효과음(player_down)과 겹쳐도 괜찮은가
- B-FAL-3 결과 화면을 닫으면 마을/필드 곡으로 돌아오는가

## 4. 전환과 상황

- B-TR-1 마을 → 사냥터 → 다음 사냥터 → 다음 마을로 이동하면서 곡이 맞게 바뀌는가
- B-TR-2 같은 곡을 쓰는 맵끼리 이동할 때 곡이 처음부터 다시 시작되지 않는가
- B-TR-3 귀환 주문서로 순간이동할 때 곡이 바로 바뀌는가
- B-TR-4 던전 입장, 방 이동, 보스방, 결과, 퇴장까지 한 번 끝까지 들어보기
- B-TR-5 던전 중간에 포기/퇴장하면 원래 맵 곡으로 돌아오는가
- B-TR-6 필드에서 죽고 부활할 때 곡이 끊기거나 다시 시작되지 않는가
- B-TR-7 던전에서 죽고 부활 코인으로 부활할 때 곡이 끊기지 않는가
- B-TR-8 컷신 시작과 끝에서 곡이 자연스럽게 바뀌는가
- B-TR-9 창(인벤토리, 상점, 설정)을 열고 닫아도 곡이 끊기지 않는가
- B-TR-10 게임 일시정지 중에도 곡이 이상하게 멈추거나 튀지 않는가
- B-TR-11 창을 내렸다가(alt+tab) 다시 올렸을 때 곡이 정상인가
- B-TR-12 빠르게 맵을 여러 번 오갈 때 두 곡이 겹쳐 남지 않는가

## 5. 효과음

자동 검증은 끝났다. 각 효과음마다 아래 E-공통을 함께 본다.

- E-0-1 게임 화면에서 일어나는 일과 소리가 맞는가
- E-0-2 연타해도 귀가 아프거나 지저분하게 쌓이지 않는가(타격, 줍기, 대화 글자, 메뉴 이동은 특히)
- E-0-3 소리가 늦게 나오지 않는가(누르는 순간 바로)
- E-0-4 다른 효과음보다 혼자 너무 크거나 작지 않은가
- E-0-5 매번 똑같이 들려 기계적이지 않은가(재생할 때마다 음 높이가 살짝 달라진다)
- E-0-6 장면이 끝난 뒤에도 소리가 길게 남아 거슬리지 않은가

형식: 번호 - 키 - 들리는 곳 - 의도한 느낌

### 전투
- E-1 hit - 적이 기본 공격이나 스킬에 맞을 때 - 짧고 단단한 타격, 낮은 퍽 위에 밝은 딱
- E-2 swing - 근접 기본 공격, 수호자 돌진 - 가벼운 바람 소리, 타격음보다 작게
- E-3 enemy_attack - 적이 공격을 휘두를 때 - 둔하고 낮은 휘두름
- E-4 enemy_windup - 보스가 큰 공격을 준비할 때 - 올라가며 떨리는 경고음, 피해야 한다는 신호가 분명할 것
- E-5 hurt - 플레이어가 맞았을 때 - 둔한 충격에 귀여운 "윽" 하강음
- E-6 enemy_die - 적 처치 - 펑 터지는 시원한 처치음(사냥 손맛에서 가장 중요)
- E-7 몬스터 여러 마리를 한 번에 잡을 때 처치음이 겹쳐도 시원한가
- E-8 타격음과 처치음이 거의 동시에 날 때 처치음이 묻히지 않는가

### 스킬
- E-10 magic - 원거리 기본 공격(마법 탄) - 부드럽고 밝은 지잉, 자주 들려도 피곤하지 않을 것
- E-11 c_slash - 전사 베기 - 날카로운 칼날 "싱"
- E-12 c_heavy - 강타, 내려찍기, 대지 충격 - 묵직한 저음 쾅
- E-13 c_dash - 전사 돌진 - 빠르게 지나가는 바람
- E-14 c_shield - 수호자 방패 치기, 방패 날리기 - 금속판 땡과 둔한 충격. 방패 3개 이상을 연달아 날릴 때도 괜찮은가
