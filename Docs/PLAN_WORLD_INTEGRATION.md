## 3. 지역 설정 (이야기와 맞추기)

- 협곡의 암석 골렘: 수호석의 힘이 새어 나와 깨어난 바위. 바위 심장 골렘(2장 중간 레이드)의 권속이다. 흑철 진영(바르가스)은 이 골렘을 부려 채석장을 점령했다.
- 설원의 설산 예티: 성소의 봉인이 녹으며 흘러나온 기운에 미쳐 사람을 공격한다.
- 성소 석상: 고대 성소를 지키는 석상. 누가, 무엇을 봉인했는지는 4장(눈꽃 숲의 지워진 역사)에서 밝혀진다. 이번에는 복선만 둔다(용사와 마족이 함께 새긴 듯한 문장).
- 숲의 해골 군단, 레이드·던전의 해골 보스는 그대로다.

## 5. 스킬 이펙트 고해상도

- 지금 이펙트 그림은 1칸 16픽셀(캐릭터보다 거칠다). 같은 크기에서 4배 촘촘한 그림(Density 4, 1칸 64픽셀)으로 다시 그린다.
- 기본 스킬과 전직 스킬이 같은 그림 키(fx_*)를 쓰므로 한 번에 모두 좋아진다. 화면 크기·타이밍·게임 판정은 바뀌지 않는다.
- 대상: 빛, 충격 고리, 마법진, 회오리, 전격, 칼날, 서리, 균열, 가시, 얼음, 파편, 눈, 불꽃, 줄기, 베기, 초승달·검기 호, 거대한 검, 빙뢰구, 불길, 운석, 그을음, 별, 방패 문장, 깃털, 빛 십자, 고리 등.
- 원칙: 도트 느낌은 유지(점 단위, 외곽선, 색 단계), 대신 색 단계·하이라이트·세부 무늬를 늘린다. 빛 계열은 부드러운 단계 그라데이션.
