# 영어 용어집

번역은 이 표를 따른다. `Tools/i18n/i18n.py check`가 표의 한국어가 들어간 문장인데 영어 쪽에 해당 단어가 없으면 알려 준다. 고유명사 전체(아이템·몬스터·스킬 이름)는 `Assets/Resources/Data/Lang/en/names.json`이 정본이다.

## 문체
- UI 버튼·메뉴: 짧은 명령형, 첫 글자 대문자 ("Back", "Enhance", "Buy"). 마침표 없음.
- 안내·확인 문장: 평서문, 존댓말 대신 담백한 2인칭 ("You can't equip this.", "Restart the game to apply.").
- NPC 대사: 판타지 RPG 구어체. 캐릭터 말투 차이는 살린다.
- 숫자 단위: 초 `s`, 미터 `m`, 퍼센트 `%`, 골드 `G`, 레벨 `Lv.`
- 이름에 조사가 붙던 자리(`을(를)`, `이(가)`)는 영어 문장으로 다시 쓴다.
