## 효과음 청취 체크리스트

원본 WAV는 `AudioSource/Sfx/<key>.wav`, 게임에 들어가는 파일은 `Assets/Resources/Audio/<key>.ogg`다. 전체를 한 번에 들으려면 `AudioSource/Sfx/_preview_all.wav`(분류 순서: 전투, 스킬, 월드, UI, 징글. 분류 사이에 작은 삐 소리 두 번)를 재생한다. 다시 만들려면 `python3 Tools/sfx/make_sfx.py --replace`, 검증 결과는 `AudioSource/Sfx/report.txt`.

형식: 키 - 게임에서 들리는 곳 - 의도한 느낌

### 전투
- hit - 적이 기본 공격이나 스킬에 맞을 때 - 짧고 단단한 타격, 낮은 퍽 소리 위에 밝은 딱 소리
- swing - 근접 기본 공격을 휘두를 때, 수호자 돌진 - 가벼운 바람 가르는 소리, 타격음보다 작게 깔림
- enemy_attack - 적이 공격을 휘두를 때 - 둔하고 낮은 휘두름, 살짝 으르렁
- enemy_windup - 보스가 큰 공격을 준비할 때 - 올라가며 떨리는 경고음, 피해야 한다는 신호가 분명할 것
- hurt - 플레이어가 맞았을 때 - 둔한 충격에 귀여운 "윽" 하강음
- enemy_die - 적을 처치했을 때 - 펑 하고 터지는 시원한 처치음, 짧은 연기와 반짝임

### 스킬
- magic - 원거리 기본 공격(마법 탄) - 부드럽고 밝은 지잉, 자주 들려도 귀가 피곤하지 않을 것
- c_slash - 전사 베기 스킬 시전과 적중 - 날카로운 칼날 "싱", 금속 울림이 살짝 남음
- c_heavy - 강타, 내려찍기, 대지 충격 계열 - 묵직한 저음 쾅, 파편이 흩어지는 느낌
- c_dash - 전사 돌진 - 좌에서 우로 빠르게 지나가는 바람
- c_shield - 수호자 방패 치기 - 금속판이 땡 하고 울리는 소리, 아래에 둔한 충격
- c_arcane - 비전 마법(구체, 장판, 끌어당김) - 위로 솟는 바람과 신비로운 반짝임
- c_fire - 화염 마법 - 화르륵 점화, 포효하는 불길, 탁탁 튀는 불꽃
- c_ice - 얼음 마법 - 쩍 갈라지는 소리 뒤 유리 파편처럼 맑게 반짝임
- c_thunder - 번개 마법 - 지직거리는 전기, 날카로운 번쩍 소리, 짧은 우르릉
- c_holy - 성직자 보호막, 신성 공격 - 맑은 종소리 두세 개와 은은한 빛 번짐
- heal - 회복 스킬, 회복 아이템 - 부드럽게 올라가는 장조 화음, 포근한 반짝임

### 월드
- chop - 나무 베기 - 도끼가 나무에 박히는 통 소리, 나무 조각
- mine - 광석 캐기 - 곡괭이가 돌에 부딪히는 쨍 소리와 돌 부서짐
- tree_fall - 나무가 쓰러질 때 - 삐걱이는 줄기, 잎 스치는 소리, 마지막에 쿵
- rock_break - 바위가 부서질 때 - 와르르 무너지는 자갈, 낮은 쿵
- pickup - 아이템, 골드 줍기, 판매 성공 - 밝은 두 음 띠링, 금속성 반짝임
- pluck - 작물 수확 - 쏙 뽑히는 퐁 소리와 흙, 잎 바스락
- deliver - 건설 재료 납품 - 따뜻한 나무 실로폰 세 음 상행
- hammer - 건설 중 망치질 - 못에 맞는 쨍과 나무 통 소리
- door_open - 던전 문 열림 - 걸쇠 철컥, 무거운 문 삐걱, 바닥에 닿는 둔한 쿵

### UI
- blip - 대화 글자가 찍힐 때 - 아주 작고 동그란 톡, 연타되어도 거슬리지 않을 것
- select - 메뉴 이동, 버튼 선택 - 가볍고 부드러운 딸깍
- confirm - 확인, 성공 응답 - 밝은 두 음 상행, 기분 좋은 긍정
- cancel - 취소, 실패 응답, 창 닫기 - 둥글고 차분한 두 음 하행, 꾸중처럼 들리지 않을 것
- card_flip - 보상 카드 뒤집기 - 종이를 튕기는 착 소리와 짧은 휙

### 징글
- player_down - 플레이어 쓰러짐 - 털썩 뒤 슬픈 세 음 하강, 너무 무겁지 않게
- build_complete - 건물 완성 - 망치 한 번 뒤 장조 아르페지오와 종 화음
- enhance_charge - 강화 진행 중 - 점점 빨라지며 올라가는 긴장감, 결과 직전에 끊김
- enhance_success - 강화 성공 - 밝은 딩과 빠른 상행 아르페지오, 반짝임
- enhance_great - 강화 대성공 - 성공보다 확실히 큰 쾅과 두 옥타브 상행, 큰 종 화음과 쏟아지는 반짝임
- enhance_fail - 강화 실패 - 바람 빠지는 두 음 하강, 아쉽지만 짧게
- enhance_break - 강화 실패로 장비 파괴 - 유리와 금속이 깨지는 소리, 쿵, 하강하는 한숨
- dungeon_clear - 던전 클리어 - 금관 팡파레와 팀파니, 심벌 울림
- rank_reveal - 던전 결과 랭크 도장, 필드 보스 등장, 뽑기 고등급, 강화권 결과, 큰 보상 획득 - 스네어 롤이 올라가다 쾅 터지는 공개음
- quest - 퀘스트 완료, 보상 수령, 뽑기 최고 등급 - 밝은 종소리 장조 아르페지오
- ending - 엔딩 - 경쾌한 멜로디와 따뜻한 화음, 마지막에 반짝임
