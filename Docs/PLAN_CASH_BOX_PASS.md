# 봉인된 상자(확률형)·강화권·성장 패스 계획

근거 계산: `Tools/balance/theory_cash.py` (별조각 300개 = 1,100원, 상자 1회 = 별조각 100개 ≈ 366원).

## 1. 목표

| 목표 | 기준 |
|---|---|
| 최고점 | 6부위 레전더리 +15 이상. 기대 비용 약 1,000만 원(강화권 약 750만 원 + 레전더리 장비) |
| 무과금에 가까운 클리어 | 성장 패스(약 3만 3천 원) 하나로 모든 던전·레이드를 깰 수 있는 +10~12 장비 |
| 편차 | 같은 금액이라도 결과 차이가 크다. 3,000회(약 110만 원) 열었을 때 +15를 한 장도 못 얻는 사람이 약 47%, 상위 10%는 2장 이상 |
| 최저 보상 | 기본 물약보다 좋은 상급 물약 묶음이나 30분 공격 버프 |

## 2. 봉인된 상자

캐시샵 새 배너. 1회 별조각 100, 10+1회 1,000. 열면 바로 아래 표에서 하나가 나온다.

| 보상 | 확률 | 등급 |
|---|---|---|
| 상급 체력·마나 물약 5개 (HP/MP 70% 회복) | 36.158% | 일반 |
| 투지의 주문서 (30분 동안 공격 피해 +15%) | 27.624% | 일반 |
| 마력 정수 10개 | 12.75% | 일반 |
| 장비 보호권 1장 | 8.5% | 일반 |
| 장비 보호권 3장 | 6% | 희귀 |
| +10 강화권 상자 (30%) | 4.5% | 희귀 |
| +10 강화권 | 2.4% | 희귀 |
| +12 강화권 상자 (10%) | 1.2% | 영웅 |
| +12 강화권 상자 (50%) | 0.55% | 영웅 |
| +12 강화권 | 0.2% | 전설 |
| +13 강화권 | 0.08% | 전설 |
| +15 강화권 상자 (50%) | 0.03% | 신화 |
| +15 강화권 | 0.008% | 신화 |

- **확률 상자** "+N 강화권 상자 (P%)": 열면 P% 확률로 +N 강화권, 아니면 마력 정수 20개.
- **부스터 (봉인 해제 게이지)**: 상자를 10회 열 때마다 게이지가 차고, 다음 1회는 부스터로 열린다.
  - 희귀 이상 확률이 2배가 되고, 일반 등급 확률은 그만큼 줄어든다.
  - 나온 보상의 수량도 2배다.
  - 게이지는 계정별로 서버가 저장한다.
- 확정 지급(천장)은 두지 않는다.

기대값: +10 강화권 약 21회(약 7,700원), +12 약 132회(약 4만 8천 원), +13 약 980회(약 36만 원), +15 약 3,400회(약 125만 원).

## 3. 강화권

| 아이템 | 효과 |
|---|---|
| +10 / +12 / +13 / +15 강화권 | 고른 장비 하나의 강화 단계를 그 단계로 바로 올린다. 이미 같거나 높으면 쓸 수 없다. 실패·파괴 없음 |

- 쓰는 곳은 대장간(강화 창)이다. 장비를 고른 뒤 "강화권 사용"을 누른다.
- 장비 레벨과 등급 제한은 없다. 단, 장비 귀속 규칙은 지금 규칙을 그대로 따른다.
- +16 이상은 강화권이 없다. 지금처럼 직접 강화(실패 시 파괴, 보호권)로만 올린다. 그 이상이 진짜 최고점 경쟁 구간이다.

## 4. 새 소모품

| id | 이름 | 비고 |
|---|---|---|
| potion_hp_hi / potion_mp_hi | 상급 체력·마나 물약 | 70% 회복. 기본 물약 단축키에서 기본 물약보다 먼저 쓴다 |
| scroll_power | 투지의 주문서 | 30분 동안 공격 피해 +15%. 같은 버프는 시간만 갱신 |
| ticket_enh10 / 12 / 13 / 15 | 강화권 | 3절 |
| box_enh10_30 / box_enh12_10 / box_enh12_50 / box_enh15_50 | 확률 상자 | 가방에서 사용 → 서버가 결과를 정한다 |

## 5. 성장 패스

- 가격: 별조각 9,000개(약 3만 3천 원), 계정당 1회, 기간 없음.
- 레벨 보상 창에 "패스 보상" 줄이 추가된다. 무료 보상(지금의 별조각)은 그대로 두고, 패스를 사면 같은 단계에서 패스 보상을 함께 받는다.
- 현재 캐릭터가 이미 달성한 단계는 패스를 사면 바로 받을 수 있다. 같은 계정의 다른 캐릭터 레벨은 수령 조건에 쓰지 않으며, 단계별 지급 횟수는 계정당 한 번이다.

| 수령 캐릭터 레벨 | 패스 보상 |
|---|---|
| 5 | 봉인된 상자 5개 |
| 10 | +10 강화권 1장, 봉인된 상자 5개 |
| 15 | 장비 보호권 5장 |
| 20 | +10 강화권 2장 |
| 25 | 봉인된 상자 10개 |
| 30 | +12 강화권 상자(50%) 1개 |
| 35 | 봉인된 상자 10개, 장비 보호권 5장 |
| 40 | +12 강화권 1장, 봉인된 상자 20개 |

기대 가치는 약 11만 원으로, 가격의 약 3.5배다. 상자 50개, +12 1장과 +12(50%) 1개, +10 3장, 보호권 10장이 들어 있다.

"봉인된 상자 N개"는 가방에 들어가는 상자 아이템이다. 쓸 때 캐시샵과 같은 표로 서버가 연다. 부스터 게이지도 함께 찬다.

## 6. 서버 (14단계)

| API | 내용 |
|---|---|
| POST /starshop/sealed/pull | {request_id, count 1 \| 11}. 별조각 차감, 부스터 게이지 반영, 결과 지급 |
| GET /starshop/sealed | 확률표, 부스터 게이지 |
| POST /characters/:id/items/open | {request_id, item_key}. 확률 상자·봉인된 상자 아이템 열기 |
| POST /characters/:id/enhance/ticket | {request_id, ticket_key, gear_key}. 강화권 적용 |
| POST /level-rewards/pass/buy | {request_id}. 별조각 9,000 차감, 계정 패스 기록 |
| GET /characters/:uuid/level-rewards | 현재 캐릭터 레벨에 따른 무료·패스 수령 가능 여부, 계정 수령 기록 |
| POST /characters/:uuid/level-rewards/pass/claim | {request_id, level}. 해당 캐릭터 레벨 검사 후 패스 보상을 그 캐릭터에게 지급 |

- 공통 규칙: 모든 결과를 서버가 정하고, request_id 멱등, 원장 기록, 재화 홀드·유료분 차감 순서는 11단계 규칙을 따른다.
- 확률표는 `server/data/sealed_box.json`에 두고, 클라이언트 확률 보기 창에 그대로 보여 준다.

## 7. 클라이언트

- 캐시샵: "봉인된 상자" 배너, 1회와 10+1회 버튼, 부스터 게이지(10칸), 확률 보기.
- 가방: 상자 아이템 "열기", 강화권 "사용"(대장간으로 이동).
- 대장간: 강화권 사용 버튼. 보유한 강화권 중 지금 장비보다 높은 것만 보인다.
- 레벨 보상 창: 패스 구매 버튼과 패스 보상 줄.
- 투지의 주문서 버프 아이콘과 남은 시간.
