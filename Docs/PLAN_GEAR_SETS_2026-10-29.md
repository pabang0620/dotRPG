# 장비 세트 효과 (2026-10-29)

사용자 결정(2026-10-29): 같은 레벨 단계 장비를 무기·상의·하의·목걸이·반지 5부위에 모으면 세트, 등급은 섞여도 된다, 단계는 2·3·5부위, 계승(`^k`)·히든(`~x`) 장비는 계승 뒤 단계로 센다.

## 1. 규칙

- 세트가 있는 단계: Lv.20, 25, 30, 35, 40, 45, 50(levelTier 3~9). Lv.1·10·15는 세트가 없다(1~15 피해는 손으로 맞춘 값이라 그대로 둔다).
- 부위: 무기·상의·하의·목걸이·반지. 반지 두 개가 같은 단계여도 1부위다. 부위마다 그 단계에서 가장 높은 등급 한 개를 센다.
- 크기: 센 부위들 중 가장 낮은 등급. 단계는 쌓인다. 단계가 다른 세트 둘(예: Lv.40 2부위 + Lv.50 3부위)은 각각 켜지고 더한다.
- 적용: %는 착용 장비의 공격력 합·체력 합에 곱한다(캐릭터 기본 공격력·레벨 체력에는 곱하지 않는다). 히든 옵션(피해 x1.3, 체력 x1.3)이 들어간 합에 곱한다.
- 보스 전용 장신구(뿌리 반지 Lv.10, 바위 심장 목걸이 Lv.20, 서리 리치 반지 Lv.35)도 그 단계로 센다.

## 2. 수치(%)

| 가장 낮은 등급 | 2부위 | 3부위 | 5부위 | 5부위 합 |
|---|---|---|---|---|
| 커먼~레어 | 체력 +3 | 체력 +3 | 체력 +4 | 공격 0, 체력 10 |
| 에픽 | 체력 +5 | 공격 +5 | 공격 +5, 체력 +5 | 공격 10, 체력 10 |
| 유니크 | 체력 +6 | 공격 +6 | 공격 +6, 체력 +6 | 공격 12, 체력 12 |
| 레전더리 | 체력 +7 | 공격 +7 | 최종 공격력 +30% | 공격 7, 체력 7, 최종 x1.3 |

최종 공격력(2026-10-30 사용자 결정): 레전더리 5부위 단계는 장비 합이 아니라 캐릭터 공격력 전체(기본 + 장비, 스킬 피해 포함)에 x1.3을 곱한다. 클라이언트 `CharacterStatsCalc.BaseAttack`, 서버 `attackCap`·`computePower`의 공격 항에 같은 배율.

커먼~레어에 공격을 주지 않은 이유: 플레이 시간(23.5시간, 1~40 44.9시간)은 같은 단계 레어 한 벌을 낀 사냥 실측으로 잡았다. 여기에 공격이 붙으면 처치 속도가 빨라져 시간이 줄어든다(아래 계산). 체력은 처치 속도를 바꾸지 않는다.

## 3. 계산 (`Tools/balance/theory_sets.py`)

피해 증가 = (10 + 장비 공격 x (1 + 공격%)) / (10 + 장비 공격) - 1. 체력 증가는 전사(파이터 x1.1) 최대 체력 대비.

| 장비 한 벌 | Lv.40 피해 / 체력 | Lv.50 피해 / 체력 |
|---|---|---|
| 사냥 실측(레어 +5) | 0 / +3.2% | 0 / +3.5% |
| 클리어 KIT(에픽 무기 +11·방어구 +10, 장신구 레어 +8) | 0 / +4.2% | 0 / +4.5% |
| 레이드·보스 방 실측(에픽 +5) | +9.2% / +3.9% | +9.4% / +4.2% |
| 유니크 +10 | +11.5% / +6.8% | +11.6% / +7.1% |
| 레전더리 +10 | +38.8% / +4.4% | +38.9% / +4.6% |

- 플레이 시간: 사냥 실측 장비(레어)는 피해 0이라 처치 속도·총 시간이 그대로다. 에픽 한 벌로 사냥하면 무리 처치 시간(전투 5.7초 + 이동 4초)이 5.0% 줄지만, 에픽 장신구까지 다 맞춘 경우만이고 실측 기준은 바뀌지 않는다.
- 요일 던전: 군주 실측 최단 133초를 에픽 한 벌로 보아도 133 / 1.092 = 122초라 목표 하한 120초 안이다(실측 장비는 레어라 실제로는 그대로).
- 보스 방 직업 비율(목표 70~100%): 모든 직업이 같은 배율을 받는다. 기본 공격 10의 몫 차이만 남아 1%p 안이다.
- 레이드 클리어율(목표 절반 이상, 지바크 58%·카마츠 50%): 에픽 +5 실측 장비가 피해 +9%, 체력 +4%를 받아 오르는 쪽이라 목표를 해치지 않는다.
- 서버 상한 사용률(실측 최대 0.55, 경고 0.8): 상한도 같은 배율로 넓혀서 변하지 않는다.
- Lv.1~15: 세트 없음, 값 변화 0.
- 레전더리 한 벌(+38.8%)은 측정 장비보다 위라 목표 표에 들어가지 않는다. 상한이 같이 넓어져 서버 판정은 걸리지 않는다.

## 4. 서버

- `utils/gearSet.ts` `setBonusOf(eco, wornKeys)`: C#와 같은 표. 장비 정의의 `levelTier`·`rarity`·`category`만 쓰므로 데이터 내보내기 변경은 없다.
- `killRules.attackCap`: 장비 공격 합 x (1 + 세트 공격%), 올림(클라이언트는 반올림). 최종 공격력은 결과 전체 x (1 + 30%). 처치·던전(runAttackCap)·파티·필드 세션·보스 러시·미니 던전 상한이 모두 이 함수를 쓴다.
- `powerEstimate.computePower`: 장비 공격 합·체력 합에 세트 %.

## 5. 화면

- 장비 툴팁(가방·경매·상점·보관·뽑기·보상 카드 모두 `GearTooltip`): 히든 옵션 줄 아래 "세트 효과 (3/5)"와 Lv·기준 등급, 단계 세 줄(켜진 단계 초록, 꺼진 단계 회색). 착용한 부위가 없으면 그 장비 등급 기준으로 보인다.
- 가방 창: 능력치 상자 위 한 줄 "세트 Lv.40 (5/5): 장비 공격력 +10%, 장비 체력 +10%", 없으면 "세트 효과 없음". 공격력 칸의 (+장비)와 HP는 세트를 반영한 값이다.

## 7. 스킬 범위 상향 (2026-10-30)

사용자 결정: 무기 유니크 5 -> 20, 레전더리 광역형 30 -> 50(토벌형 6은 그대로). 반지 유니크 8 -> 10, 레전더리 14 -> 20. 목걸이·상의·하의(갑옷·로브·각반·치마) 새로 유니크 +5, 레전더리 +10. 원본 `GearCatalog.Make`·`Archetype`, `server/data/shop.json`의 `aoeBonus`는 Unity 내보내기를 다시 돌려야 바뀐다(서버는 이 값을 판정에 쓰지 않는다).

- 적용: 반지름 = 기본 x sqrt(1 + 범위%)(`CharacterStatsCalc.Skill`). 서버 화력 상한에는 들어가지 않고, 한 타에 맞는 수는 서버 `AOE_CAP`(5, 확산형 특화 8)이 막는다. 레전더리 광역형은 전에도 무리 6마리를 다 맞혔으므로 위험이 새로 생기지 않는다.
- 한 벌 합(반지 2개): 유니크 21% -> 55%, 레전더리 광역형 58% -> 120%, 토벌형 34% -> 76%.
- 사냥 계산(`theory_sets.py`, 무리 6마리·밀도 0.12/m2·회전 베기 3.2m, 맞는 수 = 0.12 x pi x r^2 상한 6, 범위 스킬이 피해 전부라고 본 상한): 유니크 한 벌 맞는 수 4.67 -> 5.98, 사냥 시간 -12.9%. 레전더리 광역형 0%(이미 6), 토벌형 -8.1%.
- 플레이 시간 위험: 요일 던전 유니크가 Lv27부터 나오고, Lv27~39는 Lv40까지 필요 경험치의 78%다. 유니크 무기 + 반지 2개(21% -> 40%)면 그 구간 사냥이 최대 8.0% 빨라진다. 사냥이 1~40 시간(44.9시간)의 절반, 그 구간의 절반 동안 이 장비를 끼면 44.9 x 0.78 x 0.5 x 0.5 x 0.08 = 약 0.7시간(1.6%) 줄어든다. 유니크를 한 벌 다 모으면 상한 2.3시간(5%)이다. 실측 기준(레어 한 벌)은 바뀌지 않으므로 측정값으로 확인되기 전에는 보충하지 않았다.
