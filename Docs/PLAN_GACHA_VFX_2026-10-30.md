# 뽑기 고등급 연출 영상 (2026-10-30)

사용자 요청: 냥이 성문 수비대(bonghwa)의 뽑기 고등급 연출을 그대로 가져온다. 유니크·레전더리에 넣는다. 영상은 Google Flow Omni로 만들고, 고양이 발 같은 bonghwa 전용 문양은 쓰지 않는다.

## 1. bonghwa 구현 (참고 코드)

- 파일: `games/bonghwa/js/ui/core.js` `UI.vfx()`, `js/ui/hero.js` `playVfx`·`bigReveal`·`beam`, `css/fx-summon.css` `.vfx-clip`, 영상 `vfx/summon_{epic,legend,mythic}.mp4`
- 영상 규격: 960x540, 24fps, h264, 4.0~4.8초, 검은 배경. 화면에는 `mix-blend-mode: screen`으로 섞어 검은색은 투명, 빛만 보인다
- 영상 구성(전설): 바닥 마법진(문자 고리 + 가운데 문양) 위로 빛기둥이 꽂히고, 폭발 섬광, 소용돌이 빛 입자가 기둥을 감고 올라가다 흩어진다. 신화는 붉은·주황 빛기둥 + 무지개 굴절 + 연기·불꽃 입자
- 재생 시점 두 곳
  1. 결과 창이 열릴 때: 이번 뽑기의 최고 등급 영상을 결과 창 위에 한 번(z 50). 누르면 건너뛰고, 고등급 2초·그 아래 1.6초 뒤 자동으로 넘어가 카드를 나눠 준다
  2. 고등급 카드를 열 때: 그 카드 위에서만 재생(`vfx-spot`: 카드보다 가로 230%·세로 200% 크기로 가운데 맞춤). 화면 한가운데 폭발은 없다. 팡파르 소리·음악 낮춤·진동이 같이 난다
- 기타: 첫 프레임이 실제로 그려진 뒤에만 보이게 해서(빈 상자·재생 버튼 방지) 0.15초 페이드 인, 끝나면 제거. 미리 메모리에 올려 두고(`vfxWarm`) 바로 재생. 흔들림 줄이기 설정이면 재생하지 않는다

## 2. dotRPG 적용 계획

- 등급 대응(dotRPG 등급 색): 유니크 `#ffd84a`(금색) = bonghwa 전설 연출, 레전더리 `#ff8a3d`(주황) = bonghwa 신화 연출
- 문양: 고양이 발 대신 볼론 세계 문양(가운데 팔각 별 문장, 고리에는 마야풍 문자). 모든 영상이 같은 문양을 쓴다
- 영상: Flow Omni로 등급마다 2개 시안 생성 -> 사용자가 고르면 960x540·24fps·h264·4~5초로 맞춘다(검은 배경 유지)
- Unity 재생(사용자 승인 뒤 구현): `VideoPlayer` + RenderTexture를 `RawImage`에 올리고 더하기(Additive)/스크린 섞기 재질로 검은색을 투명하게. 뽑기 결과 창이 열릴 때 최고 등급 한 번(누르면 건너뜀, 2초 자동 진행), 유니크·레전더리 카드를 열 때 그 카드 위에서 한 번. 미리 불러 두고, 흔들림 줄이기 설정이면 끈다
- 대상 화면: 캐시샵 장비 뽑기, 스킨·오라 뽑기, 봉인된 상자(유니크·레전더리에 해당하는 등급만), 자동 뽑기도 같은 규칙

## 3. 결정 (2026-10-30)

- 선택: 유니크 `summon_unique_a`, 레전더리 `summon_legendary_a`
- 레전더리 놀람 연출: 결과 창은 레전더리가 있어도 유니크 영상을 튼다. 유니크·레전더리 카드는 같은 모습으로 엎어져 나온다. 유니크는 누르면 뒤집히며 유니크 영상. 레전더리는 첫 터치에 레전더리 영상만 나오고 카드는 그대로, 두 번째 터치에 뒤집힌다
- 자동 뽑기·모두 열기는 터치 없이 같은 순서로 자동 재생
