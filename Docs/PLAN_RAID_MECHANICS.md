# 레이드 광역 패턴: 광폭화와 "이대론 죽을 수 없다!" (2026-10-11)

모든 레이드 보스(`MonsterDef.raid`)에 공통으로 붙는다. 해골왕의 토템·망자의 심판은 그대로 두고 그 위에 더한다.
수치는 한곳(`Enemies/RaidMechanics.cs`의 상수)에 모아 둔다.

## 1. 광폭화 (HP 40% 이하, 1회)

- 보스 HP가 40% 이하가 되면 광폭화한다. 해골왕처럼 단계(3단계)로 먼저 광폭화한 경우 같은 상태로 보고 두 번 걸지 않는다.
- 효과: 보스 피해 x1.3, 이동 x1.3, 패턴 대기 x0.7(기존 광폭화 상수 그대로), 몸에 붉은 빛이 맥박처럼 뛴다.
- 안내: 보스 체력 바 위에 "광폭화!"(붉은색).

## 2. 절망의 포효 "이대론 죽을 수 없다!"

- 광폭화 3초 뒤 첫 시전, 이후 살아 있는 동안 30초마다.
- 순서
  1. 보스가 멈추고 머리 위에 대사 "이대론 죽을 수 없다!"(3.5초).
  2. 체력 바 위 안내 "안전지대로! 3 / 2 / 1", 화면 가장자리가 붉게 맥박친다.
  3. 보스 주변 8m 안 걸을 수 있는 곳에 금색 안전지대 3개(반경 1.8m, 바닥 원 크기가 실제 판정 크기)가 생긴다.
  4. 3.5초 뒤 판정. 끊을 수 없다(보스가 죽어야만 취소).
- 판정: 파티원(사람·AI 동료) 중 아래에 해당하지 않으면 최대 HP 20% 피해(막기 불가) + 4초 기절.
  - 안전지대 안에 서 있다
  - 무적 중이다(신의 가호 1초, 강철의 보루 1초 등)
  - 응보의 방진이 켜져 있다(첫 공격을 막고 반격, 기절도 없음)
- 파훼: 안전지대로 이동하거나, 힐러의 신의 가호·수호자의 보루를 판정 순간에 맞춘다.

## 3. 플레이어 기절

- `PlayerController.Stun(seconds)`: 이동·공격·스킬·이동기·물약 키가 막히고 맞은 자세, 머리 위 별, "기절" 글자, 내 캐릭터면 버프 칸에 "기절 n초".

## 4. 파티 동기화

- 보스는 호스트에서만 움직인다. 호스트가 두 메시지를 보낸다.
  - `PartyMsg.RaidRoar`: 보스 번호·위치, 시전 시간, 안전지대 위치 -> 파티원 화면에 대사·안내·붉은 가장자리·안전지대를 그린다.
  - `PartyMsg.RaidStun`: 자리 번호, 초 -> 그 자리의 캐릭터(자기 자신이면 내 캐릭터)를 기절시킨다.
- 피해는 지금처럼 호스트 판정 -> 피해 메시지 경로를 탄다. 혼자 하는 레이드(AI 동료)는 네트워크 없이 같은 코드로 돈다.
