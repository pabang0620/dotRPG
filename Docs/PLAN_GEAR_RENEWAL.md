# 장비 전면 개편 기획 (2026-10-05)

## 1. 확정 사항 (사용자 결정)

- 레벨 단계: Lv.1, 10, 15, 20, 25, 30, 35, 40 (8단계). 단계 레벨이 곧 착용 레벨이다.
- 등급: 단계마다 커먼·언커먼·레어·에픽·유니크 5등급 전부(Lv.1 단계는 커먼~레어 3등급). 레전더리는 Lv.20, Lv.40 두 단계에만.
- 직업 구분(큰 직업선): 무기·상의·하의는 직업 전용(전사: 검·갑옷·각반, 마법사: 지팡이·로브·치마), 목걸이·반지는 공용.
- 아이콘: 등급마다 다른 그림(전부 새로 그린다). 캐릭터 모습: 무기만 단계별로 손에 든 그림이 바뀐다(상·하의는 지금처럼 단계 구간별 모양 3종).
- 옛 장비 19종: 새 장비로 자동 교체(강화 수치 유지, 서버·클라이언트 저장 모두 변환).
- 캐시샵 장비 뽑기: 내 직업 장비만, 부위 배너(무기·방어구·장신구) + 레벨 단계를 골라서 뽑는다.

## 2. 장비 구성

| 종류 | 직업 | 단계당 개수 |
|---|---|---|
| 검 / 지팡이 | 전사 / 마법사 | 5 (Lv.1은 3) |
| 갑옷(상의) / 로브(상의) | 전사 / 마법사 | 5 |
| 각반(하의) / 로브 치마(하의) | 전사 / 마법사 | 5 |
| 목걸이 / 반지 | 공용 | 5 |

- 합계: Lv.1 24종 + Lv.10~40 7단계 x 40종 = 280종 + 레전더리(Lv.20·Lv.40 x 8종) 16종 = 320종.
- 시작 장비(나무 검·참나무 지팡이)는 그대로 둔다(귀속, 강화 가능, 파괴되면 다시 받음).
- 필드 보스 장신구 3종은 "보스 전용 유니크"로 유지하고 착용 레벨만 붙인다(뿌리 반지 Lv.10, 바위 심장 목걸이 Lv.20, 서리 리치 반지 Lv.35).

## 3. 능력치 설계(초안, 7단계에서 이론 계산으로 확정)

- 단계 기준치(레어 등급 기준) x 등급 배율. 등급 배율: 커먼 0.6, 언커먼 0.8, 레어 1.0, 에픽 1.25, 유니크 1.5, 레전더리 1.85.
- 무기 공격(레어): Lv.1 6, Lv.10 10, 15 14, 20 18, 25 23, 30 28, 35 34, 40 40.
- 전사 갑옷: 체력 + 막기. 전사 각반: 체력 + 이동. 마법사 로브: 체력(전사의 70%) + 공격 소량. 로브 치마: 체력 + 이동.
- 목걸이: 공격 + 체력. 반지: 공격 또는 막기·이동(종류마다 성격을 나눈다).
- 에픽 이상은 보조 능력치 하나 추가, 유니크·레전더리는 성장 옵션(경험치 % 또는 스킬 범위 %)을 일부에 붙인다(필드 보스 장비와 같은 방식).
- 강화 성장치(enhanceSeed)는 그림 번호가 아니라 레벨 단계로 계산한다. 강화 골드도 단계에 따라 오른다.
- 판매가는 단계 x 등급으로 정한다.
- 검증: `Tools/balance/theory_balance.py`의 빌드를 새 단계로 바꿔 요일던전 120~300초, 레이드 300~600초, 생존률 기준을 다시 맞춘다.

## 4. 착용 레벨

- 장비마다 `reqLevel`(= 단계 레벨). 클라이언트(장비 창·자동 착용·업그레이드 표시)와 서버(착용 API: `LEVEL_TOO_LOW`) 모두 검사한다.
- 레벨이 모자란 장비는 장비 창에서 흐리게, "착용 Lv.20" 표시. 뽑기·드롭·보관·거래는 레벨과 무관하다.
- 이미 끼고 있는 장비는 벗기지 않는다(새로 끼는 것만 막는다).

## 5. 얻는 경로(모두 레벨 단계를 따른다)

| 경로 | 단계 | 등급 |
|---|---|---|
| 필드 사냥 | 그 사냥터 몬스터 레벨 이하의 가장 높은 단계 | 커먼 > 언커먼 > 레어(에픽 드묾) |
| 요일 던전 카드 | 난이도 권장 레벨의 단계 | 난이도 최소 등급 이상 |
| 요일 던전 대박 카드 | 같은 단계 | 유니크 |
| 해골왕 레이드 | Lv.20 | 레어~유니크, Lv.20 레전더리 극저확률 |
| 그라흐 레이드 | Lv.40 | 에픽~유니크, Lv.40 레전더리 극저확률 |
| 필드 보스 | 보스 전용 장신구 | 3% |
| 캐시샵 장비 뽑기 | 플레이어가 고른 단계(내 레벨 이하 단계만) | 언커먼~유니크(레전더리는 Lv.20·40 단계만) |
| 대장간 상점(신규) | 내 레벨 이하 단계 | 커먼만 골드로 구매 |
| 승급(고대의 핵) | 같은 단계 | 한 등급 위(유니크 -> 레전더리는 Lv.20·40만) |

## 6. 캐시샵 장비 뽑기 개선

- 배너 3종(무기·방어구·장신구)은 그대로, 직업은 자동(내 캐릭터 직업 장비만).
- 새로 "레벨 단계" 선택 칸: 내 레벨까지 열린 단계 중 하나를 고른다(기본값은 내 단계). 확률표도 고른 단계 기준으로 보인다.
- 등급 확률(언커먼 62 / 레어 30 / 에픽 7.5 / 유니크 0.45 / 레전더리 0.05)은 유지하되, 레전더리가 없는 단계에서는 그 몫이 유니크로 간다.

## 7. 그림

- 아이콘 320장: Flow로 한 장에 10개(5등급 x 2단계, 같은 종류)씩 그린다. 약 33장, 연속 제출 차단을 피해 10장 안팎씩 나눠 생성한다.
- 아트 방향: 단계마다 지역 테마 재질(마을 수련 -> 해골 숲 뼈·철 -> 붉은 돌 -> 기사단 강철 -> 서리 소나무 -> 빙결 -> 눈보라 은빛 -> 성좌), 등급이 오를수록 장식·보석·빛이 늘어난다(커먼 낡고 소박, 유니크 화려한 문양과 빛, 레전더리 금·보라 광채).
- 손에 든 무기: 전사 검 10종(8단계 + 레전더리 2), 마법사 지팡이 10종. 무기 그림 번호를 아이콘 이름에서 읽지 않고 장비의 `artTier`로 정한다(두 자리 번호 대응).
- 상·하의 모습: 단계 구간별 3종(Lv.1~15 / 20~30 / 35~40)을 직업 재질(갑옷 / 로브)로 매핑한다.

## 8. 이름 규칙

- 단계 테마 x 등급: 커먼은 소박한 이름(예: 수습 기사의 검), 언커먼·레어는 재질·지역(예: 붉은 돌 장검), 에픽은 칭호형(예: 서리솔 수호검), 유니크는 고유명(예: 망령왕의 처형검), 레전더리는 전설명.
- 전체 목록은 구현 때 표(`Docs/GEAR_TABLE.md`)로 뽑아 문서와 코드가 같은 원본을 쓴다.

## 9. 옛 장비 변환

- 19종 -> 새 장비 대응표(같은 부위·비슷한 위력의 단계와 등급, 강화 수치 유지). 방어구는 착용 중인 캐릭터의 직업 재질로 바꾼다.
- 서버: 마이그레이션 스크립트가 `character_items`(가방·창고·착용), `item_ledger`(변환 원장 행), `drops`, `auction_listings`, `mails`, `character_enhance_pity`를 한 트랜잭션에서 바꾼다.
- 클라이언트 저장: `SaveSystem.Migrate`에 같은 대응표(오프라인 저장 대비).
- 퀘스트 보상(루비 반지), 보물상자 보상(철 흉갑), 용병 장비, 개발용 자동 시험, 서버 시험의 장비 id도 새 id로 바꾼다.

## 10. 화면

- 장비 창: 착용 레벨·직업 표시, 착용 불가 사유, 가방 필터(착용 가능만 / 전체), 비교(현재 착용 대비 증감).
- 뽑기 창: 단계 선택 칸, 단계별 확률표.
- 대장간: 커먼 장비 구매 탭.
- 일괄 판매: 단계 필터 추가(낮은 단계 장비 정리).

## 11. 진행 순서

1. 데이터 모델: `reqLevel`, `levelTier`, `artTier`, 직업 전용 방어구, 320종 표 생성기와 능력치 공식.
2. 착용 레벨 검사(클라이언트·서버), 장비 창 표시.
3. 획득 경로: 필드 드롭·던전 카드·대박·레이드·필드 보스를 단계 기반으로.
4. 캐시샵 단계 선택 뽑기, 승급 같은 단계 안으로, 대장간 커먼 구매.
5. 옛 장비 변환(서버 마이그레이션·클라이언트 저장), 고정 id 교체, 서버 시험 기대값 수정.
6. 그림: 아이콘 33장 생성·절단, 손에 든 무기 20종, 상·하의 모습 매핑.
7. 밸런스 이론 계산으로 능력치 확정, 문서·표 갱신.
