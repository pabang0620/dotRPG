재검수 상세:
- `final2-ko_100` 및 `final2-de_130`: 던전 배너·설명·보상 등급, 미니던전 카드, 강화·계승, 결과 실패 글자, 외형 목록, 상점 NPC 헤더의 겹침 해결을 원본 이미지로 확인했다.
- `final3-en_100` 및 `final3-de_130`: 파티 헤더가 탭과 분리됐고, 용병 설명의 스크롤바와 마지막 스킬·무기 문구까지 확인했다. 스킬/젬 소개와 목록의 하단 접근도 확인했다.
- 특화 hover를 추가로 열어 수호자의 짧은 설명이 한 줄 라벨로 취급되어 오른쪽으로 넘치는 문제를 발견했다. 제목과 본문을 명시적으로 나눠 수정했고 재촬영한다.
- 전직 카드의 보조 노드가 윗 카드 아래쪽 14px를 덮는 기존 배치도 발견했다. 전체 높이 안에서 행 간격을 조정했으며 재촬영한다.

자동 후보 중 던전 파티의 `나`, 난이도의 `왕`은 원래 한 글자인 별도 항목이므로 줄바꿈 오류로 세지 않는다. 마스크 안 스크롤 콘텐츠의 화면 밖 좌표도 오류로 단정하지 않는다. 최초 `initial-ko_100`의 검은 캡처는 ReadPixels 호출 오류로 무효다. `render1-ko_100`의 전투 `기절` 글자는 render-texture 캡처의 world/UI 정렬 차이에 의한 것으로, 실제 메뉴 결함과 구분하고 캡처 정렬을 보정했다. 최종 검수는 수정 후 화면을 기준으로 한다.

아래 E1 항목은 이전 감사 기록이다. 현재 버전의 미해결 목록으로 그대로 간주하지 않으며, 2026-10-27 실제 재검수 결과는 위 표와 캡처 기록을 기준으로 한다.

근거: 코드(Assets/Scripts/Runtime/UI/*.cs) + 기존 스크린샷(`merge/Logs/m_*`, `content/Logs/c3_*`, 1920×1080 / 1280×720).
기준 해상도: CanvasScaler 1280×720 기준. 아래 픽셀 값은 모두 720p 기준 단위.

우선순위: **P0** = 플레이 중 정보가 가려지거나 읽을 수 없음 · **P1** = 상용 품질에 못 미침(일관성·피드백) · **P2** = 다듬기.
