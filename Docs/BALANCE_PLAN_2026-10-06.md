# 전체 밸런스 계획 (2026-10-06)

이번 날 받은 요청을 하나씩 넣지 않고 한 기준으로 맞춘 기록이다. 피해는 A(공격력 = 기본 10 + 장비 공격력) 단위로 적는다.

## 1. 기준

| 기준 | 값 |
|---|---|
| 전사 기본 공격 | 0.27초마다 1A, 초당 약 3.7A(단일) |
| 연사 스킬(직업 주력기) | 초당 2~3A 수준. 대신 범위·관통·원거리라 기본 공격보다 안전하다 |
| 연사 스킬 마나 | 전직 직후(Lv.15)에는 자연 회복보다 빨리 닳아 20초 남짓 연사, Lv.40 전사는 회복과 비슷, 법사 계열은 마나가 많아 오래 쏜다 |
| 버프·폭딜 | 평균 피해 상승은 +20%대, 쓰는 순간만 크게 |
| 몬스터 | 일반 몬스터 공격 주기 2배, 처음 마주치면 0.5~1.5초 뒤 첫 공격(맞으면 바로 반격) |

## 3. 공통 스킬 조정 (이미 반영)

- 일반 공격 스킬: 마나 0.65배, 쿨 0.7배, 범위 1.5배, 위력 0.85배
- 버프·보호막: 지속 2배, 쿨 1.6배
- 각성기: 쿨 1.25배, 지속·타수 1.5배
- 모든 스킬 자동 조준

## 4. 장비

유니크 2.3배, 레전더리 3.2배(레어 기준). 무기 한 부위가 에픽에서 레전더리로 바뀌면 Lv.40 기준 A가 약 1.6~1.9배가 된다. 요청대로 한 부위만으로 체감되는 폭이다.

## 5. 지켜볼 점

- 연사 스킬은 전직(Lv.15) 뒤에만 열리므로 Lv.1~14 난이도에는 영향이 없다.
- Lv.40에서 파이터 연사는 마나가 거의 줄지 않는다. 너무 쉽다면 파쇄 검기 마나를 5로 올린다.
- 레전더리 장비와 검귀 해방이 겹치면 보스가 빨리 녹는다. 레이드가 너무 짧아지면 보스 체력부터 본다.
