# 상용화 전 검토 (보안·재화·법·라이선스·운영·클라이언트)

심리·기능 검토 외에 나머지 시각으로 본 결과. 항목은 세 갈래로 나눈다.
- **고침**: 코드 결함이라 바로 고쳤다.
- **오픈 전 필수**: 오픈하려면 반드시 해야 하지만, 결정이나 외부 작업(업체 계약, 신청, 문서 작성)이 필요하다.
- **판단 필요**: 위험이 낮거나 정책 선택이다. 권장안을 적었다.

[자문] 표시는 법률 자문으로 확인할 것.

## 2. 오픈 전 필수

## 4. 문제없음으로 확인한 것

- 보안: 히스토리 218커밋 비밀 노출 0, `.env` 미추적, JWT 알고리즘 고정·15분 토큰·매 요청 정지 확인, argon2id, 로그인 rate limit, 관리자 별도 리스너+TOTP, 라우트 72곳 검증·소유자 확인·SQL 바인딩, WebSocket 크기·연결·도배 제한, 에러 스택 미노출, 로그 토큰 미기록, dev 로그인은 운영 설정으로 꺼짐.
- 재화: 결제는 Steam 서버 조회로만 지급·주문당 1회·환불 회수와 부채, 봉인된 상자 확률표와 문서 일치(합 100), 부스터 게이지 계정별, 강화권 하향 거부, 레벨 보상·패스 계정당 1회, 드롭·우편 소유자 확인, 오프라인 세이브에서 온라인으로 재화가 넘어가는 경로 없음.
- 라이선스: 폰트 Galmuri(OFL, 전문 동봉), 패키지는 Unity 공식과 Steamworks.NET(MIT)뿐, 에셋스토어 에셋 없음, 서버 직접 의존성 전부 MIT, 효과음은 직접 합성, 게임 텍스트·스토어 문구에 다른 게임 이름 없음.
- 운영: 핫·점검 배포와 롤백 스크립트, 구버전 클라이언트 차단(426), 점검 모드, 관리자 CLI(정지·신고·보상 우편·공지), 06:00 KST 초기화 단일 함수, 야간 정합성 점검.
- 클라이언트: 세이브 원자적 쓰기와 백업 복구, Busy 플래그 해제, 리소스 캐시, 해상도·창 모드·VSync·프레임 제한, 글자 크기 4단계·색약 보정·흔들림 끄기·음량 개별·키 재설정, 출시 빌드에서 steam_appid.txt 차단.
