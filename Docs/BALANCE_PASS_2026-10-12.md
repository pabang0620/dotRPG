# 마무리 밸런스 점검 (2026-10-12, 이론 계산)

오늘 바뀐 것(몬스터 방어력, 각성기 4종 재설계, 채집 제거)을 넣고 사냥터·던전·레이드·필드 보스를 다시 계산한다.
특히 레이드를 1·2·3·4명으로 들어갈 때 체력과 난이도가 맞는지 본다. 게임은 돌리지 않는다.

## 1. 현재 구조 (코드 확인)

- 던전·레이드 몬스터 체력 = 기본 x 난이도 hpMul x 인원 보정 x 레벨 성장.
- 인원 보정 `DungeonDatabase.PartyHpScale` = 1명 1.0 / 2명 1.7 / 3명 2.4 / 4명 3.0. 서버 `dungeons.json partyHpScale`도 같다.
- 인원은 `PartyManager.Count`(나 + 다른 사람 + AI 동료). 몬스터 피해 배율은 인원과 무관하다.
- 한 사람이 맡는 체력: 1명 1.0 / 2명 0.85 / 3명 0.80 / 4명 0.75. 사람이 많을수록 한 사람 몫이 줄어든다.
- AI 동료는 사람 화력의 65%로 본다(theory_dungeon 기존 가정). AI로 4칸을 채우면 체력은 3.0배인데 화력은 1 + 3 x 0.65 = 2.95라서 사람 4명보다 느리다.

## 2. 목표

| # | 항목 | 목표 |
|---|---|---|
| R1 | 레이드 난이도 순서 | 사람 4명이 가장 쉽고(빠르고 안전), 혼자가 가장 어렵다 |
| R2 | 레이드 시간(모델) | 사람 4명 약 150~250초, AI 포함 4칸 약 180~280초(실제는 모델의 약 2배, 300~600초) |
| R3 | 혼자(AI 없이) | 클리어는 가능하되 사람 4명보다 확실히 느리고, 보스 공격을 혼자 받아 위험하다 |
| R4 | 사냥터 | 무리 정리 4~7초(기존 목표 유지) |
| R5 | 각성기 | 한 번 쓸 때 피해가 직업끼리 크게 어긋나지 않는다(같은 쿨 대비) |

## 3. 할 일

1. theory_dungeon.py에 방어력을 넣는다(Lv15 이상 몬스터, 직접 피해만, 수호자가 있으면 방어 붕괴 가동률만큼 해제).
2. 레이드 표에 인원별 줄을 추가한다: 혼자, 혼자 + AI 3, 사람 2, 사람 2 + AI 2, 사람 3, 사람 3 + AI 1, 사람 4. 보스 공격을 한 사람이 받을 때 버티는 시간도 같이 낸다.
3. 각성기 4종의 1회 피해를 계산해 비교한다.
4. 목표를 벗어난 것만 수치를 고친다(클라이언트와 서버 데이터를 같이, 데이터 버전 갱신).

## 4. 결과

계산: `python3 Tools/balance/theory_dungeon.py` (방어력 반영, 레이드 인원별 표 추가). 모델 초는 실제의 약 절반이다.

### 4.1 레이드 인원별 (이전 인원 보정 1.0/1.7/2.4/3.0, 방어력 반영)

| 구성 | 해골왕 전체(초) | 그라흐 전체(초) | 한 사람 몫 체력 | 보스 한 방(맞는 사람 HP 대비) |
|---|---|---|---|---|
| 혼자 | 165~325 | 160~334 | 1.00 | 18~28% |
| 혼자 + AI 3 | 222 | 222 | 0.75 | 4~6%(수호자) |
| 사람 2 | 187 | 184 | 0.85 | 14~23% |
| 사람 3 | 182 | 181 | 0.80 | 14~23% |
| 사람 4 | 180 | 177 | 0.75 | 4~6%(수호자) |

문제: 혼자 파이터(165초)가 사람 4명(180초)보다 빨랐고, 사람 2·3·4명이 거의 같았다. 사람이 늘어도 한 사람 몫 체력이 조금만 줄어서(0.85 -> 0.75) 비숍·수호자처럼 화력이 낮은 직업이 들어오면 오히려 느려졌다(R1 위반).

### 4.2 바꾼 값

| 항목 | 이전 | 이후 | 위치 |
|---|---|---|---|
| 인원 보정 PartyHpScale | 1.0 / 1.7 / 2.4 / 3.0 | 1.0 / 1.6 / 2.1 / 2.5 | DungeonDatabase.cs, server/data/dungeons.json |
| 한 사람 몫 체력 | 1.00 / 0.85 / 0.80 / 0.75 | 1.00 / 0.80 / 0.70 / 0.63 | |
| 유성우 원소 자국 | 자국마다 0.5초마다 5%, 겹치면 전부 들어감 | 적마다 0.5초에 한 번 10%(겹쳐도 한 번) | CareerCombat.Arcanist.cs |

- 유성우는 혜성이 192개라 자국이 겹치면 보스 한 마리가 자국 피해만 3000% 넘게 받았다. 겹침을 막고 한 번 피해를 올려 보스 한 마리 기준 약 혜성 900% + 자국 140% + 마지막 거대 혜성 450% = 약 1500%로, 천검귀일(낙검 6개 + 거대 검 600%, 약 1560%)과 맞췄다(R5).
- 레이드 hpMul은 그대로 둔다. 방어력이 들어가며 약 10% 느려진 것을 인원 보정 인하가 되돌려 목표 안에 있다.

### 4.3 이후

| 구성 | 해골왕 | 바르가스 | 바위 심장 | 그라흐 |

| 혼자 | 165~325 | 177~355 | 176~350 | 160~334 |
| 혼자 + AI 3 | 189 | 202 | 201 | 187 |

- 사람 4명이 모든 레이드에서 가장 빠르고(150~164초, 실제 약 300~330초), 보스 공격은 수호자가 받아 한 방이 HP의 4~6%다.

- AI 동료로 채운 4칸(187~202초)은 사람 4명보다 느리고 혼자보다 안전하다.
