## 작업 방식
- 에이전트마다 별도 git worktree(`C:\Users\admin\Desktop\games\dotRPG-wt\<이름>`) → 각자 컴파일·빌드·DevCapture 검증 → 커밋 → 오케스트레이터가 `feature/dungeon-raid`에 합치고 푸시.
- 동시 실행은 요청 제한 때문에 2개 이하.
- Playwright(이미지·음악 생성)는 메인 세션이 직접 한다.
