# dotRPG 설계 문서 (세로 슬라이스 v0.1)

## 0. 레퍼런스에 대해 먼저 밝혀 둘 점

- 첨부된 레퍼런스는 **정지 이미지 한 장(1344×896)** 으로 전달되었습니다. 움직이는 프레임은 볼 수 없었기 때문에,
  "애니메이션"은 캐릭터들의 **자세(도끼질·곡괭이질·물뿌리기·낚시·운반·칼 휘두르기)** 를 보고 추론했습니다.
- 레퍼런스의 에셋(스프라이트·타일)은 라이선스를 확인할 수 없으므로 **전혀 추출·사용하지 않았습니다.**
  모든 그래픽과 사운드는 코드(`ProceduralArt.cs`, `SfxSynth.cs`)로 새로 그리고 합성한 임시 에셋입니다.

## 1. 레퍼런스 분석

| 항목 | 분석 |
|---|---|
| 시점 | **탑다운(약간 기울어진 3/4 탑다운)**. 지붕과 앞벽이 함께 보이는 JRPG/농장게임식 시점. 쿼터뷰(아이소메트릭)나 횡스크롤이 아님. |
| 아트 스타일 | **16×16 타일 픽셀아트**를 4배 확대(화면 약 21×14 타일). 채도 높은 초록 잔디(체크무늬), 주황빛 흙길, 파란 물, 짙은 갈색 외곽선. |
| 캐릭터 | 2등신 치비, 몸 전체가 약 1타일(16px). 큰 머리·작은 몸·짧은 다리. 나무는 약 2×2타일. |
| 화면 비율 | 이미지 3:2. 게임은 16:9 PC 해상도를 기준으로 하되 카메라가 약 13.5타일 높이를 보여 주도록 설계. |
| 이동/애니메이션 | 아래·옆·위를 보는 캐릭터가 섞여 있음 → **4방향**. 작업 자세(도끼, 곡괭이, 물뿌리개, 낚싯대, 망치, 머리 위 상자 운반), 칼 공격 자세. |
| 맵 구성 | 울타리 친 당근 밭, 파란 지붕 집, **반투명 청사진 상태의 건설 현장**(모서리 브래킷 + 반짝이), 흙길, 호수·부두·흙 둑, 둥근 나무/과일나무, 그루터기, 바위, 딸기 덤불, 꽃, 당근 상자. |
| NPC | 여러 마을 사람이 각자 일을 하는 모습(벌목, 채광, 농사, 낚시, 운반, 건설, 수영). |
| 적 | **해골** 4~5마리가 마을과 초원을 돌아다님. |
| 전투 | 칼을 든 빨간 머리 캐릭터가 해골 옆에 있음 → **근접 전투가 존재한다고 판단**. |
| 연출 | 건설 현장의 노란 별 반짝이 + 먼지, 물뿌리개의 물방울, 낚싯줄. |
| UI | **화면에 UI가 전혀 보이지 않음.** |
| 카메라 | 한 장면이라 고정인지 추적인지 알 수 없음. |

### 레퍼런스만으로는 알 수 없어 별도로 설계한 부분

- **누가 플레이어인가?** 레퍼런스는 여러 주민이 자동으로 일하는 "마을 경영/자동화" 게임처럼 보입니다.
  요청이 "캐릭터를 조작하는 RPG"이므로 **플레이어 = 모험가 한 명**, 나머지 주민 = 분위기를 만드는 NPC로 재해석했습니다.
- 조작 체계, 체력·데미지 규칙, 적 AI, 목표/퀘스트, UI, 저장, 사운드, 카메라 동작, 맵 크기.

## 2. 게임 콘셉트

> **"해골 숲 옆 작은 마을"** — 해골 때문에 멈춘 마을 공방 공사를, 떠돌이 모험가가 재료를 모으고 해골을 쫓아내 다시 일으키는 아기자기한 탑다운 액션 RPG.

- 톤: 레퍼런스처럼 밝고 부지런한 마을. 전투는 가볍고 짧게, 마을 생활 느낌을 중심에.
- 장기 방향(Steam): 마을이 성장하는 RPG — 공방에서 도구 제작 → 새 지역 개방 → 주민 합류 → 마을 발전.

## 3. 핵심 플레이 루프 (세로 슬라이스, 약 5분)

```
 촌장에게 의뢰 받기
        │
        ▼
 ┌─ 탐험 ─────────────────────────────┐
 │  나무/바위를 검으로 쳐서 목재·돌 수집 │
 │  동쪽 숲에서 해골과 전투             │◀── 다치면 당근을 뽑아 먹고 회복
 │  NPC 대화로 힌트                     │
 └──────────────┬─────────────────────┘
                ▼
 공사 현장에 재료 전달 → 공방 완성 연출
                ▼
 촌장에게 보고 → 보상(최대 체력 +1하트) → 엔딩 화면 → 자유 탐험 계속
```

재미 포인트: 한 번의 버튼(검)으로 채집과 전투가 모두 되는 손맛, 해골의 공격 예고를 보고 피한 뒤 반격하는 리듬,
청사진이 완성 건물로 바뀌는 보상감, 부지런한 주민들이 만드는 레퍼런스 특유의 분위기.

## 4. 구현 순서 (실제로 진행한 순서)

1. 프로젝트 골격: Unity 버전 고정, 패키지 매니페스트, 어셈블리 정의(asmdef), 폴더 구조
2. 데이터 계층: `GameConfig`/`PlayerStats`/`EnemyStats`/`QuestConfig` ScriptableObject, 대사 JSON, 맵 텍스트
3. 임시 아트/사운드 생성기 (`ProceduralArt`, `SfxSynth`) + `SpriteLibrary`(Resources로 교체 가능)
4. 입력 추상화(`InputReader`) → 플레이어 이동·방향·애니메이션·충돌
5. 월드 빌더(Tilemap + 오브젝트 스폰), 카메라 추적
6. 상호작용(NPC, 표지판, 당근, 건설 현장) → 대화 시스템
7. 전투(체력, 피격, 넉백, 무적, 처치) → 해골 AI와 리스폰
8. 퀘스트 → HUD/대화창/메뉴(UI) → 게임 흐름(타이틀·일시정지·게임오버·엔딩)
9. 설정·저장/불러오기 → 에디터 도구(빌드, 설정 적용, 아트 내보내기)
10. 오프라인 컴파일 검증 + 아트/맵 렌더 확인
