첫 번째 마을: 창작 기와 건물 세트

실제 적용 이미지
- Art/Town/courtyard_house.png: 사용자가 선택했던 약초집 원본, 서쪽 주택.
- Art/Town/tea_house.png: 찻잎 화분과 베란다가 있는 북동쪽 주택.
- Art/Town/weaver_house.png: 직조기와 쪽빛 직물이 있는 남쪽 주택.
- Art/Town/chief_hall.png: 붉은 대문, 해 문양, 석조 기단의 촌장집.
- Art/Town/general_store.png: 황토색 차양과 생활용품 진열대의 잡화점.
- Art/Town/smithy.png: 굴뚝, 화덕, 공구 작업대의 대장간.
- Art/Town/warehouse.png: 철띠 대문, 곡물 문양과 적재 공간의 창고.
경로 기준: Assets/Resources/. 새 6종은 내장 image_gen으로 창작했으며 기존 약초집 1종과 함께 실제 런타임에 사용한다.
임시 대체 이미지나 색상만 바꾼 변형은 없다. 옛 절차적 이미지는 리소스 누락 시에만 쓰는 대체 리소스이다.

크기와 동작
- 모든 이미지 원본은 1536×1024 RGBA. 투명 배경, Point 필터, 비압축, Mipmap 없음.
- 이미지마다 측정한 PPU, 계단 기준 피벗, 출입구 X 위치, 벽체 충돌과 앞뒤 표시 순서를 VillageBuildingArt.cs에서 관리한다.
- 일반 전사의 키 약 1.22타일에 맞춰 문 높이는 그 이상, 건물 폭은 약 10타일로 배치한다.
- 계단을 밟을 수 있고 전면 벽에서 멈춘다. 계단 위 캐릭터는 건물 앞에 보인다.
- 상점, 강화, 창고 UI 및 주택/촌장집 대화 기능을 유지한다.

마을 배치
- Village.txt를 58×54로 북쪽 확장했다. 기존 광장, 플레이어 시작 지점, 동쪽 숲 출구 좌표는 유지한다.
- 각 부지의 좌하단: 약초집 (8,24), 차 농가 (43,40), 직조공 집 (35,8), 촌장집 (23,42), 잡화점 (15,33), 대장간 (32,30), 창고 (44,24).
- 북쪽 길과 동서 연결 길을 추가하고 건물 부지 안의 나무·잡동사니를 정리했다.
- 서비스 NPC는 해당 건물 근처로, 공사장은 남동쪽으로 옮겼다.

검증
- Unity -executeMethod DotRPG.EditorTools.CourtyardHousePreview.ExportAndBuild
  7종 PNG의 실제 런타임 키 연결, 피벗, 크기, 필터, 투명 가장자리를 검사하고 Windows 빌드.
- 게임 -dotrpgHouse <folder>
  광장에서 7개 문과 숲 출구까지 경로 연결, 건물/소품 겹침, 계단 이동, 벽 충돌, 캐릭터 앞뒤 순서, 3개 서비스 창 확인.
- Docs/images/courtyard-houses의 옛 이미지는 과거 절차적 버전이며 현재 적용 미리보기가 아니다.
- 생성 도구: 내장 image_gen. 전체 생성 지시문은 Docs/VILLAGE_BUILDINGS_PROMPTS.txt.
