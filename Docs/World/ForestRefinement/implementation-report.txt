숲 사냥터 소품 고도화 — 2026-10-09

대상
해골 숲(forest), 이끼 낀 유적(forest_ruins), 검은 뿌리 숲(forest_depths), 옛 수로 합류지(forest_crossing).
마을과 나머지 지상 지역, 지하 지역은 이번 수정에서 제외.

시각 변경
- 배경의 큰 잎 형태와 올리브색에 맞춰 수관의 명암을 넓게 묶고 작은 잎 노이즈를 줄임.
- 참나무·활엽수·소나무 각각 서로 다른 실루엣 두 가지. grove/개별 발점에 고정된 해시로 변형 선택.
- 기존 pine_layered를 일반 pine과 별도 그림으로 연결. 물가 willow의 종 구분 유지.
- 고사목 두 종류, 이끼 바위 두 종류, 덤불, 통나무, 그루터기, 이끼에 묻힌 작은 석주 제작.
- 큰 건축물/배경/지형/동선은 유지. 소품 위치, 크기 변환, RGB, 충돌, 채집 보상과 재생 시간은 유지.
- 신규 PNG 원본 알파 보존. crop view + 밑동 피벗 + nearest-neighbor(Point)로 렌더링.
- 채집 후 그루터기, 실제 재생 시 새 나무/바위 그림과 접지 그림자 유지.
