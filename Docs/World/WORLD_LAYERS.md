# 지상 순환 세계와 뿌리 아래 지하세계

작업 브랜치: `jaein`. 성소는 지상 제4마을이며 기존 성소의 지형과 수변 아트는 유지한다. 기존 네 지역의 1–2–1 사냥터 갈래를 통해 지상 세계가 순환한다. 중앙에 새 안전 마을인 **뿌리샘 마을**을 만들고, 마을 중앙 나무 아래 계단에서 지하로 내려간다.

## 연결과 확인 방법

```text
해골 숲 옆 작은 마을 → 숲 사냥터 1 → [2 / 3] → 4 → 바위 협곡 마을
바위 협곡 마을 → 협곡 사냥터 1 → [2 / 3] → 4 → 눈꽃 숲 마을
눈꽃 숲 마을 → 설원 사냥터 1 → [2 / 3] → 4 → 침수된 고대 성소
침수된 고대 성소 → 성소 사냥터 1 → [2 / 3] → 4 → 첫 마을

네 마을 ↔ 중앙 뿌리샘 마을 ↔ B1 뿌리 아래 갱도
                              ↙             ↘
                     B2 뒤엉킨 뿌리굴    B2 푸른 포자 동굴
                              ↘             ↙
                              B3 반딧불 심연
```

모든 통로는 왕복 가능하다. 기존 첫 마을에 없던 성소 복귀 출구는 광장의 안내 표식으로 보완했다. 네 기존 마을의 중앙 연결문은 저장 위치·기존 건물·포털과 겹치지 않는 빈 공간에 배치한다. 도착 지점은 트리거에서 떨어져 있어 즉시 되돌아가지 않는다.

- 지도 기본 단축키 **M** → **지상월드 / 지하월드** 버튼으로 전체 연결도를 전환한다.
- 지역을 선택하면 해당 맵의 지형, 출구, 기존 NPC 정보를 본다. 지도 탐색은 캐릭터를 이동시키지 않는다.
- 지하세계는 40레벨 이후 강화 장비와 파티로 도전하는 지역이다. B1 40–45, B2 45–50, B3 50–55. 실제 몬스터는 42 / 47 / 53레벨이다.
- 플레이어 최고 레벨과 장비 상한은 기존 **40**을 유지한다. 상세 수치는 [UNDERWORLD_LEVELS.md](UNDERWORLD_LEVELS.md)에 있다.
- 개발용 `-dotrpgWorldLayers <독립 저장 폴더>` 인자는 기존 저장과 분리된 40레벨 무음 체험을 뿌리샘에서 시작한다. 자동 저장은 꺼진다. 릴리스에서는 개발용 인자 초기화가 제외된다.

## 참고와 재해석

## 지형 및 구조물

뿌리샘은 52×44, 네 동굴은 각각 56×48 타일이다. 기존 카메라와 이동 좌표는 변경하지 않는다. 새 동굴의 바닥은 32px/타일로 렌더링한다.

초기 동굴에서 눈에 띄던 큰 원형 얼룩과 동일한 구조물의 반복을 제거했다. 방의 윤곽, 좁아졌다 넓어지는 연결부, 내부 암벽 섬, 불규칙한 물웅덩이로 형태를 구분한다. 뿌리굴은 흙·이끼·뿌리, 포자 동굴은 청록 균류와 수면, 심연은 짙은 청색 암반과 수정이 중심이다. 큰 구조물은 암벽 어깨에 놓고 작은 식생은 가장자리에 모아 보행 공간을 비운다.

`UnderworldContour`의 1/8타일 윤곽을 그림과 물·암벽 충돌이 함께 사용한다. 따라서 부드럽게 이어진 물가와 실제 이동 경계가 따로 어긋나지 않는다. 암벽 정면, 바닥 윗면, 젖은 가장자리의 명암을 구분한다. 물은 발의 이동을 막지만 투사체는 통과하고, 암벽은 투사체도 막는다. 동적 물결과 제한적인 광원 맥동은 맵 오브젝트 수명에 묶인다.

뿌리샘의 잡화점·대장간·창고는 기존 실내 시스템에 연결한다. 성소에는 이번 작업에서 별도의 상점 건물을 추가하지 않았다.

## 몬스터와 리소스

- **흑갑 굴파괴충:** 겹친 검은 갑각, 상아색 턱, 붉은 틈. 6개의 다리로 이동하며 돌진한다.
- **심연의 방패 파수꾼:** 층진 흑철 판금, 짙은 붉은 천, 청록 문양 방패. 전방 방어와 방패치기.
- **공허의 주술사:** 겹친 보라색 후드와 찢어진 옷자락, 수정 지팡이, 전용 보라색 투사체.

각 종은 5방향 × 4개의 새로 그린 핵심 자세를 가진다. 엔진의 idle 2개·walk 4개·attack·hurt 슬롯으로 연결하며, 호흡과 피격 보정은 지지점을 유지하는 런타임 픽셀 변형으로 만든다. 원화를 통째로 흔드는 방식으로 걸음걸음을 대체하지 않는다. 128×128 캔버스에 최근접 샘플링하고 불투명 경계·단계 색으로 정리한다. 같은 종의 모든 방향과 프레임은 동일한 배율과 발 높이를 사용한다.

실제로 사용하는 신규 PNG 원화:

- `Assets/StreamingAssets/Underworld/landmarks.png`: 나무 계단, 뿌리 아치, 버섯, 수정, 석순, 폐허 표식.
- `Assets/StreamingAssets/Underworld/floor.png`, `rock-face.png`: 지면과 암벽 재질.
- `Assets/StreamingAssets/Underworld/hollow_scarab.png`, `hollow_guard.png`, `hollow_hexer.png`: 몬스터 자세 원화. 같은 이름의 JSON은 셀 경계와 기준점.
- `UnderworldArt`, `UnderworldArt.Terrain`: 위 리소스를 조합하는 실제 지형 렌더러.
- `UnderworldMonsterArt`: 실제 스프라이트 캐시·모션 연결·투사체.
- `WorldAtlasArt`: 게임 코드로 제작한 지상/지하 연결지도.

PNG는 **내장 image_gen**으로 제작했다. 프롬프트와 제작 방식은 [환경 아트 기록](underworld-art-prompts.json), [몬스터 아트 기록](underworld-monster-art-prompts.json)에 저장했다. 임시 도형 몬스터는 최종 사용 경로에서 제거했다. 원본 PNG는 프로젝트에 포함되며 사용자 개인 캐시를 참조하지 않는다.

## 검증과 제한

경로/레이아웃/월드/40+ 수치 검증 371항목, 서버 정책 테스트 5개, 서버 TypeScript 빌드와 데이터 로더 검증을 통과했다. 온라인 만렙 파티는 지하 적의 높은 레벨 때문에 보상이 2%로 잘못 줄지 않으며, 저레벨 동승 제한과 지상 정책은 유지한다.

네이티브 실행 검증은 기존 로컬 플레이어에 새로 컴파일한 런타임 DLL과 StreamingAssets를 적용해서 진행한다. Unity Editor 라이선스가 없어 Editor를 통한 전체 플레이어 재빌드와 구분한다. 실제 네트워크 파티 세션과 여러 PC의 성능 측정은 수행하지 않았다.

최종 네이티브 기능 검증은 **343 통과 / 0 실패**다. 네 마을 중앙문, 지상 순환 복귀문, 지하의 모든 왕복 포털을 실제로 밟았다. 네 동굴에서 발 이동·수면과 암벽 충돌·안전한 도착 위치·몬스터 생성 위치·물 위 투사체 통과·암벽 투사체 차단을 확인했다. 세 종의 돌진 명중, 방패 전후방 피해 차이, 방패치기 명중, 원거리 투사체 발사·이동·정리를 실제 AI로 검증했다.

기준점 수정 후 별도 아트 검증은 **29 통과 / 0 실패**다. 몬스터 120개 엔진 프레임의 방향·투명 여백·동작별 몸통 중심을 확인했다. 걸음과 피격의 수평 중심 이동은 종별 최대 1.82 / 3.08 / 1.83px, 발 높이 오차는 1px 이하다. 전 과정 음량은 **0**이었다. 보고서: [기능 검증](Underworld/runtime-qa.txt), [아트 검증](Underworld/art-qa.txt).

바탕화면의 **dotRPG 지상·지하 월드 체험** 바로가기로 독립 저장 체험을 실행할 수 있다. 체험 캐릭터는 실제 피해를 받으며 장시간 무적이 적용되지 않는다.
