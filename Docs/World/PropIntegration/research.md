# 지상 소품과 배경의 통합 — 조사 및 구현 근거

2026-10-09. 기존 지상 21맵의 배경 원화, 이동 경로, 포털, 카메라, 충돌과 소품 좌표를 보존한다. 다른 게임의 원화를 가져오거나 배치도를 복제하지 않고, 재질과 접지 표현의 원칙만 참고한다.

## 기존 화면에서 찾은 차이

- 숲은 세밀한 바닥에 비해 나무의 검은 외곽선과 밝은 주황색 뿌리가 두드러진다. 일부 반복 수관은 주변 식생과 다른 밀도로 보인다.
- 바위절벽의 둥근 회색 바위는 황갈색 층상 암반과 재질이 달라 별도 오브젝트처럼 보인다.
- 설원은 밝은 주황색 뿌리와 일정한 눈 덩어리가 눈바닥과 분리되어 보인다. 바닥과 같은 차가운 암부와 밑동의 쌓인 눈이 필요하다.
- 성소의 기존 작은 조형물은 넓은 석재 면 위에 훨씬 조밀한 질감이 얹혀 있다. 주요 벽·계단·제단의 구도는 보존하고 작은 잔해부터 재질을 맞춘다.

따라서 새 지역별 소품에는 제한된 면 단위 명암, 지역에 맞는 색의 외곽선, 기존 발 기준점, 바닥 재질과 이어지는 밑동을 사용한다. 강한 검은 타원을 원화에 넣어 해결하지 않는다. 소품의 형태 변화는 기존 위치와 크기 범위 안에서만 적용한다.

## 접촉 그림자 구현

`Assets/Scripts/Runtime/World/WorldBuilder.SurfaceGrounding.cs`의 기존 정적 접촉 레이어를 유지하고 채집 자원에만 작은 별도 패치를 연결했다.

- `SurfaceResourceContact`는 `ResourceNode.Available` 및 `VisualRenderer`의 상태만 읽는다. 자원의 체력, 드롭, 재생 시간, 콜라이더, 애니메이션은 변경하지 않는다.
- 서 있는 나무는 밑동 그림자, 잘린 나무는 더 작은 그루터기 그림자로 바뀐다. 사라진 바위의 그림자는 즉시 숨고, 재생 시 복귀한다.
- 패치는 `SurfaceWorldScene` 아래에 둔다. 나무의 `TreeFade` 하위 렌더러가 아니므로 나뭇잎 가림 처리에서 알파를 덮어쓰지 않는다. 자원 흔들림에도 바닥 접촉점은 움직이지 않는다.
- 재생 중에는 기존 `Visual`의 성장 배율에 따라 그림자 불투명도만 완만하게 돌아온다. 사전에 만든 수면 마스크가 움직이지 않도록 패치 크기는 애니메이션하지 않는다.
- 자원 접촉 반경은 수관 크기가 아니라 기존 발 콜라이더 지름에서 구하며, 가로 반경 최대 0.66타일·세로 최대 0.26타일로 제한한다. 32PPU Point 텍스처의 낮은 알파 8단계로 그린다.
- 물·절벽·깊은 구멍은 기존 지형 및 `LivingWater` 마스크로 제외한다. 성소는 기존 `SanctumShore` 윤곽을 사용한다. 가장자리 가까운 그림자는 추가로 약해져 물가에 각진 잘림이 생기지 않게 한다.
- 작은 성소 기둥과 긴 잔해는 발 위치가 땅일 때만 접지를 더한다. 평면 잔해 `rubble`은 자체 밑동 표현을 사용하고 벽보다 뒤의 바닥 순서로 그려, 돌이나 그림자가 벽면에 떠 보이지 않게 한다. 큰 아치, 벽, 계단, 제단, 지하 B3의 전경 기둥은 대상에 넣지 않는다.
- 나무용 두 상태와 바위용 한 상태의 작은 텍스처를 맵 생성 때만 만든다. 매 프레임 텍스처 생성은 없으며, 모든 새 스프라이트·텍스처는 `SurfacePropGrounding.OwnedResources`가 맵 종료 때 정리한다.

## 검증 계약과 범위

`SurfacePropGrounding.ResourceContacts`, `ResourceContactCount`, `ResourceShadowPixelCount`와 각 contact의 `Node`, `Renderer`, `StandingSprite`, `DepletedSprite`, `SyncVisual()`로 자원별 시각 상태를 확인할 수 있다. 기존 `Renderer`는 정적 그림자 전용이며, 정적 접지 픽셀이 없는 맵에서는 null이다.

필수 실행 확인은 나무의 정상→그루터기→재생, 바위의 정상→소멸→재생, TreeFade 가림 중 그림자 유지, 물가 마스크, 맵 재입장 뒤 리소스 정리다. 이 문서는 조사와 구현 근거를 기록하며, 전체 통합 실행 검증의 통과 수치를 대신하지 않는다.

## 실제 반영한 범위

- `Assets/StreamingAssets/WorldProps/`의 새 투명 PNG 4장에 소품 48종을 제작했다. 현재 지상 21맵에서 사용하는 것은 32종이며, 나머지 16종은 같은 지역 세트의 예비 리소스다. 임시 대체 이미지는 없다. 제작 프롬프트와 도구는 `prompts.json`, 잘라 쓰는 영역과 발점은 `metadata.json`에 기록했다.
- 새 외형은 지상 21맵의 독립 소품 1,132개에 연결했다. 숲의 나무·관목·통나무, 협곡 사암, 설원의 적설 수목·돌, 성소의 작은 기둥·잔해를 포함한다. 건물·아치·큰 벽·계단·제단의 원화와 크기는 보존했다.
- 숲 사냥터 4개에서 배경 수관 위에 뿌리가 겹치던 장식은 숨긴다. 정확히 `EdgeTree` 또는 `Forest edge understory`이고, 발이 `%` 지형에 있으며, 충돌·채집·NPC·서비스·포털이 없는 객체만 대상이다. 물리 객체와 기존 좌표는 유지한다.
- 지하 4맵은 현재 나무·석조물이 배경 합성 안에 포함되어 있다. 특히 B3 전경 기둥은 배경의 동일 픽셀을 복제한 가림 레이어다. 배경을 유지하라는 요청에 따라 이 원화와 기둥은 교체하지 않았다.
- 투명 atlas는 맵마다 하나만 로드하며 포인트 필터와 발 기준점을 사용한다. 개별 그림의 비율을 보존하고, 기존 외형보다 폭이 1.15배 넘지 않게 맞춘다. 콜라이더와 이동 경로는 변경하지 않는다.

실제 게임 캡처는 [변경 전후 비교](before-after.jpg)와 [네 지역 적용 후 화면](four-regions-after.jpg)에서 확인할 수 있다. 해당 합성 JPG는 문서용 축소본이며 각 지역의 `*-environment.png`와 `*-gameplay.png`는 원래 캡처 해상도다.

검증은 기존 로컬 네이티브 플레이어에 최신 런타임 DLL과 새 StreamingAssets를 배포해 수행했다. Unity Editor 전체 재빌드는 라이선스가 없어 수행하지 않았다. 자동 검증은 별도 저장 폴더에서 볼륨 0으로 실행한다. 실제 결과 수치와 보호 파일 해시는 `verification.json`, `invariants.json`, `report.txt`에 기록한다.

최종 실행 결과: 지상 21맵 **911 통과 / 0 실패**, 지하 4맵 **219 통과 / 0 실패**. 배경·레이아웃·경로 보호 파일 61개와 실제 로드한 25맵 원화의 SHA가 작업 전과 일치했다. 숲의 비물리 중복 장식 125개만 숨겼으며, 물리 나무와 채집물은 유지했다. 채집 외형은 존재하는 지역의 대표 나무·바위 3개에서 실제 고갈·재생 코루틴과 그림자 상태를 실행해 확인했다. 스크린샷은 대표 4지역 및 마을·성소 사냥터를 직접 비교했다.
