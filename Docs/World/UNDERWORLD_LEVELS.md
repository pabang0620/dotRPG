# 지하세계 Lv.40+ 구성

지하세계는 현재 최고 레벨인 **플레이어 Lv.40 이후의 장비·파티 도전 지역**이다. 플레이어 레벨 상한, 저장 데이터의 레벨 규칙, 스킬 해금 및 기존 지상 사냥터는 변경하지 않았다. 지도에 표시되는 Lv.40~55는 지역 난이도 구간이며, 캐릭터가 Lv.55까지 성장한다는 뜻이 아니다.

| 지역 | 지역 난이도 | 실제 몬스터 | 기본 처치 경험치 |
| --- | --- | --- | --- |
| B1 · 뿌리 아래 갱도 | Lv.40~45 | Lv.42 | 109 |
| B2 · 뒤엉킨 뿌리굴 | Lv.45~50 | Lv.47 | 133 |
| B2 · 푸른 포자 동굴 | Lv.45~50 | Lv.47 | 133 |
| B3 · 반딧불 심연 | Lv.50~55 | Lv.53 | 165 |

각 맵은 18개 무리 생성점에 3마리씩, 총 54마리를 배치한다. 흑갑 굴파괴충·심연의 방패 파수꾼·공허의 주술사가 각각 18마리이며 재생성 주기는 25초다. 출입은 레벨로 잠그지 않는다.

## 전투 수치

기본 정의는 굴파괴충 HP 63 / 공격력 16, 방패 파수꾼 84 / 15, 주술사 40 / 14다. 기존 대응 지상 역할보다 체력은 약 40%, 공격력은 약 20% 높다. 기존 `MonsterDatabase.SpawnDef`의 레벨 보정과 준비·회복 시간은 그대로 적용한다.

| 실제 레벨 | 굴파괴충 HP / 공격력 | 방패 파수꾼 HP / 공격력 | 주술사 HP / 공격력 |
| --- | --- | --- | --- |
| 42 | 373 / 68 | 497 / 64 | 237 / 60 |
| 47 | 411 / 75 | 548 / 70 | 261 / 66 |
| 53 | 456 / 83 | 608 / 77 | 290 / 72 |

수치는 기본 1인 배율에서 계산한 반올림 결과다. 체력은 `기본 HP × (1 + 0.12 × (레벨−1))`, 공격력은 `기본 공격력 × (1 + 0.08 × (레벨−1))`을 사용한다. 몬스터 생성에는 플레이어의 Lv.40 상한이 적용되지 않는다.

## 경험치·보상·온라인 파티

- 기존 `XpAt(level)`은 Lv.40에서 상한을 유지한다. 지하 전용 호출만 Lv.60까지 기존 경험치 곡선을 확장하고 25% 추가 처치 경험치를 적용한다.
- 캐릭터 만렙은 40이다. 만렙에서는 기존 규칙대로 경험치로 추가 레벨을 얻지 않는다.
- 장비 단계는 기존 최고 단계인 Lv.40을 유지한다. 높은 몬스터 레벨이 존재하지 않는 Lv.45~55 장비를 생성하지 않는다.
- 서버의 필드 몬스터 레벨 검증 상한은 60으로 확장했다. 플레이어 레벨 검증 및 성장 상한은 변경하지 않았다.
- 온라인 파티의 저레벨 동승 방지 계산에 한해 지하 몬스터의 비교 레벨을 `min(실제 몬스터 레벨, 플레이어 상한)`으로 사용한다. 따라서 Lv.40 파티가 Lv.53 적을 잡았다는 이유만으로 드롭이 2%로 줄어들지 않는다. 실제 적 레벨·체력·처치 화력 검사에는 Lv.53을 그대로 사용한다.
- Lv.20 캐릭터의 지하 동승은 기존 하드 격차 제약을 유지하며, Lv.30 캐릭터도 일반 격차 감쇠를 받는다. 지상 지역의 동승 방지 정책은 변경하지 않았다.

검증: 경로·레이아웃·월드 분류·경험치 C# 검증 371항목 통과, 서버 데이터 로더 63개 맵과 지하 4개 맵의 Lv.42/47/47/53 및 생성 수 확인, 서버 TypeScript 빌드 통과. 온라인 파티 정책은 순수 함수 회귀 테스트로 검증하며, 실제 네트워크 파티 세션 테스트와 구분한다.
