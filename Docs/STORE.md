# 스토어 소개 문구 (Steam 기준 초안)

> 스토어 페이지에 그대로 붙일 수 있게 쓴 초안이다. 글자 수 제한이 있는 칸은 괄호에 적었다.
> 온라인 기능(파티 찾기·경매장·채팅)은 서버 연결 전이라 출시 문구에서 빼 두었다. 서버가 붙으면 아래 "온라인 추가 시" 문단을 쓴다.

## 짧은 소개 (300자 이내)

불타는 마굿간에서 모든 것을 잃은 일꾼이 검을 든다. 해골 숲 옆 작은 마을에서 시작하는 도트 탑다운 액션 RPG.
요일마다 바뀌는 던전, 수·토·일에 열리는 레이드, 실패하면 장비가 깨지는 강화, 그리고 가장 믿었던 스승의 진짜 얼굴.

## 긴 소개

### 잿더미에서 시작하는 이야기
축제 전날 밤, 해골 숲에서 언데드가 쏟아져 나왔다. 양부모는 마굿간 앞에서 쓰러졌고, 함께 자란 친구 리아는 검은 갑옷의 지휘관에게 끌려갔다.
모든 것을 잃은 마굿간 일꾼을 일으켜 세운 사람은 떠돌이 성전기사 카엘. 그는 검을 가르치고, 길을 알려 주고, 늘 한발 앞서 있다. 너무 앞서 있다.

### 직접 휘두르는 손맛
- 전사와 마법사, 두 직업. 스킬 4개와 각성 기술, 직업마다 다른 이동기(대시·순간이동)
- 보스가 바닥에 그리는 공격 범위를 보고 피하는 패턴 전투
- 패시브 트리와 보조 젬으로 같은 스킬도 다르게 쓰기

### 매일 할 거리
- 요일마다 열리는 던전 5종과 4단계 난이도. 주말에는 전부 열린다
- 수·토·일의 중간 레이드에서 봉인 열쇠 조각을 모아, 일요일 최종 레이드에 도전
- 랭크와 보상 카드: 빠르고 깔끔하게 깰수록 좋은 카드를 뒤집는다

### 강화의 긴장감
- +10부터는 실패하면 장비가 부서질 수 있다. 망치가 세 번 내려칠 때까지 숨을 참게 된다
- 장비 보호권, 재료 수급, 강화 단계별 확률을 직접 계산하는 재미

### 동료
- 마을에서 용병을 고용해 최대 4인 파티. 탱커·딜러·힐러가 알아서 역할을 나눈다
- 이야기 속 동료는 마을 밖에 나서면 자동으로 합류한다

### 편의 기능
- 키 변경, 글자·UI 크기 4단계, 색약 보정(경고 범위 색 변경), 화면 흔들림 끄기
- 저장 슬롯 3개, 저장 손상 시 백업에서 복구 안내
- 한국어 픽셀 폰트(Galmuri11)

## 온라인 추가 시 (서버 연결 후)

- 파티 찾기 게시판과 자동 매칭. 60초 안에 모이지 않으면 빈자리는 AI 용병이 채워 바로 출발
- 플레이어끼리 거래하는 경매장. 강화 장비는 한 번 거래되면 계정 귀속
- 일반·파티·귓속말 채팅과 빠른 신호(모여, 부활해 줘, 기믹 위치, 준비 완료, 고마워)

## 태그 후보

액션 RPG, 픽셀 그래픽, 탑다운, 핵 앤 슬래시, 스토리 중심, 파티 기반, 던전 크롤러, 싱글플레이어
