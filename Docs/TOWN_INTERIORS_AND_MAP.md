# 마을 실내와 지도

## 이용 방법

- 세 마을의 잡화점, 대장간, 창고 문에서 상호작용하면 5×5 실내로 들어간다.
- 안쪽 NPC와 대화하면 기존 구매/판매, 강화, 보관 기능을 이용할 수 있다. 퀘스트 대사가 있으면 기존처럼 대화가 우선한다.
- 아래쪽 화살표로 걸어나가면 들어온 건물 앞에 도착한다. 실내 저장 후 재접속도 지원한다.
- 눈꽃마을과 협곡마을에도 요일던전 안내원이 있다. 눈꽃마을의 기존 집은 잡화점, 남서쪽 큰 건물은 대장간, 남동쪽 새 집은 창고다.
- 지도(기본 M) 오른쪽 지역 목록으로 세 마을과 아홉 사냥터를 살펴본다. 캐릭터는 이동하지 않는다.
- NPC 번호 또는 오른쪽 이름을 누르면 위치와 이름을 강조한다. 목록은 6명씩 넘길 수 있다.
- 실내 NPC는 마을 지도에서 건물 입구에 표시한다. ‘실내 보기’ 또는 상점/대장간/창고 실내 버튼으로 내부 지도도 살펴본다.
- 현재 지역은 실제 NPC 위치를 갱신한다. 다른 지역은 기본 배치 위치를 보여준다. 방문한 지역은 이번 실행에서 촬영한 실제 지형, 아직 촬영하지 않은 지역은 실제 맵 레이아웃으로 만든 ‘미방문 지역 약도’로 구분한다.

## 구현

- `MapRegistry.Interiors`: `village/canyon/winter` × `shop/blacksmith/storage`, 총 9개 안전 맵. 각 실내의 부모 마을과 서비스 종류를 명시한다.
- `WorldBuilder.Interiors`: 32px/tile 바닥·벽·카운터를 코드로 제작하고 기존 소품을 재사용한다. 통로, NPC 접근 거리, 출구와 복귀 위치를 분리한다.
- `WorldAtlas`: 현재 플레이 월드를 로드하거나 바꾸지 않고 맵 텍스트를 읽는다. 실제 지형 스냅샷과 약도 텍스처를 캐시한다. 이야기 NPC는 진행 조건에 맞춰 표시한다.
- `MinimapView`: 투명 중심을 유지한 금속 테두리, 청록 장식, 북쪽 표시, 지역 이름판. 서비스 아이콘은 실내에서는 NPC, 마을에서는 건물 입구를 가리킨다.
- `FountainWater`: 동일했던 원본 분수 프레임 대신 물 색상 마스크 안에서만 흐름·파문·물방울 16프레임을 생성한다. 석재, 식물, 피벗, 충돌은 고정된다.
- 모집 양식은 개별 행으로 정렬한다. 스킬 노드에는 팔레트와 외곽선을 통일한 16px 도트 문양을 사용한다. 강화창의 특정 외부 게임 확률 출처 문구는 제거했으며 확률/재료/강화 규칙은 변경하지 않는다.
- 나무·돌·당근 제거 요청은 취소되어 해당 시스템을 유지한다.

## 검증과 배포

- `-dotrpgPresentation <folder>`: 기존 키 설정/강화 검사 + 분수 프레임, 지도 전환의 무이동성, 각 실내 출입/복귀, NPC 상호작용, 로컬 저장 복원, 눈꽃마을 던전 안내, 화면 캡처.
- `server`: `npm test -- --runTestsByPath test/characters.test.ts`는 9개 실내의 온라인 저장·재조회와 5×5 범위 밖 위치 거부를 검사한다.
- 서버 `maps.json`, `data_version.json`과 클라이언트 두 `DataVersion.txt`를 함께 갱신했다. 온라인 적용은 같은 버전의 서버 데이터와 새 클라이언트를 함께 배포해야 한다. 원격 서버 배포는 수행하지 않았다.
- 로컬에서는 Runtime DLL을 컴파일하고 기존 플레이어 복사본에 넣어 실행 검증했다. Unity 전체 빌드는 이 환경의 headless 라이선스 인증 오류 때문에 완료하지 못했다. 테스트용 실행 파일을 정식 재빌드로 간주하면 안 된다.
