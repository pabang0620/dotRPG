# UI 점검: 버튼 글자 넘침, 화면 밖 (2026-10-11)

근본 원인: `ui_btn` / `ui_btngray` 테두리(8px 9-slice)는 이 캔버스 배율에서 화면상 약 12px이다. 그런데 버튼 글자 칸이 테두리 안쪽 여백 없이 버튼 전체(또는 4~5px 여백)로 잡혀 있었다. `UIFactory.Text`의 기본값은 가로 줄바꿈 + 세로 넘침 허용이라, 긴 글자는 테두리 위에 그려지거나 두 줄로 꺾여 버튼 위아래로 튀어나왔다. 일부는 `HorizontalWrapMode.Overflow`라 자동 축소(best fit)가 가로로는 듣지 않았다.

공통 해결: `UIFactory.FitInFrame(text)`(테두리 안쪽 10px 여백 + 자동 축소, 최소 원래 크기의 60%·11 + 세로 잘림), `UIFactory.FrameRim = 12`.

| 화면 | 요소 | 문제 | 해결 |
|---|---|---|---|
| HUD | 자동 진행 / 자동 사냥 (F6/F7) | 키 표시가 버튼 오른쪽 테두리 위(-5px), 아이콘이 왼쪽 테두리 위(5px), "자동 진행 (12)"는 글자 칸(64px)보다 길어 두 줄로 꺾여 버튼 밖으로 | 버튼 132 -> 140px, 키 표시·아이콘을 테두리 안(12px)으로, 키 표시 자동 축소, 글자 칸 36/32px 여백 + 세로 잘림 |
| 모든 창 | `WindowScreen.Button`(탭, 확인, 구매, 페이지, 전직 화면 버튼 등 약 160곳) | 글자 칸 = 버튼 전체, 긴 글자는 테두리 위·두 줄 넘침 | `FitInFrame` (폭 70px 미만 버튼은 여백 6px) |
| 던전 HUD | 부활 / 포기 / 마을로 | 같은 문제 | `FitInFrame` |
| 대화상자·설정 | `MenuList` 줄 이름·값 | 긴 이름이 줄바꿈되어 다음 줄과 겹침 | 자동 축소 + 세로 잘림 |
| 스킬 바 | 키 이름·잠금 문구·MP(칸 58px로 줄어든 뒤) | 키를 "Space" 등으로 바꾸면 줄바꿈되어 칸 밖으로 | 자동 축소(최소 9) + 세로 잘림 |
| 스킬 창 | 노드 카드의 키 표시(34x26) | 긴 키 이름 넘침 | 자동 축소 |
| 버프 칸 | "방진 3회 120초" 등 | 칩(108px)보다 길어 오른쪽으로 넘침 | 자동 축소(최소 9) |
| 요일 던전 | 목록 줄 | 한 줄 고정(Overflow)이라 권장 레벨 등 긴 줄이 오른쪽 태그("오늘 개방")와 겹침 | 글자 폭을 태그 앞까지, 자동 축소 |
| 폰 | 메뉴 버튼, 터치 버튼 글자 | Overflow라 자동 축소가 가로로 안 들어 버튼 밖으로 | 줄바꿈 + 세로 잘림으로 바꿔 축소가 듣게, 메뉴 버튼은 테두리 안 여백 |

손대지 않은 것(테두리 없는 칸): 장비창 능력치 칸, 레이드 결과 칩, 각성 컷인 스킬 이름, 레이드 카드 "레전더리!", 상태 바 숫자, HUD 재화 숫자.

화면 확인 필요: 자동 버튼 두 개가 넓어져(합계 286px) 보스 막대가 뜬 좁은 화면(UI 크기 1.15/1.3)에서 퀘스트 칸(272px)보다 14px 왼쪽으로 나간다(화면 안이다).
