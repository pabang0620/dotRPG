# 파이터: 붉은 검압과 검은 잔상

2026-10-05 · jaein. 사용자가 첨부한 컨셉 이미지의 동작과 색 구조를 분석하고, 파이터 전용 투명 스프라이트를 새로 제작해 실제 스킬에 연결했다.

## 컨셉 분석

참고 이미지의 공통 흐름은 작은 불씨와 검 주위의 붉은 힘이 응축된 뒤, 주황색·아이보리색 중심선을 가진 두꺼운 검흔으로 방출되고, 검은 띠와 붉은 잔불로 소멸하는 것이다. 가로 베기, 원형 베기, 관통 검기, 지면 균열과 상승하는 힘이 각각 다른 실루엣을 만든다. 검은 띠는 빠른 움직임의 방향과 뒤따르는 잔상을 읽게 해 준다.

이 규칙을 게임의 도트 캐릭터와 위에서 조금 내려다보는 시점에 맞췄다. 원본 인물·문자·로고·개별 그림은 사용하지 않았다. 원화는 새 생성물이며, 게임 렌더러가 방향·스케일·프레임·흑적색 잔상을 제어한다. 생성된 원본 PNG를 게임에서 프레임으로 분리해 사용한다.

## 적용한 스킬

| 스킬 | 형태와 동작 | 유지한 판정 |
|---|---|---|
| 쌍참 | 작은 검압 → 주황색 칼날과 두꺼운 진홍색 초승달 → 찢긴 검은 잔상. 바라보는 앞쪽으로 제자리 1회 베기 | 전방 160도·2.8m, 대상당 1회 |
| 질풍관통 | 뾰족한 검기 응축 → 몸과 함께 전진하는 창끝 모양 검압 → 도착점에 집중된 충격 | 기존 4m 돌진 경로와 종료 지점 판정 |
| 회천검무 | 검과 몸이 함께 8방향을 돌며 큰 초승달 검흔이 한 바퀴 이동. 무거운 밝은 날과 검은 띠를 구분 | 반경 3.2m, 대상당 1회 |
| 삼중검파 | 검을 들어 내려찍기 → 지면의 압축 충격 → 동시에 뻗는 세 갈래 날카로운 균열 | 정면·좌우 24도, 최대 7m 관통 |
| 검신합일 | 작은 붉은 힘이 모여 위로 솟는 검압. 적용 순간을 크게 보여 주고 유지 상태는 기존 표시 사용 | 기존 6초 치명타 강화 |
| 발도·단공 | 짧고 응축된 준비 → 가는 주황색 절단선과 검은 띠가 전방으로 뻗음 → 붉은 파편 소멸 | 기존 8m·폭 1.4m와 체력 조건 |
| 천지일선 | 더 높은 검압 응축 → 긴 아이보리 절단선, 두꺼운 붉은 단층과 검은 띠 → 절단선에 분산된 잔불 | 기존 전방 18m·폭 3.6m, 진행되는 베기에 맞춰 명중 |

패시브 2개는 기존 조건과 상태 표시를 유지하며, 기존 적중/발동 피드백이 새로운 파이터 원화를 사용한다. 항상 번쩍이는 신규 패시브 효과는 추가하지 않았다. 다른 세 전직 직업과 기본 전사·마법사의 그래픽 리소스는 교체하지 않았다.

컨셉 적용 작업에서 스킬 수치나 판정을 확대하지 않았다. 직전 요청에서 쌍참 2타·회천검무 3타를 1타로 모은 피해 단위와 세 갈래 검기로 바꾼 동작은 유지하며, 해당 변경의 치명타·중첩 결과 차이는 [동작 변경 기록](FIGHTER-REVISION.md)에 설명했다. 카탈로그 ID, 비용·배율·쿨다운·시전 시간·거리·폭·지속 시간·전직 및 각성 조건은 비교 검사에서 동일했다.

## 실제 리소스와 코드

- `Assets/StreamingAssets/CareerRenewal/FighterConcept.png`: 내장 image_gen으로 새로 만든 1254×1254 RGBA 투명 원화. 4개 모티프 × 준비/방출/절정/잔상 4개 프레임. 기존 Fighter.png는 이전 원화로 보존하며 새 코드에서는 FighterConcept을 로드한다.
- `Assets/StreamingAssets/CareerRenewal/FighterConcept.frames.json`: 원본의 불규칙한 투명 여백을 분석한 16개 프레임 경계. PNG 자체는 변형하지 않았다.
- [생성 프롬프트](FIGHTER-CONCEPT-PROMPT.json): 사용 도구, 참고 이미지 역할, 전체 프롬프트 기록.
- `Assets/Scripts/Runtime/Art/CareerPulseArt.cs`: 파이터 전용 새 원화 로딩, Point/Clamp, mipmap 없이 1회 캐시.
- `Assets/Scripts/Runtime/Art/CareerRenewalFx.cs`: 전방/회전 검흔, 빠른 방출→절정→소멸, 흑적색 잔상, 준비 밝기 변화.
- `Assets/Scripts/Runtime/Combat/CareerCombat.cs`, `CareerCombat.Renewal.cs`: 몸·오른손 검의 준비/타격 자세 연결, 지면 충격과 세 갈래 검기, 실제 코루틴과 동기화한 효과.
- `Assets/Scripts/Runtime/Art/CareerPaintEffect.cs`: 검신합일 원화의 상승 방향 정렬. 적중 파편과 각성 단층 연출은 새 모티프를 사용한다.
- `Assets/Scripts/Runtime/Core/DevCapture.Career.cs`, `DevCapture.Pulse.cs`, `DevCapture.Renewal.cs`: 새 원화 로딩, 8방향 정렬, 자세 연결, 버프 및 효과 종료 검사와 7스킬 실제 화면 캡처.

화면에 연결된 파이터 효과는 실제 제작 리소스이며 이번 적용에 임시 대체 이미지는 없다. 네이티브 해상도와 최근접 보간을 사용한다. 신규 효과는 기존 합계 80개 제한과 적중 실루엣 32개 제한 안에서 재생된다. 이번 원화 교체로 프레임마다 텍스처를 생성하지 않는다.

런타임과 에디터 코드를 컴파일했고, 바탕화면 「dotRPG 만렙 4직업 체험」이 가리키는 기존 플레이어에 최신 DLL, 새 PNG 및 프레임 JSON을 반영했다. 전체 Unity 플레이어를 새로 빌드한 것은 아니다. 이번 작업의 실제 온라인 2클라이언트 전투와 다수 플레이어 동시 사용 성능은 미검증이다.
