# 전직 이펙트 재제작 — 2026-10-05

후속 해상도 개선은 [VFX5](VFX5.md)를 참고한다. 아래는 96px 재제작 단계의 기록이다.

히어로·미하일·비숍·배틀메이지 참고 게시글에서 검격의 두께, 방패의 구조, 원소의 대비, 날개의 전개를 분석하고 dotRPG용 픽셀 원화를 새로 제작했다. 참고 GIF의 프레임이나 픽셀을 가져오지 않았다. 이전 VFX3 위에 적용한 현재 버전이다.

## 적용 내용

| 직업 | 새로운 형태와 움직임 |
|---|---|
| 파이터 | 강철색 절삭면, 진홍색 검기와 짧은 잔상. 쌍흔은 교대 검격, 삼연은 평행 잔상, 갑주 가르기는 금속 파편, 돌파/일점은 좁은 관통 형태. 오검 마지막 타격에 교차 결정타 |
| 수호자 | 은색 테두리·남청색 면·청록 문장의 방패. 동료의 방벽은 쌍방패, 결계는 중앙 문장과 돔, 호령은 깃발과 지면 파동, 반격은 바깥으로 방출되는 강철 파편. 각성에는 큰 방패와 보조 방벽 |
| 메이지 | 분절된 비전 룬을 공통 기반으로 사용. 화염은 상승하는 룬창, 냉기는 면이 있는 결정, 번개는 분기 전류, 비전 궤도는 결정 궤적, 균열은 어두운 내부와 밝은 가장자리. 삼원 일식은 실제 세 타격에 화염·냉기·번개를 방출한 뒤 일식 핵 |
| 비숍 | 깃줄과 색 단계가 있는 날개, 생명의 잎, 입체 종, 좁은 빛의 화살. 회복 명중 프레임부터 빛의 씨앗이 나타나고 잎이 퍼짐. 각성은 열린 성역 아치·날개·후광을 전개 |

- 24개 일반 액티브 및 4개 각성기에 연결했다. 기존 8개 패시브의 조건부 표시 정책과 스킬 아이콘은 유지했다.
- 96×96 프레임, 12프레임 RGBA 시트, 48 PPU, 최근접 보간, 무압축. 큰 흐림 대신 명확한 면과 색 단계로 그렸다.
- 등장 준비는 기존 시전 시간에, 타격과 회복의 명중 효과는 기존 실제 판정 이벤트에 연결한다. 명중 원화는 첫 프레임부터 보인다.
- 캐릭터 앞뒤를 지나는 주효과는 위쪽과 아래쪽 원화를 분리하여 후면·전면 순서로 렌더링한다. 날개와 방패가 캐릭터 얼굴을 가리는 문제를 줄였다.
- 주효과의 픽셀은 중심에서 43.75픽셀 이내에 있다. 월드 크기는 기존 43픽셀 반경 환산을 사용하며 차이는 래스터 반올림 여백이다. 장식 중심 원화는 큰 광역 판정보다 작게 유지하고 실제 판정 경계는 별도로 표시한다.
- 시트 주효과 외의 작은 명중 파편은 장식이다. 넓은 판정 경계처럼 그리지 않는다.
- 일회성 효과의 추가 파편은 준비/명중 4개, 일반 주효과 6개, 각성 주효과 10개로 제한했다. 확대된 발광 복제층을 제거하여 도트 테두리를 보존했다.

## 코드와 실제 리소스

- `Assets/Scripts/Runtime/Art/CareerVfxArt.Reforged.cs`: 새로운 검흔, 방패, 깃털, 원소, 명중·시전 원화와 프레임 전개. 정수 좌표 래스터 제작 소스.
- `Assets/Scripts/Runtime/Art/CareerVfxArt.cs`: 새 원화로 연결, 기존 상태 표시와 정확한 반경 경계.
- `Assets/Scripts/Runtime/Art/CareerArt.cs`: 새 리소스 경로, 후면/전면 렌더링, 방향, 발광·파편 조정.
- `Assets/Scripts/Runtime/Combat/CareerPresentation.cs`: 여명의 화살 원화를 실제 명중 위치와 방향에 추가 연결.
- `Assets/Scripts/Editor/CareerAssetExport.cs`: Unity 메뉴 `dotRPG/Export Career Art`로 동일 원화를 재생성.
- `Assets/Scripts/Runtime/Core/DevCapture.Career.cs`: 반경, 레이어 복원, 첫 프레임 표시 검증 추가.
- `Assets/Resources/Art/Careers/Reforged/`: 실제 사용 PNG 136개, 총 1,632프레임. Effects 28개, Details 8개, Presentation 44개, Layered 56개. 후면/전면 시트는 주효과를 분리한 파생 리소스이며 별개의 56개 스킬을 뜻하지 않는다.
- `Assets/Resources/Art/Careers/manifest.json`: 신규 리소스 경로와 해시.

임시 이미지나 미연결 컨셉 이미지가 아닌 게임에 연결된 제작 리소스다. 로컬 검증 플레이어의 기존 Resources 번들에는 새 경로가 없으므로 PNG를 만드는 **동일 C# 래스터 제작 소스의 메모리 스프라이트 경로**로 재생했다. 완전한 Unity 빌드에서는 신규 PNG를 Resources에서 로드한다.

## 검증

- [런타임 결과](VFX4/runtime-results.txt): **369 통과, 0 실패**. 실제 28개 스킬 효과, 전직/각성 제한, 자원·쿨다운 제한, 보호막 소모·만료, 효과 수 제한, 사망·맵 이동 정리 포함.
- 주효과 28개 × 12프레임의 반경 제한과 앞뒤 레이어를 합쳤을 때 원화와 동일함을 검사했다. 투명 PNG 136개 전부의 캔버스 여백도 검사했다.
- [불변 파일 검사](VFX4/invariants.json): 이번 작업 시작 시점 대비 CareerCombat, 기본 SkillEffects, 직업 데이터·수치, 전직 진행, SkillCaster, 서버 스킬 데이터의 SHA-256이 동일하다. 피해·회복·범위·소모·쿨다운·실제 타격 간격은 변경하지 않았다.
- [Runtime 컴파일](VFX4/compile.txt) 및 [Editor 컴파일](VFX4/editor-compile.txt) 통과. 기존 API 경고는 남아 있다.
- 테스트는 시작 전에 AudioListener 볼륨 0, 실행 중 BGM·효과음 볼륨 0으로 진행했다. 일반 플레이의 저장된 음량 설정은 변경하지 않았다.
- 바탕화면 `dotRPG 전직 체험` 바로가기 대상의 Runtime DLL에 최종 코드를 반영했다. 네 직업 체험 저장 파일은 유지했다.
- 전체 Unity 임포트/배포 빌드는 이번에 수행하지 않았다. 기존 세션에서 Unity 라이선스 오류가 있었으며, 이번 실행 검증은 기존 로컬 플레이어와 새 Runtime DLL을 사용했다.
- 실제 두 PC의 온라인 동시 전투와 저사양 PC FPS는 미측정이다. 이번에 수정하지 않은 서버 테스트는 반복하지 않았다.
