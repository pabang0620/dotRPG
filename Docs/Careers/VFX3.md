# 전직 전용 이펙트 · 판정에 맞춘 연출

이번 변경은 전직 4종의 36개 스킬을 확인하고, 24개 액티브와 4개 각성기의 시전·명중·유지 표현을 연결한 작업이다. 기본 전사·마법사의 그래픽 호출은 전직 작업 이전 `cab85da` 상태와 동일하게 복구했다. 기존 VFX v2 기록은 과거 결과이며, 현재 결과는 이 문서를 기준으로 한다.

보호막은 생성·유지·흡수 충격·소모 또는 만료 후 짧은 소멸 단계를 갖는다. 마지막 소멸은 시각 효과만 0.22초 남으며 보호막 판정은 연장되지 않는다. 작은 중앙 문양과 실제 반경 경계를 별도로 그려 장식의 크기를 판정 범위로 오해하지 않도록 했다. 돌진과 즉시 타격은 시각용 잔상이 생겨도 판정을 지연하지 않는다.

## 실제 리소스와 코드

- [CareerVfxArt.cs](../../Assets/Scripts/Runtime/Art/CareerVfxArt.cs): 기존 28개 주효과에 더해 28개 개별 명중·10개 상태·경계·검흔·결정타의 총 41개 시트를 직접 픽셀 좌표로 제작한다.
- [Presentation PNG](../../Assets/Resources/Art/Careers/Presentation): 1152×96 RGBA 시트, 96×96 프레임 12개, 중심 피벗, Point 보간. 유지 상태처럼 움직임이 불필요한 시트는 같은 프레임을 유지한다.
- [CareerArt.cs](../../Assets/Scripts/Runtime/Art/CareerArt.cs): 리소스 로딩·캐시, 방향, 짧은 잔상, 제한된 파편 메시, 소멸 처리.
- [CareerPresentation.cs](../../Assets/Scripts/Runtime/Combat/CareerPresentation.cs): 판정 시점의 연출, 실제 반경 표시, 연결선, 도발 표식, 기존 상태값을 읽는 표시 전용 컴포넌트.
- [CareerCombat.cs](../../Assets/Scripts/Runtime/Combat/CareerCombat.cs): 기존 판정 직후 시각 이벤트 호출. 전투 수식·대상 선택·타격 간격 유지.
- [SkillEffects.cs](../../Assets/Scripts/Runtime/Combat/SkillEffects.cs): 기본 스킬에 추가됐던 전직 공용 호출 9곳 제거.
- [CareerAssetExport.cs](../../Assets/Scripts/Editor/CareerAssetExport.cs): Unity 메뉴에서 동일 PNG를 재생성.
- [DevCapture.Career.cs](../../Assets/Scripts/Runtime/Core/DevCapture.Career.cs): 실제 스킬·상태·정리 검증과 비교 캡처.
- [DevCapture.cs](../../Assets/Scripts/Runtime/Core/DevCapture.cs): 자동 검증 모드는 시작 전에 AudioListener 볼륨 0, 시작 시 음악·효과음 볼륨 0 적용. 일반 플레이 설정은 저장 변경하지 않는다.

새 PNG는 임시 대체 이미지가 아닌 게임에서 사용하는 실제 제작 리소스다. 다만 현재 로컬 검증 플레이어는 새 Unity Resources 번들을 만들 수 없는 환경이므로, PNG와 **같은 제작 코드가 만드는 메모리 스프라이트** 경로를 실행했다. 이미지 생성 서비스의 컨셉 이미지나 미연결 목업은 사용하지 않았다.

## 확인 결과와 한계

- [실행 결과](vfx3-runtime-results.txt): 게임 내 **282개 통과, 0개 실패**. 28개 스킬의 실제 공격/회복/보호막, 각성 제한, 전직 저장, 도발/시련, 스프라이트 조회 포함.
- 추가 검사: 전투 RNG 보존, HP·MP·timeScale 비변경, 정확한 반경 스케일, 보호막 소모/만료, 효과 최대 96·경계 24·연결선 40 제한, 부하 후 정리, 맵 이동 및 사망 정리.
- 마지막 파편 여백 조정 후 [리소스 재생 및 촬영 검사](vfx3-preview-results.txt)를 다시 실행했다. 새 41개 시트의 492프레임은 모두 투명 여백을 가지며 캔버스 가장자리에 닿는 픽셀이 없다.
- [변경 금지 파일 해시 확인](vfx3-invariants.json): 전직 정의·수치 계산·사용 조건·시전 시스템·서버 스킬 데이터 7개 모두 동일. 기본 SkillEffects는 `cab85da`와 동일. 기본 아이콘·애니메이션 리소스 변경 없음.
- Runtime·Editor C# 컴파일과 서버 TypeScript 빌드 통과. 전직·캐릭터 서버 테스트 57개 통과.
- 서버 전체 테스트는 556개 통과/35개 실패. 수정 전 원격 `8aaa38e`에서도 같은 35개가 실패한다(543개 통과). 사냥터 수치 기대값·레이드 키·Windows의 SIGTERM/Bash/파일 권한 관련 실패로, 전직 VFX 작업에서는 변경하지 않았다. 로그는 함께 보관한다.
- Unity 전체 임포트·배포용 빌드는 라이선스 오류로 미검증. 로컬 실행은 기존 플레이어에 새 Runtime DLL을 적용했다.
- 실제 두 PC 온라인 동기화, 저사양 하드웨어의 정량 FPS 측정은 미검증. 네트워크 멤버의 예측 연출은 HP/보호막 값을 수정하지 않으며, 호스트가 판정을 유지한다. 지속 상태의 원격 표시 정확도는 실접속 검증이 추가로 필요하다.
- 사망/맵 변경/시간 만료 시 일회성 객체와 메시를 제거한다. 배우당 최대 6개 상태 렌더러와 1개 패시브 렌더러는 재사용하며 숨김 상태로 보관한다. 스프라이트·공용 재질은 제한된 캐시로 유지하므로 메모리를 전부 0으로 돌려놓는 설계는 아니다.
- 개별 효과의 규모와 알파를 조절해 캐릭터가 보이도록 했으며, 새로운 히트스톱·조작 잠금·전체 화면 점멸은 추가하지 않았다. 기존 각성 카메라 흔들림 호출과 설정을 유지했다.

## 저장 및 실행

요청에 따라 이번 정밀 개선 **이전** 상태를 `b3253dc`로 커밋했고, 원격 변경을 병합한 `5f60f6f`를 `origin/jaein`에 푸시했다. 이번 VFX v3는 `jaein` 작업 디렉터리에 남겨 구분했다.

바탕화면의 `dotRPG 전직 체험` 바로가기 대상에 최신 Runtime DLL을 반영했다. 기존 40레벨 네 직업 저장 파일은 유지한다. 체험 모드는 자동 검증과 달리 사용자 볼륨 설정을 유지한다.
