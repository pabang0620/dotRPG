# 전직 · 스킬 · 각성 구현 명세

기준: 최고 레벨 40, 기존 공격력 A = (직업 기본 공격력 + 장비 공격력) × 동료 배율 × (1 + 증가 피해/100), 최종 단계에서 정수 반올림, H = 대상 최대 HP. 별도 자원 없이 기존 MP 사용.

전사 → 파이터 / 수호자, 마법사 → 메이지 / 비숍. 15레벨에 자동 전직하지 않으며 스킬창에서 비교 → 선택 → 확정한다.

## 포인트와 호환

15레벨 전직 4P, 이후 레벨당 1P(40레벨 29P). 각 분기: 패시브 → 입문 액티브 → Lv.18 액티브 → Lv.22 액티브. 각 노드는 3단계, 비용 1/2/3P. 선행 노드는 1단계만 필요. 초기화는 전액 반환한다. 각성은 별도 영역이며 비용이 없다.

옛 노드 투자 효과는 legacy training으로 보존하고, 소비한 포인트를 전직 포인트에 한 번 환급한다. 보조 젬과 기본 스킬 레벨 조건을 보존한다. 옛 blades/meteor는 더 이상 사용하거나 장착할 수 없다. 새 각성 퀘스트가 자동 완료되지 않는다.

전직 스킬은 위력·범위·효율 보조 젬만 적용한다. 연타·흡혈·보스 젬은 기본 스킬에서 계속 사용한다. 슬롯을 옮겨도 스킬 ID 기준 쿨다운을 유지한다.

## 시련 시작과 진행

각 마을 광장의 전직 안내원 또는 스킬창 → 각성 이야기. 퀘스트창에서도 바로 이동할 수 있다. 마을에서 대화 2단계 → 역할 시련 → 깨달음 → 마무리 대화 순서로 각성한다. 온라인 파티에서는 솔로 시련 시작을 막는다. 혼자 진행할 때 아이비와 훈련 환영을 제공한다. 실패/맵 이탈 시 2단계가 유지되어 재도전 가능하다. 진행 단계와 완료 플래그는 저장된다.

|직업|기록 속 지도자|시련|각성 상징|
|---|---|---|---|
|파이터|카엘|4초 주기의 2초 틈에 연속 5회 실제 적중|다섯 검흔|
|수호자|레오나·아이비|2회 실제 도발, 보호막 흡수 40, 20초 동료 생존|이름을 품은 육각 방벽|
|메이지|약초꾼 오르|화염 룬창→서리 결정진→뇌광 공명 실제 적중|세 원소의 궤도|
|비숍|아이비|정화 1회, 실제 회복 90, 보호막 흡수 25, 20초 생존|새잎과 날개|

시련의 전체 대사와 각성 직후 안내는 `CareerTrials.Story`에 들어 있다. 수호자 시련은 Lv.18·5개 노드, 메이지는 Lv.22·4개 노드, 비숍은 Lv.22·7개 노드의 1단계만 필요하다. 전체 노드/최대 강화는 요구하지 않는다.

## 공통 전투 규칙

직접 공격은 치명·갑주 표식·축복을 적용한다. 화상과 반격은 2차 피해로 표시하여 패시브 재귀 발동을 막는다. 보호막은 합산 대신 현재값과 새 값 중 큰 값을 유지하며 지속 시간을 갱신한다. 피해 감소는 별도 효과 합산 최대 65%(기존 기본 감소 이후). 회복은 최대 HP를 넘지 않는다. 도발은 기본 일반 적 4초/보스 1.2초에 단계·위력 젬을 곱하고, 이후 누적 위협으로 선정한다.

액티브 2/3단계는 주요 위력 ×1.12/×1.24. 공격/회복은 A×배율×단계×위력 젬, 보호막은 H×비율×단계×위력 젬. 방어 자세·치명 버프·축복 역시 단계와 위력 젬을 적용한다. 불굴의 결계/각성의 추가 감소 20%/35%, 반격 자세의 감소 25%는 고정이다. 범위 젬은 넓이에 적용(반경 √배율). 기존 MP 감소/공격속도 쿨다운 보정도 적용한다.

## 리소스와 검증

아이콘은 32×32 PNG 36장. 액티브/각성은 투명 96×96×12프레임 시트 28장. `CareerArt.cs`의 정수 픽셀 제작 원본에서 직접 출력했다. 런타임은 Resources PNG를 우선 로드하며 이전 로컬 플레이어에서는 동일한 제작 원본으로 재생한다. AI 임시 대체 이미지나 외부 참고 이미지 복사본은 없다.

미리보기: `icons_36_preview.png`, `effects_28_preview.gif`. 실제 플레이 캡처는 `captures/`, 전체 런타임 결과는 `runtime-results.txt`, 검증 범위와 제약은 [VALIDATION.md](VALIDATION.md), 대사는 [STORIES.md](STORIES.md) 참조.

배포에는 새 클라이언트 + 서버 빌드 + `0014_careers.sql` DB 마이그레이션이 함께 필요하다. 파티 와이어 버전은 6으로 올려 구버전과의 메시지 오독을 막는다.


## 그래픽 연결·재생 규격

`Assets/Resources/Art/Careers/manifest.json`에 스킬별 PNG 경로, 공통 캔버스·피벗·필터를 기록한다. 32×32 아이콘은 잠금·선택 프레임과 분리했다. 효과 시트는 왼쪽부터 12프레임, 일반 타격 0.55초(약 21.82fps), 각성 주 연출 1.15초(약 10.43fps), 시전 예고는 해당 시전 시간에 맞추며 반복하지 않는다. 지속 회복·다단히트는 실제 적용 시점에 별도 효과를 재생한다. Point 필터, 무압축, 밉맵 없음, 중심 피벗(0.5,0.5). 검격·방패 돌진·빛의 화살은 방향 회전, 원형 장판은 중심 고정이다.

제작 원본은 `CareerArt.cs`, Unity 메뉴 `dotRPG/Export Career Art`로 다시 내보낼 수 있다. 모든 신규 아이콘과 효과는 실제 PNG로 저장·연결되어 있으며 임시 이미지로 분류된 파일은 없다. 기존 기본 직업의 인물 컷인은 재사용하고, 직업별 각성 문양·색·명칭·오라를 새로 적용했다. 새 직업 인물 초상화나 영상 컷신을 제작한 것은 아니다.

## 밸런스 기준

새 자원이나 전용 능력치는 추가하지 않았다. 장비 포함 기존 공격력과 최대 HP를 사용하므로 기존 레벨·장비 성장에 따라 피해/회복/방어가 함께 증가한다. 포인트는 레벨 15에서 4P로 두 분기의 패시브와 첫 액티브를 선택 가능하며, 최고 40에서 기본 29P로 8개 노드의 총 48P 투자에 선택이 남도록 했다(이전 노드 환급은 별도).

1단계·보조 젬·패시브 제외 이론치: 파이터 질풍 삼연은 A×5.25/11초, 메이지 뇌광 공명은 대상별 A×3.6/10초로 최대 4대상, 비숍 여명의 화살은 단일 A×2.5/4초다. 수호자는 공격 배율보다 피해 감소와 H 비례 보호막에 예산을 배분했다. 이는 초기 수치이며 실제 전투에서는 MP·캐스팅·사거리·장비·적 방어·치명·동료에 따라 달라진다. 장시간 실전 밸런스 측정은 별도 필요하다.
