# 스킬 체계 v2 (2026-10-03 개편)

계산 근거: `python3 Tools/balance/theory_skills.py` (개편 전후 표를 함께 출력)

## 1. 왜 바꿨나

- v1은 10개 스킬이 모두 범위·연쇄 공격이었다. 단일 대상 스킬이 없어 보스전에서는 기본 공격이 스킬보다 나았다.
- 번개 사슬·빙뢰구가 무리 상대 기본 공격의 340% 안팎으로 압도적이었고, 서리 폭발과 빙뢰구를 번갈아 쓰면 일반 몬스터를 약 90% 얼려 둘 수 있었다.
- 범위 보너스가 반지름에 곱해져 +35%와 +25%만 겹쳐도 면적이 2.85배가 됐다.
- 다섯 슬롯이 Lv2~10, 플레이 약 2.3시간 안에 모두 열렸다. 중간 레이드(약 20시간)까지 새 스킬이 없었다.

## 2. 원칙

| 원칙 | 내용 |
|---|---|
| 슬롯마다 역할 하나 | 1 단일 주력 / 2 범위 / 3 제어 / 4 방어 / 5 각성 |
| 범위기는 직업당 하나 | 각성기를 빼면 범위 공격은 2번 슬롯뿐 |
| 범위기 1마리당 피해 | 단일기의 약 60%. 무리 3마리 이상일 때만 단일기보다 이득 |
| 해금 분산 | Lv 2 / 6 / 12 / 18 / 22 (약 0 / 0.6 / 4 / 11 / 20시간). 각성은 중간 레이드가 열리는 Lv22 |
| 범위 보너스 | 면적에 곱한다(반지름은 제곱근). +35%·+25% 겹쳐도 면적 1.69배 |
| 연속 제어 점감 | 일반 몬스터도 6초 안에 다시 기절·빙결되면 지속시간이 절반씩 준다(1, 1/2, 1/4 ...). 보스는 기존대로 0.3배 |

## 3. 스킬표

| 슬롯 | 전사 | 마법사 | 수치 (피해 배율 / 재사용 / MP) |
|---|---|---|---|
| 1 단일 주력 (Lv2) | 파쇄 일격: 앞의 적 하나를 내려친다 | 번개 창: 가장 가까운 적 하나에 낙뢰 | 3.2 / 2.5초 / 6 · 3.0 / 2.5초 / 6 |
| 2 범위 (Lv6) | 회전 베기 (반지름 1.6) | 빙뢰구 (부딪힌 자리 반지름 1.6, 빙결·연쇄 없음) | 2.0 / 5초 / 14 · 1.9 / 5초 / 14 |
| 3 제어 (Lv12) | 전쟁 함성: 기절 1초, 어그로, 피해 +20% 6초 | 서리 폭발: 빙결 1.2초 | 0.4 / 14초 / 18 |
| 4 방어 (Lv18) | 철벽: 받는 피해 -40% 4초 | 마나 보호막: 받는 피해 -40% 4초 | - / 16초 / 12 |
| 5 각성 (Lv22) | 천검 강림 | 메테오 | v1과 같음 |

방어 슬롯(4번)의 패시브 노드는 방어 스킬에 맞게 바뀐다: 피해 노드 → 감소율(값의 1/4), 범위 노드 → 지속시간. 추가 발동은 적용되지 않는다.

## 4. 보조 젬

| 젬 | 해금 | 효과 |
|---|---|---|
| 추가 피해 | Lv3 | 피해 35% 증폭, MP 30% 증가 |
| 마력 효율 | Lv5 | MP 30% 감소 |
| 범위 확대 | Lv7 | 면적 35% 증폭, MP 15% 증가 |
| 흡혈 | Lv8 | 입힌 피해의 10% 회복 |
| 연속 시전 | Lv10 | 한 번 더 발동, 피해 30% 감소, MP 40% 증가 |
| 보스 사냥 | Lv14 | 보스에게 주는 피해 30% 증폭 (v1의 추가 연쇄 자리, 같은 id `sup_chain`이라 저장 데이터 호환) |

## 5. 동료 AI

- 탱커 브론: 전쟁 함성 → 철벽 → 파쇄 일격
- 검사 카이·카엘: 각성 → 파쇄 일격 → 회전 베기
- 빙결 엘린: 서리 폭발 → 마나 보호막 → 빙뢰구 → 번개 창
- 번개 세라: 각성 → 번개 창 → 빙뢰구
- 범위기(회전 베기·빙뢰구)는 3마리 이상 모였을 때만, 방어 스킬은 체력 70% 아래에서 적이 가까울 때(탱커는 어그로를 잡고 있을 때도) 쓴다.
