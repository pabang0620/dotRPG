# Steam 등록 진행 기록 — 2026-10-15

## 작업 분담

게임 코드·콘텐츠 수정과 검증은 다른 세션에서 진행 중이다. 이 세션은 등록 절차와 입력 자료를 담당한다. 결제는 진행하지 않는다. 게임의 판매 모델이나 인앱결제 기능을 임의로 변경하지 않는다.

## 확인한 상태

- Steam Guard 인증 완료 후 대시보드를 확인했다. 계정에 신규 파트너 가입 안내가 표시되며, 개발자/퍼블리셔 등록을 선택해 `Legal Name & Address` 입력 화면까지 진행했다. 현재 법적 이름·사업 형태·주소·정산 알림 이메일 입력 대기다. 제출·계약 동의·결제는 하지 않았다.
- dotRPG HEAD: `41c9d226` — 캐시 아이템 가치 기획. 이전 커밋에 보스 체력바 위치 변경이 있다.
- starspire HEAD: `9bc0936` — 이름 제한, 확률 공개 기록·검증, 계정 삭제·청소년 보호·게임시간 선택제 반영.
- 작업 트리에도 수정이 진행 중이다. 10월 14일의 테스트 통과 수치를 현재 버전의 검증으로 간주하지 않는다.
- dotRPG 운영 주소는 빈 값, starspire 소스 App ID는 0이다. 이 사실만으로 Steam 계정에 앱이 없다고 단정하지 않는다.

## 로그인 후 진행할 순서

1. 기존 파트너 등록 여부, 접근 가능한 앱, 미사용 앱 크레딧을 확인한다. 기존 앱이 있으면 중복 생성하지 않는다.
2. dotRPG·캐릿터 키우기(기술 프로젝트 starspire)의 App ID와 depot, 스토어 초안 상태를 기록한다.
3. 기존 앱에서 입력 가능한 스토어 초안을 준비한다. 계정 등록 미완료라면 현재 단계와 필요한 실제 정보를 확인한다.
4. 비용 지출 화면에서는 중단한다. 법적 계약·신원·세금·은행 정보는 임의로 작성하거나 동의하지 않는다.

소개문은 변경 중인 게임 규칙과 대조 후 입력한다. 특히 dotRPG 기존 소개의 레이드 요일·동료 필드 합류·스킬 수는 최신 확정 사양으로 검증하기 전 게시하지 않는다. 언어 파일의 존재를 번역 완료로 취급하지 않는다. 실제 Steam에서 미검증인 Cloud·업적·온라인 기능도 확정 표시하지 않는다.

공개 개발사 표시명과 계약상 법적 이름은 별개다. 기존 문서의 브랜드명으로 계약 주체를 추정하지 않는다. 개인/사업자 구분, 법적 이름·주소, 수익 정산 계좌·세금 정보는 계정 소유자가 정확한 자료를 제공해야 한다. 인증코드·비밀번호는 채팅이나 저장소에 기록하지 않는다.

## 결제 제외에 따른 경계

공식 안내상 새 앱마다 Steam Direct 수수료가 필요하다. 미리 결제한 앱 크레딧이나 기존 앱이 있는지 로그인 후 확인해야 하며, 둘 다 없다면 비용 없이 앱 등록 전체를 완료할 수는 없다. 이번 작업에서 새 결제는 하지 않는다.

공식 자료(2026-10-15 확인):

- https://partner.steamgames.com/doc/gettingstarted/onboarding
- https://partner.steamgames.com/doc/gettingstarted/appfee

실제 계정 화면에서 완료를 확인하기 전까지 등록·심사·공개를 완료로 기록하지 않는다.

현재 계정 화면의 순서: 이름/주소 → NDA → SDA → 수수료 → 정산/세금 정보 → 등록 완료. 따라서 이 계정에서는 게임별 스토어 편집보다 파트너 가입이 먼저다. 등록 화면은 결제 후 출시 대기 기간을 30일로 표시해 공개 문서의 21일 안내와 다르므로, 확정 출시일을 이 기록에서 계산하지 않는다.

## 후속 진행 결과

사용자가 NDA 단계를 직접 진행했다. 사용자가 전화번호와 CAPTCHA를 입력하고 SDA 동의·제출을 명시적으로 승인한 후, SDA의 동의 항목 3개를 체크하고 제출했다. 저장 처리 후 `Pay Fee / Product Submission fee` 화면으로 이동한 것을 확인했다. 이 화면의 Continue는 Steam 상점 결제 화면으로 이동하는 버튼이므로 누르지 않았다. 수수료 결제, 정산·세금 입력, 파트너 등록 완료 및 게임별 앱 생성은 아직 진행하지 않았다. 계약 제출과 Valve의 최종 수락은 구분한다.
