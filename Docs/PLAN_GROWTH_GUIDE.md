# 성장 추천 (퀘스트가 없을 때)

다음 퀘스트가 더 높은 레벨을 요구해서 지금 할 퀘스트가 없을 때, 무엇을 하면 레벨이 오르는지 HUD와 퀘스트 창에서 알려 주고 자동 진행이 추천 사냥터에서 사냥을 이어 가게 한다. 공백 구간과 길이는 `Docs/PLAN_QUEST_GAPS.md`를 따른다. 서버는 바꾸지 않았고, 클라이언트에 이미 있는 데이터(퀘스트, `HuntingGrounds`, `DungeonDatabase`, `DungeonProgress`, `DailyQuestClient`)만 쓴다.

## 언제 나오는가

- 메인·서브 퀘스트 중 진행 중, 보고 대기, 수락 대기인 것이 하나도 없을 때 (`GrowthGuide.Active`).
- 다음 퀘스트 레벨은 잠긴 퀘스트 중 선행 퀘스트와 플래그는 이미 채웠고 레벨만 모자란 것의 가장 낮은 `minLevel`이다 (`GrowthGuide.NextQuestLevel`).
- 판정은 0.5초마다 다시 하고, 레벨이 바뀌거나 퀘스트가 바뀌면 바로 다시 한다.

## 추천 순서

| 순서 | 항목 | 고르는 법 | 버튼 |
|---|---|---|---|
| 1 | 요일 던전 | 오늘 열린 요일 던전 중 내 레벨 지역(숲·협곡·설원)의 것을 먼저, 오늘 남은 입장이 1회 이상일 때만 | 던전 창 열기 (요일 던전 탭, 해당 던전·난이도 선택) |
| 2 | 일반 던전 | 내 레벨 지역의 일반 던전(해골 광산 소굴, 안개 낀 묘지, 얼어붙은 회랑). 매일, 횟수 제한 없음 | 던전 창 열기 (일반 던전 탭) |
| 3 | 사냥터 | 내 레벨 이하 최소 레벨 중 가장 높은 사냥터. 분당 경험치는 `KillXp x 12` (`HuntingGrounds.KillsPerMinute`) | 추천 사냥터로 자동 사냥 |
| 4 | 일일·주간 의뢰 | 온라인에서 의뢰가 열려 있고 아직 받지 않았거나 보상을 받지 않은 것이 있을 때 | 의뢰 창 열기 |
| 5 | 파티 사냥 | 온라인일 때 안내만 한다. 처치 경험치 2인 +15%, 3인 +30%, 4인 +50% | 없음 |
| 6 | 등록된 추가 콘텐츠 | `GrowthGuide.RegisterSource`로 등록한 것 (미니 던전 자리) | 등록한 쪽이 정한다 |

- 던전 난이도는 권장 레벨(일반 5, 모험 12, 왕 20, 영웅 27)을 넘긴 것 중 가장 높은 것이다. Lv5 미만이면 던전 항목은 나오지 않는다.
- 지역은 추천 사냥터의 테마로 정한다. Lv1~12 숲, Lv13~24 협곡, Lv25부터 설원 (성소·지하도 포함).

## 화면

- **HUD 퀘스트 알리미**: 성장 추천이 켜지면 빈 알리미 대신 카드로 바뀐다.
  - 제목: `성장 추천 · Lv23 → 다음 퀘스트 Lv25`
  - 내용: `추천: 얼어붙은 회랑(모험) / 서리 소나무 숲 사냥터`, 그 아래 한 줄 안내
  - 자동 진행 버튼 이름이 `추천 사냥`으로 바뀐다. 누르면 추천 사냥터로 가서 사냥한다.
  - 레벨이 오르면 바로, 그 밖에는 5초마다 다시 그린다 (오늘 남은 입장 반영).
- **휴대폰**: 알리미가 접혀 있을 때는 제목 한 줄만 보이므로 짧은 제목 `성장 추천 Lv23 → 25`를 쓴다. 펼치면 PC와 같은 내용이 나온다.
- **퀘스트 창**: 상세 칸 왼쪽 아래 `성장 추천` 버튼으로 전환한다. 성장 추천이 켜진 상태에서 창을 열면 처음부터 이 화면이 나온다. 항목은 최대 6개를 순서대로 보여 주고, 각 줄 오른쪽에 버튼이 있다. 목록의 퀘스트를 고르거나 `퀘스트 보기`를 누르면 원래 상세로 돌아간다.

## 자동 진행

- 따라갈 퀘스트가 없을 때 멈추지 않는다.
  - 성장 추천이 켜져 있으면 추천 사냥터로 걸어가서 자동 사냥을 한다.
  - 받을 수 있는 서브 퀘스트가 남아 있으면(체크·추적하지 않은 것) 그것들을 이어서 진행한다.
  - 둘 다 아니면 예전처럼 `따라갈 퀘스트가 없습니다.`로 멈춘다.
- 사냥 중 1초마다 확인한다.
  - 받을 수 있는 퀘스트가 생기면(레벨 도달) 사냥을 끝내고 퀘스트로 돌아간다.
  - 레벨이 올라 더 높은 사냥터가 추천되면 그곳으로 옮긴다.
- 서브 퀘스트 자동진행에서 서브 퀘스트를 다 마쳤을 때도 성장 추천이 켜져 있으면 추천 사냥터에서 사냥을 이어 간다.
- 메인 퀘스트가 레벨에만 막힌 경우(`LevelGate`)는 기존대로 퀘스트 사냥으로 처리한다. 사냥터 선택은 성장 추천과 같은 `GrowthGuide.BestZone`을 쓴다.
- 아무 키나 누르면 멈추는 것은 기존과 같다.

## 확장 지점: `GrowthGuide.RegisterSource`

2026-10-18: 미니 던전이 이 지점으로 연결됐다(`MiniDungeon/MiniDungeonGrowth.cs`). 다음 메인 퀘스트가 레벨 때문에 막혔고(따라잡기 x10) 오늘 30분이 남았을 때만 `OrderCatchUp`(메인 퀘스트 바로 아래)으로 뜬다. 평소에는 사냥보다 느려서 추천하지 않는다(`BALANCE_MEASURE_2026-10-16.md` 6.1절). 아래 예시는 처음 설계안이다.

미니 던전처럼 나중에 들어오는 콘텐츠는 시작할 때 한 번 등록하면 HUD 카드, 퀘스트 창, 순서 정렬에 함께 들어간다.

```csharp
GrowthGuide.RegisterSource(level =>
{
    var d = MiniDungeons.BestFor(level);          // 레벨에 맞는 미니 던전, 없으면 null
    if (d == null) return null;                   // null이면 목록에 안 나온다
    return new GrowthGuide.Entry
    {
        order = GrowthGuide.OrderNormal + 50,     // 일반 던전 다음에 보이게. 0이면 OrderExtra(600)
        shortText = L.T(d.name),
        text = L.F("미니 던전 <color=#ffe066>{0}</color>", L.T(d.name)),
        button = L.T("미니 던전 열기"),
        action = () => MiniDungeons.Open(d.id),   // null이면 버튼 없는 안내 줄
    };
});
```

- 순서 값: 요일 던전 100, 일반 던전 200, 사냥터 300, 의뢰 400, 파티 500, 추가 콘텐츠 기본 600. 같은 값은 등록 순서대로 나온다.
- HUD 카드 내용은 요일·일반 던전과 사냥터 항목만 쓴다. 등록한 항목은 퀘스트 창 목록에 나온다.
- 등록 함수가 예외를 던지면 그 항목만 빠지고 로그가 남는다.
- 새 문구는 `L.T`·`L.F`로 감싸고 11개 언어 번역을 넣는다.
