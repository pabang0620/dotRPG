## 1. 규칙

| 항목 | 결정 |
|---|---|
| 대상 | 기본 액티브 10개(전사 5, 마법사 5) + 전직 스킬 38개 = 48개 전부. 스킬마다 특화 A·B 한 쌍 |
| 축 | A = 집중·압축(진홍 `#ff3344`): 발사체를 하나로 모으고, 범위를 좁히고, 한 방·한 대상을 세게. 쿨타임이 없던 스킬은 그대로 쿨 없이 두되 첫 대상에만 집중. B = 확산·분산(은백 `#e8ecff`, 테두리 `#6c7aa0`): 발사체를 여러 갈래로, 범위를 넓게, 대상 수를 늘리고 한 방은 약하게 |
| 해금 | Lv41~50 레벨업 때 자동. 돈·퀘스트·아이템 없음 |
| 선택·교체 | 마을(safe 맵) 안에서 스킬 창 특화 탭에서 무료, 횟수 제한 없음. 코바 마을의 전직 안내원 이츠나와 사얍 마을의 익시 대화에 같은 탭을 여는 "특화 조정" 항목. 마을 밖에서는 보기만. 선택 안 하면 원래 스킬 그대로(특화 없음) |
| 프리셋 | 스킬 스타일 3개에 특화 선택이 함께 저장된다(`styleSchema`에 `specs` 추가) |
| 기대값 | 기준 상황에서 A와 B의 분당 기대 피해가 같다. 기준 상황: A는 보스 1체 정면, B는 사냥터 묶음 3체(`HuntingGrounds.PackSize`). 회복·버프·제어기는 회복량·버프량·제어 총량(초 x 대상 수)으로 같은 규칙 |
| 색 | 특화를 고른 스킬의 투사체·장판·타격 이펙트 주색이 특화 색으로 바뀐다. 직업색은 보조색(테두리·잔광)으로 남는다. 아이콘은 기존 아이콘 위에 특화 테두리 2종(`spec_frame_a`, `spec_frame_b`)을 겹친다. 새 아이콘은 만들지 않는다 |
| 서버 | 선택을 저장·검증한다(레벨·해금·직업). 피해 계산은 하지 않는다(기존과 같다). 기대값 동일 원칙으로 공격 상한(`attackCap`)은 그대로 두고, 다중 적중 상한 `AOE_CAP`만 5에서 8로 올린다(B의 최대 대상 8) |

## 3. 특화 표

표기: 배율은 공격력 대비, 범위는 m, 기준은 `S()` 가공 전 원값. 마지막 열은 1절 원칙대로 A 보스 1체 한 번 시전 / B 묶음 3체 한 번 시전 합이고 두 값은 10% 안에 있다. 쿨·MP를 적지 않은 것은 원래 값 그대로. 버프·방어·제어·회복 줄은 각각 버프량·감소량·제어 총량(초 x 대상)·회복량으로 같은 규칙.

## 4. 데이터 구조

`Assets/Resources/Data/SkillSpecs.json`(클라이언트 원본, 내보내기로 `server/data/skill_specs.json`):

```json
{
  "schema": 1,
  "specs": [
    { "id": "m_ice_a", "skill": "m_ice", "side": "a", "name": "빙결일창", "unlock": 46,
      "text": "얼음창 하나에 셋의 힘을 모아 9m를 꿰뚫는다. 적중 시 2초 빙결.",
      "params": { "projectiles": 1, "spreadDeg": 0, "damageMult": 7.8, "range": 9, "freeze": 2.0 } },
    { "id": "m_ice_b", "skill": "m_ice", "side": "b", "name": "빙결육창", "unlock": 46,
      "text": "얼음창 여섯을 넓게 뿌린다. 한 창은 약하지만 묶음을 한 번에 적신다.",
      "params": { "projectiles": 6, "spreadDeg": 70, "damageMult": 1.3, "range": 6.5, "freeze": 1.0 } }
  ]
}
```

- `params` 키는 공용 집합이다: `projectiles`, `spreadDeg`, `damageMult`, `hits`, `cooldown`, `manaCost`, `radius`, `range`, `duration`, `targets`, `pierce`(bool), `extra`(스킬 전용 태그 문자열, 예 `"spread_on_step"`). 없는 키는 원값 유지.
- 기본 스킬 10개는 `SkillData.cs`의 `SkillGem` 값에, 전직 스킬 38개는 `CareerSkill` 값에 `params`를 덮어쓴다. 덮어쓴 결과가 `CharacterStatsCalc.Skill()`로 들어가므로 랭크·보조 젬·패시브 배율은 그대로 곱해진다.
- 해금 레벨은 데이터(`unlock`)가 원본이고 2절 표와 같다. 서버도 같은 파일을 읽는다.
