## 4. 데이터 구조

`Assets/Resources/Data/SkillSpecs.json`(클라이언트 원본, 내보내기로 `server/data/skill_specs.json`):

```json
{
  "schema": 1,
  "points": { "perLevel": 1, "from": 41, "to": 50, "active": 2, "passive": 1 },
  "specs": [
    { "id": "m_ice_a", "skill": "m_ice", "side": "a", "axis": "focus", "cost": 2, "name": "빙결일창",
      "text": "얼음창 하나에 셋의 힘을 모아 9m를 꿰뚫는다. 관통할수록 세진다.",
      "params": { "projectiles": 1, "spreadDeg": 0, "damageMult": 7.8, "range": 9, "freeze": 2.0, "extra": "pierce_ramp_25_3" } },
    { "id": "m_ice_b", "skill": "m_ice", "side": "b", "axis": "spread", "cost": 2, "name": "빙결육창",
      "text": "얼음창 여섯을 넓게 뿌린다. 벽과 적에서 한 번 튕긴다.",
      "params": { "projectiles": 6, "spreadDeg": 70, "damageMult": 1.3, "range": 6.5, "freeze": 1.0, "extra": "bounce_1" } }
  ]
}
```

- `axis`: focus·spread·burst·sustain·attack·mobility·support·passive. 서버의 AOE_CAP 조건은 `axis == "spread"`로 판정한다.
- `cost`: 액티브 2, 패시브 1. `points`가 원본이고 서버도 같은 파일을 읽는다.
- `params` 키는 공용 집합: `projectiles`, `spreadDeg`, `damageMult`, `hits`, `cooldown`, `manaCost`, `radius`, `range`, `duration`, `targets`, `pierce`, `extra`(스킬 전용 태그). 없는 키는 원값 유지. 덮어쓴 결과가 `CharacterStatsCalc.Skill()`로 들어가므로 랭크·보조 젬·패시브 배율은 그대로 곱해진다.
