# 캐시 아이템 가치 보존 기획 (판매·분해·교환소·컬렉션)

목표: 별조각으로 얻은 외형·장비가 겹치거나 쓸모가 줄어도 "버리는 돈"이 되지 않게 한다. 현금화 통로는 만들지 않고, 게임 안 가치로만 남긴다.

## 2. 지금 dotRPG 구조 (코드 기준)

- 외형 뽑기 1회 100 별조각(10+1회 1,000). 오라: 에픽 1%·희귀 18%·일반 81%. 스킨: 유니크 0.02%·에픽 1%·희귀 18%·일반 80.98%. 선택 게이지(오라 50회 에픽, 스킨 150회 유니크).
- 가진 외형이 또 나오면 "여분". 여분 분해 시 무료 별조각: 일반 20·희귀 50·에픽 300·유니크 1,500(`DISMANTLE_STARS`). 여분 4개 합성(일반->희귀 40%, 희귀->에픽 10%·15회 천장, 에픽->유니크 3%·10회 천장).
- 분해 기댓값(전부 여분이라 가정): 오라 1회 약 28 별조각, 스킨 1회 약 28.5 별조각 = 뽑기 값의 약 28%.
- 확정 교환: 일반 300·희귀 1,000·에픽 3,000(에픽 스킨 4,000), 유니크 스킨은 게이지로만.
- 컬렉션 6종: 세트를 다 가지면 계정 공격력·체력 %(공격 최대 +4%, 체력 최대 +11%).
- 장비 뽑기(무기·방어구·장신구) 1회 100 별조각, 언커먼 62%·레어 30%·에픽 7.5%·유니크 0.45%·레전더리 0.05%, 300회 천장. 뽑기 장비는 계정 귀속(경매·교환 불가). 상점 판매가는 골드(예: 20단계 에픽 무기 1,313골드).
- 별조각은 무료분부터 쓰고 유료분은 주문별 lot으로 추적(환불 시 남은 유료분 회수, 쓴 만큼 부채).

## 3. 제안

### 3-1. 새 재화 "별의 결정" (교환 포인트)
- 얻는 곳: 외형 여분 분해, 뽑기 장비 분해, 확정 교환으로 산 외형의 중복 분해.
- 쓰는 곳: 별빛 교환소(3-3)만. 별조각·골드로 바꿀 수 없고, 교환소 물건은 전부 계정 귀속이라 다른 이용자에게 넘길 수 없다(환전 금지 대응).
- 지갑은 별조각과 따로 둔다(`crystal_wallet`, 원장 `crystal_ledger`). 유료 별조각으로 얻은 아이템에서 나온 결정은 출처 주문을 기록해(유료 lot과 같은 방식) 환불 시 회수한다.

### 3-2. 분해 값 (뽑기 1회 기대 가치가 별조각 기준 40% 이상 남도록)

| 대상 | 무료 별조각(현행 유지) | 별의 결정(추가) |
|---|---|---|
| 외형 여분 일반 | 20 | 4 |
| 외형 여분 희귀 | 50 | 12 |
| 외형 여분 에픽 | 300 | 60 |
| 외형 여분 유니크 | 1,500 | 300 |
| 뽑기 장비 언커먼 | - | 3 (+강화 재료 뼈 2) |
| 뽑기 장비 레어 | - | 8 (+정수 1) |
| 뽑기 장비 에픽 | - | 30 (+정수 3) |
| 뽑기 장비 유니크 | - | 150 |
| 뽑기 장비 레전더리 | - | 600 |

- 외형 뽑기 1회 분해 기대: 별조각 약 28 + 결정 약 6.3(1결정 = 2 별조각 가치로 잡으면 약 12.6) = 약 41% 회수.
- 장비 뽑기 1회 분해 기대: 결정 약 7.1(약 14 별조각 가치) + 재료. 뽑기 장비는 상점 판매(골드)를 막고 분해만 허용한다(유료 -> 골드 -> 교환·경매 통로 차단). 단, 지금 착용 중이거나 강화한 장비는 강화 단계만큼 결정을 더 준다(+1강당 5%).

### 3-3. 별빛 교환소 (결정으로 사는 확정 품목, 전부 계정 귀속)

| 품목 | 가격(결정) | 비고 |
|---|---|---|
| 원하는 희귀 오라·스킨 1개 | 150 | 확정 교환(지금 1,000 별조각)보다 싸게: 결정 가치 300 별조각 |
| 원하는 에픽 오라 1개 | 500 | |
| 원하는 에픽 스킨 1개 | 700 | |
| 스킨 선택 게이지 +10칸 | 120 | 주 1회 |
| 장비 뽑기 천장 +10칸 | 100 | 주 3회 |
| 강화 보호권 1장 | 80 | 주 5회 |
| 요일 던전 초기화권 1장 | 60 | 주 2회 |
| 정수 10개 | 40 | 주 10회 |
| 교환소 전용 외형(시즌마다 4종) | 400~900 | 여기서만 얻는 외형으로 결정에 목표를 줌 |

- 주간 한도는 결제 한도가 아니라 교환소 재고다(결제 제한 금지 원칙과 무관). 원신처럼 일부 품목만 한도를 두고 외형은 한도 없음.
- 교환소 품목은 모두 확정 구매라 확률 표시 대상이 아니다. 단 "장비 뽑기 천장 +칸"은 뽑기 천장과 묶이므로 확률 공개 페이지의 천장 설명에 함께 적는다.

### 3-4. 컬렉션 확장 (분해 대신 "모아 두는" 가치)
- 지금 6세트에 등급별 세트를 추가: 스킨·오라가 늘어나는 만큼 5~6개씩 묶어 세트를 만들고, 세트 보너스는 공격 +1% 또는 체력 +2%(전체 상한: 공격 +8%, 체력 +20%).
- 등록은 외형을 소모하지 않는다(현행). 등록한 외형의 여분은 분해 시 결정 +20%를 더 준다(모은 사람이 손해 보지 않게).
- 장비 도감: 뽑기·드롭으로 처음 얻은 유니크·레전더리를 도감에 기록하면 계정 체력 +0.5%(부위·단계별 1회). 도감 등록 후 그 장비를 분해해도 도감은 남는다.

## 4. 남용·법적 장치

1. 유료·무료 분리: 결정은 별조각으로 되돌릴 수 없고, 유료 별조각 출처는 주문 단위로 추적해 청약철회·환불 시 남은 결정과 교환소 품목을 회수(쓴 만큼 부채, paid.md 제6조와 같은 방식).
2. 현금화 차단: 뽑기 장비는 상점 골드 판매 불가·계정 귀속(현행), 결정·교환소 품목도 계정 귀속. 1:1 교환과 경매에 올릴 수 없다.
3. 청약철회: 쓰지 않은 유료 별조각은 7일 철회(현행). 분해는 "사용"에 해당하므로 분해 전 확인 문구에 철회 제한을 한 줄로 알린다(결제 확인 창이 아니라 분해 안내 문구).
4. 표시: 분해 값·교환 가격을 화면과 정책 페이지(유료 정책 제9조 부근)에 적는다. 합성·뽑기 확률은 지금처럼 확률 공개 페이지에 자동 반영.
5. 서비스 종료 시: 결정은 유료 재화가 아니므로 환불 대상이 아님을 정책에 명시하되, 유료 별조각 환불 기준(paid.md 제8조)은 그대로.

## 5. 필요한 그림

- 별빛 교환소 창 머리 장식 1종, 교환소 NPC 초상 1종(마을에 배치할 경우, 여자 도트 캐릭터).
