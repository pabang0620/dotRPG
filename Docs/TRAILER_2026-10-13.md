# 홍보 영상 (1분, 실제 플레이 화면)

게임이 스스로 장면을 연출하며 매 프레임을 저장하고, ffmpeg로 자막과 음악을 붙여 1분 영상으로 만든다. 화면 녹화 프로그램은 쓰지 않는다.

## 1. 순서
```bash
# 0) 빌드 복사본을 최신으로 맞추고 PC 빌드 (평소 절차)
# 1) 촬영 (1920x1080 창 모드, 약 4분)
cd /mnt/c/Users/admin/Desktop/games/dotRPG_apkbuild/Builds/WindowsSteamTest
cmd.exe /c start "" dotRPG.exe -dotrpgTrailer "C:\Users\admin\Desktop\games\trailer_capture" -screen-width 1920 -screen-height 1080 -screen-fullscreen 0
# 2) 편집
cd /mnt/c/Users/admin/Desktop/games/dotRPG
Tools/video/make_trailer.sh /mnt/c/Users/admin/Desktop/games/trailer_capture
# -> games/dotRPG_videos/dotRPG_trailer_1min.mp4
```

## 2. 촬영 모드 `-dotrpgTrailer <폴더> [-scene a,b]`
- 코드: `Assets/Scripts/Runtime/Core/DevCapture.Trailer.cs`. 오프라인, 세이브는 촬영 폴더 안에 따로 생긴다.
- 30fps 고정 시간으로 `clips/<장면>/f0000.jpg`를 저장한다.

| 장면 | 내용 |
|---|---|
| hunt | Lv32 파이터 + AI 3명, Lv30 사냥터 자동 사냥 10초 |
| awaken | 파이터 천검귀일, 아케니스트 유성우를 실제 몬스터 무리에 |
| dungeon | Lv27 수호자 + AI 3명, 요일 던전 영웅 난이도 9초 |
| grah | 그라흐 레이드: 체력 66%로 맞춰 결계 의식(대사, 마법진, 파훼 그로기) 17초, 이어서 파동 4.5초 |
| king | 해골왕 레이드: 3페이즈로 맞춰 망자의 심판 저지 11초, 처치 4초, 보상 카드 8초 |

## 3. 편집 `Tools/video/make_trailer.sh <촬영 폴더> [출력 파일]`
- 타이틀 카드(로고 + 문구) 3.5초, 장면 9개(아래 2줄 자막), 엔딩 카드 4초, 레이드 음악(`music_raid_enrage.ogg`) 페이드.
- 장면별 시작 초·길이·자막은 스크립트의 `segments` 표에서 고친다. 장면을 다시 찍으면 시작 초를 다시 고른다(결계 장면은 대사가 약 7.5초에 나온다).
- 글꼴: 나눔스퀘어라운드 Bold(WSL). 출력: 1920x1080, H.264 crf 18, AAC 192k.

## 4. 주의
- 파티 장면은 AI 동료로 찍는다(온라인 4인 파티를 자동으로 찍는 장치는 없다).
- 완성 영상은 모두 `games/dotRPG_videos`에 둔다. 촬영 폴더(JPG 수천 장)는 영상을 만든 뒤 지운다. 저장소 안에 두지 않는다.

## 5. 속도감 있는 광고 (30초, 이것만 쓴다)
```bash
# UI 없이 촬영 (-clean 1): 각성기는 사냥터에서 가장 트인 곳 + 몬스터 16마리, 레이드 보상은 유니크 2장 + 레전더리 무기(촬영 전용 보상 판정)
cmd.exe /c start "" dotRPG.exe -dotrpgTrailer "C:\Users\admin\Desktop\games\ad_capture" -clean 1 -screen-width 1920 -screen-height 1080 -screen-fullscreen 0
python3 Tools/video/make_ad.py /mnt/c/Users/admin/Desktop/games/ad_capture   # -> games/dotRPG_videos/dotRPG_ad_30s.mp4
```
- 컷은 `music_raid_enrage`(80.7 BPM)의 반 박자(0.372초) 단위. 컷마다 확대 펀치(14%, 5프레임), 흰색 번쩍임, 타격 컷은 흔들림, 처치는 슬로 모션.
- 자막은 Pillow로 그린 PNG: 제목 글꼴 Black Han Sans(OFL, `Tools/video/fonts`), 금속 그라데이션 + 굵은 외곽선 + 색 발광 + 기울임. 각성기는 직업 색 이름판(천검귀일, 천쇄방패, 유성우, 천상의 행진). 이 ffmpeg(8.0.1)는 drawtext 글자 크기에 시간 식을 쓰면 비정상 종료한다.
- 컷마다 게임 효과음을 겹치고 -14 LUFS로 맞춘다.
- 컷 표(장면, 시작 초, 반 박자 수, 확대, 슬로, 흔들림, 효과음, 자막 형식, 문구, 색, 확대 중심)는 `SHOTS`. 다시 찍으면 장면별 시작 초를 다시 고른다(보상 장면은 8.6초에 마우스 설명창이 뜨므로 그 전에 끊는다).

## 6. 레이드 보스 트레일러 (게임 안, 2026-10-15)
- 레이드 4종(해골왕, 흑철의 바르가스, 바위 심장 골렘, 수호자 그라흐)마다 10초 영상 1개: `Assets/Resources/Video/trailer_<던전 id>.mp4`.
- 재생: 그 기기에서 던전 창으로 레이드를 처음 고를 때 1번(입장할 수 있는 상태일 때만, 방장·파티원 모두 같은 시점이고 출발을 막지 않는다), 던전 창 레이드 배너의 "보스 영상 보기"로 다시 보기. 아무 키·클릭·터치로 건너뛴다. 코드 `UI/BossTrailer.cs`, 본 기록은 PlayerPrefs `boss_trailer_seen_<id>`.
- 새 레이드에 영상을 붙이려면 같은 이름 규칙으로 파일만 넣으면 된다(배너와 첫 선택 재생이 자동으로 붙는다).
- 만든 방법 (Google Flow, lwh970924 계정):
  1. 시작 장면: Nano Banana Pro(0 크레딧), 16:9. 참고 이미지 2장 = 보스 스프라이트(`char_<boss>_down_attack` 8배 확대) + 레이드 배너(`banner_raid_<id>`). 픽셀 아트 키 아트 프롬프트.
  2. 영상: 동영상 > 프레임 > 시작 프레임에 1번 그림, Omni 1.1 Flash, 720p, 10초, x1 = **15 크레딧**. (Veo 3.1 Lite 8초 10, Fast 20, Quality 100: 쓰지 않는다.) 프롬프트는 장면 유지 + 카메라 밀기 + 보스 각성 VFX + 마지막에 충격파.
  3. 후처리: 오른쪽 아래 워터마크는 지우지 않고 잘라낸다.
     `ffmpeg -i in.mp4 -vf "setpts=PTS-STARTPTS,crop=994:559:143:80,scale=1280:720:flags=lanczos,fade=t=in:st=0:d=0.3,fade=t=out:st=9.5:d=0.5,format=yuv420p" -af "asetpts=PTS-STARTPTS,loudnorm=I=-16:TP=-1.5:LRA=11,afade=t=out:st=9.4:d=0.6" -c:v libx264 -profile:v baseline -level 3.1 -bf 0 -crf 22 -maxrate 4M -bufsize 8M -r 24 -c:a aac -b:a 128k -ar 44100 -movflags +faststart out.mp4`
     (baseline이 아니면 Unity가 타임스탬프 경고를 낸다.)
- 원본(시작 장면 jpg, Flow 원본 mp4, 참고 이미지)은 저장소 밖 `/home/lee/project/generated-images/dotrpg_trailer/`.
