# 홍보 영상 (1분, 실제 플레이 화면)

게임이 스스로 장면을 연출하며 매 프레임을 저장하고, ffmpeg로 자막과 음악을 붙여 1분 영상으로 만든다. 화면 녹화 프로그램은 쓰지 않는다.

## 1. 순서
```bash
# 0) 빌드 복사본을 최신으로 맞추고 PC 빌드 (평소 절차)
# 1) 촬영 (1920x1080 창 모드, 약 4분)
cd /mnt/c/Users/admin/Desktop/games/dotRPG_apkbuild/Builds/WindowsSteamTest
cmd.exe /c start "" dotRPG.exe -dotrpgTrailer "C:\Users\admin\Desktop\games\trailer_capture" -screen-width 1920 -screen-height 1080 -screen-fullscreen 0
# 2) 편집
cd /mnt/c/Users/admin/Desktop/games/dotRPG
Tools/video/make_trailer.sh /mnt/c/Users/admin/Desktop/games/trailer_capture
# -> trailer_capture/dotRPG_trailer.mp4
```

## 2. 촬영 모드 `-dotrpgTrailer <폴더> [-scene a,b]`
- 코드: `Assets/Scripts/Runtime/Core/DevCapture.Trailer.cs`. 오프라인, 세이브는 촬영 폴더 안에 따로 생긴다.
- 30fps 고정 시간으로 `clips/<장면>/f0000.jpg`를 저장한다.

| 장면 | 내용 |
|---|---|
| hunt | Lv32 파이터 + AI 3명, Lv30 사냥터 자동 사냥 10초 |
| awaken | 파이터 천검귀일, 아케니스트 유성우를 실제 몬스터 무리에 |
| dungeon | Lv27 수호자 + AI 3명, 요일 던전 영웅 난이도 9초 |
| grah | 그라흐 레이드: 체력 66%로 맞춰 결계 의식(대사, 마법진, 파훼 그로기) 17초, 이어서 파동 4.5초 |
| king | 해골왕 레이드: 3페이즈로 맞춰 망자의 심판 저지 11초, 처치 4초, 보상 카드 8초 |

## 3. 편집 `Tools/video/make_trailer.sh <촬영 폴더> [출력 파일]`
- 타이틀 카드(로고 + 문구) 3.5초, 장면 9개(아래 2줄 자막), 엔딩 카드 4초, 레이드 음악(`music_raid_enrage.ogg`) 페이드.
- 장면별 시작 초·길이·자막은 스크립트의 `segments` 표에서 고친다. 장면을 다시 찍으면 시작 초를 다시 고른다(결계 장면은 대사가 약 7.5초에 나온다).
- 글꼴: 나눔스퀘어라운드 Bold(WSL). 출력: 1920x1080, H.264 crf 18, AAC 192k.

## 4. 주의
- 파티 장면은 AI 동료로 찍는다(온라인 4인 파티를 자동으로 찍는 장치는 없다).
- 촬영 폴더(JPG 수천 장)는 영상을 만든 뒤 지워도 된다. 저장소 안에 두지 않는다.
